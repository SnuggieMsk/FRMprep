# 14. Binomial Trees

Option pricing by replication and risk-neutral valuation on a lattice. GARP tests the no-arbitrage delta, the risk-neutral probability, full two-step valuations, and the American early-exercise check at each node.

## Learning objectives

- Value a derivative on a one-step tree by constructing a riskless (replicating) portfolio.
- Define and apply risk-neutral probabilities; explain why real-world probabilities are irrelevant to the price.
- Value European options on two-step trees by backward induction.
- Value American options on trees, comparing exercise and continuation value at every node.
- Calibrate u and d to volatility: $$u = e^{\sigma\sqrt{\Delta t}}$$, $$d = 1/u$$.
- Modify the tree for options on stocks with dividend yields, currencies, and futures.
- Explain convergence to Black–Scholes–Merton as the number of steps increases.

## One step: replication and delta

Stock at $$S_0$$ moves to $$S_0 u$$ (option worth $$f_u$$) or $$S_0 d$$ (worth $$f_d$$) over Δt. Hold Δ shares and short one option; choose Δ so the portfolio's payoff is identical in both states:

$$\Delta = \frac{f_u - f_d}{S_0 u - S_0 d}$$

A riskless portfolio must earn the risk-free rate, which forces a unique no-arbitrage option price. No assumption about the *probability* of an up move was needed — only no-arbitrage.

{: .note }
The replicating delta is the binomial ancestor of the BSM hedge ratio: for a call, 0 ≤ Δ ≤ 1 and it rises as the option moves into the money. In a multi-step tree Δ differs at every node — the discrete version of dynamic delta hedging.

## Risk-neutral valuation

The algebra of replication can be repackaged: define

$$p = \frac{e^{r\Delta t} - d}{u - d}$$

Then the option price is the **expected payoff under p, discounted at the risk-free rate**:

$$f = e^{-r\Delta t}\left[p f_u + (1-p) f_d\right]$$

p is the **risk-neutral probability** — the up-probability in a fictitious world where every asset drifts at r. It is a pricing device, not a forecast: real-world probabilities and risk premia cancel out of the no-arbitrage price. A sanity check: under p the stock's expected value grows at r, i.e., $$p S_0 u + (1-p) S_0 d = S_0 e^{r\Delta t}$$.

## Calibrating to volatility

Match the tree's variance to the stock's (Cox–Ross–Rubinstein):

$$u = e^{\sigma\sqrt{\Delta t}} \qquad d = \frac{1}{u} = e^{-\sigma\sqrt{\Delta t}}$$

σ is the annualized volatility and Δt the step length in years. With d = 1/u the tree recombines: an up-down path and a down-up path land on the same node, so an n-step tree has n + 1 terminal nodes, not 2ⁿ.

## Two-step trees and backward induction

Value the terminal payoffs, then roll backward one step at a time, applying the one-step formula at each node (and using each node's own p if parameters vary).

### Worked example: two-step European call

$$S_0 = 100$$, K = 100, u = 1.1, d = 0.9, r = 6% (continuous), Δt = 0.5 years.

$$p = \frac{e^{0.06 \times 0.5} - 0.9}{1.1 - 0.9} = \frac{1.030455 - 0.9}{0.2} = 0.6523$$

Terminal stock prices and call payoffs: $$S_{uu} = 121 \to 21$$; $$S_{ud} = 99 \to 0$$; $$S_{dd} = 81 \to 0$$.

Up node: $$f_u = e^{-0.03}(0.6523 \times 21 + 0.3477 \times 0) = 0.97045 \times 13.698 = 13.293$$

Down node: $$f_d = 0$$.

Root: $$f = e^{-0.03}(0.6523 \times 13.293 + 0.3477 \times 0) = 0.97045 \times 8.671 = \mathbf{\$8.41}$$

Shortcut for European options only: discount the probability-weighted terminal payoffs in one shot, $$f = e^{-0.06}\,p^2 (21) = 0.94177 \times 0.4255 \times 21 = 8.41$$ — same answer.

## American options: check early exercise at every node

Backward induction with one extra comparison at each node:

$$f_{node} = \max(\text{intrinsic value},\; \text{continuation value})$$

where continuation is the usual discounted risk-neutral expectation. Early exercise of American puts is optimal when the stock is low enough that collecting K now beats waiting; American calls on non-dividend stocks are never exercised early.

### Worked example: American put with early exercise

Same tree ($$S_0 = 100$$, u = 1.1, d = 0.9, r = 6%, Δt = 0.5, p = 0.6523), American put, K = 100. Terminal payoffs: 121 → 0; 99 → 1; 81 → 19.

Up node (S = 110): continuation $$= e^{-0.03}(0.6523 \times 0 + 0.3477 \times 1) = 0.337$$; intrinsic = 0 → value **0.337**.

Down node (S = 90): continuation $$= e^{-0.03}(0.6523 \times 1 + 0.3477 \times 19) = 0.97045 \times 7.259 = 7.045$$; intrinsic = 100 − 90 = **10**. Exercise: 10 > 7.045 → value **10**.

Root: $$f = e^{-0.03}(0.6523 \times 0.337 + 0.3477 \times 10) = 0.97045 \times 3.697 = \mathbf{\$3.59}$$

The European put on the same tree is worth \$2.59 — the dollar of difference is the value of the early-exercise right, created entirely at the down node.

{: .warning }
The single most common error: valuing an American option by discounting terminal payoffs directly (the European shortcut). That skips the node-by-node max(intrinsic, continuation) test and **understates** the American price. Always roll back node by node, and compare intrinsic vs continuation at *every* non-terminal node — including the root.

## Other underlyings: adjust the numerator

The risk-neutral probability uses the underlying's **cost-of-carry growth rate** in the numerator:

| Underlying | p |
|---|---|
| Non-dividend stock | $$\dfrac{e^{r\Delta t} - d}{u - d}$$ |
| Stock index, dividend yield q | $$\dfrac{e^{(r-q)\Delta t} - d}{u - d}$$ |
| Currency, foreign rate $$r_f$$ | $$\dfrac{e^{(r-r_f)\Delta t} - d}{u - d}$$ |
| Futures | $$\dfrac{1 - d}{u - d}$$ |

A futures price is costless to enter, so its risk-neutral drift is zero — set the growth factor to 1. **Discounting is always at the domestic risk-free rate r**, whatever sits in the numerator.

{: .tip }
Memorize one template: $$p = \frac{e^{(\text{growth})\Delta t} - d}{u - d}$$ where growth = r, r − q, r − r_f, or 0. Exam answer choices usually include the result of using plain r when q or r_f should have been subtracted.

## Convergence to BSM

As the number of steps grows (Δt → 0) with u, d calibrated to σ, the binomial price of a European option converges to the Black–Scholes–Merton price. In practice 30+ steps is close; trees remain the workhorse for **American** options precisely because BSM has no closed form for them.

## Quick quiz

**1.** A stock trades at 50; in one year it is 60 or 45. The risk-free rate is 5% (continuous). The risk-neutral probability of the up move is closest to:
- A. 0.504
- B. 0.333
- C. 0.546
- D. 0.500

**2.** With σ = 30% and monthly steps, u is closest to:
- A. 1.090
- B. 1.300
- C. 1.025
- D. 1.350

**3.** In a binomial tree for options on futures, the risk-neutral probability is:
- A. (e^{rΔt} − d)/(u − d)
- B. (1 − d)/(u − d)
- C. (e^{(r−q)Δt} − d)/(u − d)
- D. (e^{−rΔt} − d)/(u − d)

**4.** At a node, an American put has intrinsic value 8.20 and continuation value 7.60. The value used at that node in backward induction is:
- A. 7.60
- B. 8.20
- C. 7.90
- D. 0.60

<details markdown="1">
<summary>Show answers</summary>

**1. A.** u = 60/50 = 1.2, d = 45/50 = 0.9. p = (e^{0.05} − 0.9)/(1.2 − 0.9) = 0.15127/0.3 = 0.504. Note u and d come from the given prices — no volatility formula needed here.

**2. A.** u = e^{0.30√(1/12)} = e^{0.30 × 0.2887} = e^{0.0866} = 1.0905. Choice B forgets the √Δt.

**3. B.** Futures have zero drift in the risk-neutral world (no cash outlay), so the growth factor is 1. Discounting still uses e^{−rΔt}.

**4. B.** American valuation takes max(intrinsic, continuation) = max(8.20, 7.60) = 8.20 — the holder exercises.
