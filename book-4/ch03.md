# 3. Measuring and Monitoring Volatility

GARP tests the EWMA and GARCH(1,1) update formulas (near-certain calculation questions), why return distributions deviate from normality, and how implied volatility and correlation are monitored. Memorize both recursions cold.

## Learning objectives

- Explain how asset return distributions deviate from normality (fat tails, skew) and why.
- Distinguish conditional vs unconditional distributions and explain regime switching.
- Estimate volatility using simple historical (equal-weight) standard deviation and discuss its drawbacks.
- Apply the EWMA model to update volatility estimates.
- Apply the GARCH(1,1) model; compute the long-run (unconditional) variance and explain mean reversion.
- Explain implied volatility and its term structure/smile as a market-based volatility measure.
- Describe how correlations and covariances are updated (EWMA/GARCH logic) and monitored.

## Deviations from normality

Empirical daily returns show:

- **Fat tails (leptokurtosis):** far more 4σ–10σ days than the normal predicts.
- **Negative skew** in equities: crashes are bigger than rallies.
- **Volatility clustering:** big moves follow big moves — volatility is time-varying.

A key insight: returns can be **conditionally normal** (normal each day given that day's volatility) yet **unconditionally fat-tailed**, because mixing normals with different variances produces excess kurtosis. **Regime switching** formalizes this: volatility flips between high and low states; within a regime returns look normal, across regimes the blended distribution has fat tails. So fat tails arise from a changing σ at least as much as from non-normal shocks.

{: .note }
This is why volatility *updating* (EWMA/GARCH) matters: if you track the conditional σ accurately, the standardized returns look much closer to normal.

## Historical (equal-weight) volatility

Using m daily returns (mean assumed ≈ 0 at daily horizon):

$$\hat\sigma_n^2 = \frac{1}{m}\sum_{i=1}^{m} r_{n-i}^2$$

Drawbacks: every observation gets weight 1/m regardless of age; a single large return causes a jump in σ that persists until it abruptly drops out of the window (**ghosting**).

## EWMA

Exponentially weighted moving average puts geometrically declining weights on past squared returns. One-line recursion:

$$\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$$

- λ (decay factor) ∈ (0,1); RiskMetrics classic: **λ = 0.94** for daily data.
- Higher λ → slower reaction, longer memory; lower λ → fast reaction, noisy.
- No mean reversion: the forecast for all future days equals today's estimate.
- Weight on the squared return from i days ago: $$(1-\lambda)\lambda^{i-1}$$.

### Worked example: EWMA update

λ = 0.94, yesterday's volatility estimate σ = 1.2%/day, yesterday's return = −2%.

$$\sigma_n^2 = 0.94 \times (0.012)^2 + 0.06 \times (-0.02)^2 = 0.94 \times 0.000144 + 0.06 \times 0.0004$$

$$= 0.00013536 + 0.000024 = 0.00015936$$

$$\sigma_n = \sqrt{0.00015936} = 1.262\%$$

The big return pulls volatility **up** from 1.20% to 1.26%. (Distractor check: forgetting to square, or averaging σ instead of σ², gives wrong answers like 1.25% by linear interpolation.)

## GARCH(1,1)

$$\sigma_n^2 = \omega + \alpha\, r_{n-1}^2 + \beta\, \sigma_{n-1}^2$$

with α + β < 1 for stationarity. The long-run (unconditional) variance:

$$V_L = \frac{\omega}{1 - \alpha - \beta}$$

Equivalently $$\omega = \gamma V_L$$ with weights γ + α + β = 1. GARCH = EWMA **plus mean reversion** toward $$V_L$$: multi-day forecasts decay from today's σ² to $$V_L$$ at rate (α+β). EWMA is the special case ω = 0, α = 1−λ, β = λ.

### Worked example: GARCH(1,1) update and long-run variance

ω = 0.000002, α = 0.13, β = 0.86. Current daily volatility 1.6%; today's return +1%.

**Long-run variance:**

$$V_L = \frac{0.000002}{1 - 0.13 - 0.86} = \frac{0.000002}{0.01} = 0.0002 \;\Rightarrow\; \sigma_L = \sqrt{0.0002} = 1.414\%$$

**Update:**

$$\sigma_n^2 = 0.000002 + 0.13 \times (0.01)^2 + 0.86 \times (0.016)^2$$

$$= 0.000002 + 0.000013 + 0.00022016 = 0.00023516$$

$$\sigma_n = 1.534\%$$

Volatility falls from 1.60% toward the 1.41% long-run level because the new return (1%) was small relative to the prior estimate — mean reversion in action.

{: .warning }
Work entirely in **variances**, converting to σ only at the end. The single most common error is plugging σ (0.016) where σ² (0.000256) belongs, or quoting the variance 0.000235 as "volatility." Also: α multiplies the **return**, β multiplies the **prior variance** — swapping them is a favorite distractor.

## Implied volatility

Back out σ from observed option prices by inverting BSM. It is **forward-looking** (market's consensus over the option's life) versus backward-looking statistical estimates.

- **VIX:** model-free 30-day implied volatility of S&P 500 options — the "fear gauge."
- **Smile/skew:** implied vol varies with strike (equity index puts trade at higher implied vol — crash protection premium), violating BSM's constant-σ assumption.
- **Term structure:** implied vol varies with maturity.

Limitations: only available where liquid options trade; embeds risk premia, so it tends to sit above subsequent realized volatility on average.

## Monitoring correlation and covariance

The same updating machinery applies to covariances:

$$\text{cov}_n = \lambda\,\text{cov}_{n-1} + (1-\lambda)\,x_{n-1}y_{n-1}$$

then $$\rho_n = \text{cov}_n / (\sigma_{x,n}\sigma_{y,n})$$. Use the **same λ** for variances and covariances to keep the covariance matrix internally consistent (positive semi-definite). Correlations spike toward 1 in crises — exactly when diversification is needed most — so monitoring them dynamically matters for portfolio VaR.

| Model | Reaction speed | Mean reversion | Parameters |
|---|---|---|---|
| Equal-weight historical | Slow, ghosting | No | window m |
| EWMA | Tunable via λ | No | λ |
| GARCH(1,1) | Tunable via α | **Yes**, to $$V_L$$ | ω, α, β |
| Implied | Instant (market) | n/a | none (market price) |
