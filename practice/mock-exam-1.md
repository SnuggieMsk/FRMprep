# Mock Exam 1 — Questions

This mock replicates the FRM Part I computer-based exam: **100 multiple-choice
questions** drawn from all four books and presented in mixed order, exactly as
on exam day.

{: .important }
Sit this in **one timed 4-hour block**, closed book, using only a
GARP-approved calculator (TI BA II Plus or HP 12C family). There is **no
negative marking** — answer every question. Target pace: ~2.4 minutes per
question.

{: .note }
Grade yourself with the companion [answer key](mock-exam-1-answers), which
contains worked solutions, the book/topic tag for every question, and a
per-book scoring grid.
