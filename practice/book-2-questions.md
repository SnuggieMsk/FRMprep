# Book 2 Question Bank — Quantitative Analysis

25 exam-style questions spanning all 15 chapters, with extra weight on Chapter 6 (hypothesis testing) and Chapter 10 (stationary time series), where GARP's 2026 LOs push applied calculation. Work them closed-book under time pressure (~90 seconds each), then check the worked solutions at the bottom.

**Q9 (Ch 6).** A strategy's 36 monthly excess returns average 1.2% with a sample standard deviation of 3.6%. Testing $$H_0\!: \mu = 0$$ against $$H_1\!: \mu \neq 0$$ (two-tailed critical values: $$t_{35,2.5\%} = 2.03$$, $$t_{35,5\%} = 1.69$$), the best conclusion is:

B. t = 2.00; fail to reject $$H_0$$ at 5%, but reject at 10%

**Q10 (Ch 6).** A test of $$H_0\!: \mu = 0$$ is run at a 5% significance level and has power of 0.80. Which statement is correct?

D. Power is the probability of rejecting $$H_0$$ when $$H_0$$ is true

## Answers and explanations

**Q1 — B.** *(Medium.)* Bayes via the total-probability table:

$$P(H \cap D) = 0.10 \times 0.60 = 0.06 \qquad P(L \cap D) = 0.90 \times 0.20 = 0.18$$

$$P(H \mid D) = \frac{0.06}{0.06 + 0.18} = \frac{0.06}{0.24} = 0.25$$

Distractor A is the joint probability (numerator only); D is the inverted conditional $$P(D \mid H)$$.

**Q2 — A.** *(Easy.)* Independence gives $$P(A \cap B) = 0.4 \times 0.5 = 0.20$$, so

$$P(A \cup B) = 0.40 + 0.50 - 0.20 = 0.70$$

Distractor B forgets to subtract the intersection.

**Q3 — B.** *(Easy.)* $$\mathrm{Var}(3 + 2X) = 2^2 \times 5 = 20$$. The additive constant does nothing (C wrong); the multiplier enters squared (A forgets the square); D squares the whole product.

**Q4 — B.** *(Medium.)* Binomial with $$n = 10$$, $$p = 0.1$$:

$$P(X=2) = \binom{10}{2}(0.1)^2(0.9)^8 = 45 \times 0.01 \times 0.4305 = 0.1937 \approx 19.4\%$$

Distractor A omits the combination factor; C is $$P(X=1) = 38.7\%$$; D is the cumulative $$P(X \le 2) = 93.0\%$$.

**Q5 — B.** *(Medium.)* Poisson with $$\lambda = 2$$:

$$P(X = 3) = \frac{e^{-2}\,2^3}{3!} = 0.1353 \times \frac{8}{6} = 0.1804 \approx 18.0\%$$

Distractor A is $$P(X=0) = e^{-2}$$; C is $$P(X=2) = 27.1\%$$; D is the cumulative $$P(X \le 3)$$.

**Q6 — C.** *(Easy.)* $$\mathrm{Cov}(aX+b,\ cY+d) = ac\,\mathrm{Cov}(X,Y) = 2 \times 5 \times 0.006 = 0.060$$. Additive constants drop out entirely (D wrongly lets them creep in); A applies no scaling; B scales by only one multiplier.

**Q7 — B.** *(Medium.)* Mean = 6%; squared deviations 16, 4, 0, 4, 16 sum to 40, so

$$s^2 = \frac{40}{5-1} = 10 \Rightarrow s = 3.162\% \qquad SE(\bar{X}) = \frac{3.162\%}{\sqrt{5}} = 1.41\%$$

Distractor D stops at $$s$$; A divides by $$n$$ instead of $$\sqrt{n}$$; C is $$s^2/n$$ misread as a percentage.

**Q8 — B.** *(Easy.)* Negative skew = longer/heavier **left** tail (big losses more likely than big gains); kurtosis 6.5 means excess kurtosis of 3.5 — fatter tails than normal. Skew and kurtosis measure different things and never "offset" (D).

**Q9 — B.** *(Medium.)*

$$t = \frac{1.2 - 0}{3.6/\sqrt{36}} = \frac{1.2}{0.6} = 2.00$$

With 35 df, the 5% two-tailed critical value is 2.03, so 2.00 falls just short — fail to reject at 5%. At 10% the critical value is 1.69, so reject. Distractor A applies the normal value 1.96 despite the small-sample t-test — exactly the trap the question sets; C forgets $$\sqrt{n}$$; D forgets to divide $$s$$ by $$\sqrt{n}$$ at all.

**Q10 — A.** *(Medium.)* Power $$= 1 - \beta$$, so $$\beta = P(\text{Type II}) = 0.20$$; more observations sharpen the test and raise power. B confuses the two error types ($$P(\text{Type I}) = \alpha = 0.05$$). C is backwards — a stricter significance level makes rejection harder and *lowers* power for a fixed sample. D defines a Type I error, not power: power conditions on $$H_0$$ being **false**.

**Q11 — A.** *(Hard.)* Chi-square test of a variance:

$$\chi^2 = \frac{(n-1)s^2}{\sigma_0^2} = \frac{19 \times 0.0036}{0.0025} = \frac{0.0684}{0.0025} = 27.36$$

Since 27.36 < 30.14, fail to reject — a sample standard deviation of 6% from only 20 observations is not statistically distinguishable from 5%. Distractor C uses $$n = 20$$ instead of $$n - 1 = 19$$ (and even then 28.80 < 30.14 would still fail to reject); D is the variance ratio $$s^2/\sigma_0^2$$ without the df scaling.

**Q12 — A.** *(Medium.)*

$$\hat\beta = \frac{\mathrm{Cov}(X,Y)}{\mathrm{Var}(X)} = \frac{0.0045}{0.0030} = 1.50 \qquad \hat\alpha = 0.9\% - 1.50 \times 0.5\% = 0.15\%$$

Distractor B inverts the slope by dividing covariance by $$\mathrm{Var}(Y)$$-style logic; C forgets to subtract $$\hat\beta\bar{X}$$; D flips the subtraction.

**Q13 — B.** *(Medium.)*

$$\bar{R}^2 = 1 - (1 - 0.64)\,\frac{62-1}{62-3-1} = 1 - 0.36 \times \frac{61}{58} = 1 - 0.3786 = 0.6214$$

Adjusted R² is always below R² (C) when $$k \ge 1$$. Check the df ratio: numerator $$n-1$$, denominator $$n-k-1$$.

**Q14 — A.** *(Medium.)*

$$t = \frac{0.85 - 1.00}{0.34} = -0.44$$

$$|{-0.44}| < 1.96$$, so the slope is statistically indistinguishable from 1 — fail to reject. Distractor B is the trap: $$t = 0.85/0.34 = 2.50$$ tests $$\beta = 0$$, which is **not** the hypothesis asked. Always test against the value stated in the question.

**Q15 — C.** *(Easy.)* Both conditions are required: the omitted variable must be a determinant of $$Y$$ **and** correlated with the included regressor. If it is uncorrelated with the regressor (B), its effect lands in the error term without biasing the slope.

**Q16 — C.** *(Easy.)* Heteroskedasticity leaves OLS coefficients unbiased and consistent but invalidates the conventional standard errors, so t-stats and p-values mislead. White (heteroskedasticity-robust) standard errors fix the inference; no robust SE ever changes the coefficient estimates (D).

**Q17 — D.** *(Easy.)* Long-run mean of an AR(1):

$$E[Y] = \frac{\delta}{1-\phi} = \frac{0.6}{1-0.7} = 2.00$$

Distractor B is the intercept alone; C divides by $$\phi$$; A divides by $$1+\phi$$.

**Q18 — C.** *(Medium.)*

$$\rho_1 = \frac{\theta}{1+\theta^2} = \frac{0.5}{1.25} = 0.40$$

Distractor D is the trap: $$\rho_1 \ne \theta$$. B divides by $$1+\theta$$. And remember $$\rho_h = 0$$ for $$h \ge 2$$ — the MA(1) ACF cuts off, it does not decay.

**Q19 — C.** *(Hard.)* Iterate the recursion:

$$E_t[Y_{t+1}] = 0.5 + 0.8 \times 4.0 = 3.70$$

$$E_t[Y_{t+2}] = 0.5 + 0.8 \times 3.70 = 3.46$$

Check via mean reversion: long-run mean $$= 0.5/0.2 = 2.5$$, and $$2.5 + 0.8^2(4.0 - 2.5) = 2.5 + 0.96 = 3.46$$. ✓ Distractor D stops after one step; A jumps all the way to the long-run mean; B incorrectly applies $$\phi^2$$ to $$Y_t$$ alone ($$0.5 + 0.64 \times 4.0 = 3.06$$).

**Q20 — C.** *(Easy.)* Random-walk variance scales linearly with horizon, so the standard deviation scales with $$\sqrt{h}$$:

$$\sigma_{25\text{-day}} = 2\% \times \sqrt{25} = 10\%$$

Distractor D multiplies σ by 25 (that scales **variance**, not volatility); A applies no scaling.

**Q21 — B.** *(Easy.)* $$r = \ln(110/100) = \ln(1.10) = 9.53\%$$. The log return is always below the simple return (C); D goes the wrong way ($$e^{0.10}-1$$).

**Q22 — C.** *(Medium.)* Work in variances:

$$\sigma_t^2 = 0.94 \times (0.010)^2 + 0.06 \times (0.020)^2 = 0.000094 + 0.000024 = 0.000118$$

$$\sigma_t = \sqrt{0.000118} = 1.086\% \approx 1.09\%$$

Distractor B averages the volatilities instead of the variances ($$0.94 \times 1\% + 0.06 \times 2\% = 1.06\%$$) — the classic EWMA error; A drops the return term.

**Q23 — B.** *(Easy.)*

$$SE = \frac{s}{\sqrt{N}} = \frac{4.00}{\sqrt{10{,}000}} = \frac{4.00}{100} = \$0.04$$

Distractor A divides by $$N$$; halving this SE would require $$4 \times 10{,}000 = 40{,}000$$ replications.

**Q24 — B.** *(Easy.)* The L1 (absolute value) penalty in LASSO produces corner solutions that zero out coefficients — built-in variable selection. Ridge's L2 (squared) penalty shrinks smoothly toward but never exactly to zero. A and C swap the methods; D reverses the bias-variance effect of $$\lambda$$ (more penalty = more bias, less variance).

**Q25 — B.** *(Medium.)*

$$\text{Precision} = \frac{40}{40+10} = 0.80 \qquad \text{Recall} = \frac{40}{40+20} = 0.667$$

$$F_1 = \frac{2 \times 0.80 \times 0.667}{0.80 + 0.667} = \frac{1.067}{1.467} = 0.73$$

Distractor C is precision alone, A is recall alone, and D is accuracy ($$170/200 = 0.85$$) — which looks flattering only because the classes are imbalanced.
