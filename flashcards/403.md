**Q1.** Three ways empirical daily returns deviate from normality.
> **A:** Fat tails (leptokurtosis), negative skew (equity crashes bigger than rallies), and volatility clustering (big moves follow big moves).

**Q2.** How can returns be conditionally normal yet unconditionally fat-tailed?
> **A:** Mixing normals with different variances (time-varying volatility / regime switching) produces excess kurtosis. Tracking conditional σ makes standardized returns look near-normal.

**Q3.** Equal-weight historical volatility formula and its main drawback.
> **A:** $$\hat\sigma_n^2 = \frac{1}{m}\sum_{i=1}^m r_{n-i}^2$$. Drawback: every observation gets equal weight 1/m, causing "ghosting" — σ jumps and persists until a big return drops out of the window.

**Q4.** State the EWMA variance update.
> **A:** $$\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$$. RiskMetrics uses λ = 0.94 for daily data.

**Q5.** How does the decay factor λ affect EWMA behavior?
> **A:** Higher λ → slower reaction, longer memory; lower λ → fast reaction, noisy. Weight on the squared return i days ago is $$(1-\lambda)\lambda^{i-1}$$. No mean reversion.

**Q6.** EWMA update: λ = 0.94, prior σ = 1.2%, latest return = −2%.
> **A:** $$\sigma_n^2 = 0.94(0.012)^2 + 0.06(0.02)^2 = 0.00015936$$ → σ = 1.262%. Work in variances, not σ.

**Q7.** State the GARCH(1,1) variance update.
> **A:** $$\sigma_n^2 = \omega + \alpha\,r_{n-1}^2 + \beta\,\sigma_{n-1}^2$$, with α + β < 1 for stationarity. α multiplies the return, β the prior variance.

**Q8.** GARCH(1,1) long-run (unconditional) variance.
> **A:** $$V_L = \frac{\omega}{1-\alpha-\beta}$$. Equivalently ω = γV_L with γ + α + β = 1. Forecasts revert to V_L at rate (α+β).

**Q9.** Compute long-run volatility: ω = 0.000003, α = 0.04, β = 0.94.
> **A:** $$V_L = \frac{0.000003}{1-0.98}=0.00015$$ → $$\sigma_L=\sqrt{0.00015}=1.225\%$$.

**Q10.** Relate EWMA to GARCH(1,1).
> **A:** EWMA is GARCH(1,1) with ω = 0, α = 1−λ, β = λ. So EWMA has no mean reversion; GARCH adds reversion to a long-run variance.

**Q11.** What is implied volatility and how does it differ from statistical estimates?
> **A:** The σ backed out by inverting BSM from observed option prices — forward-looking (market consensus over the option's life), versus backward-looking historical/EWMA/GARCH estimates. VIX is model-free 30-day S&P implied vol.

**Q12.** What is the volatility smile/skew?
> **A:** Implied vol varies with strike (equity index puts trade at higher implied vol — crash protection premium), violating BSM's constant-σ assumption. Term structure = variation with maturity.

**Q13.** EWMA covariance update and a key consistency rule.
> **A:** $$\text{cov}_n = \lambda\,\text{cov}_{n-1} + (1-\lambda)\,x_{n-1}y_{n-1}$$, then $$\rho_n = \text{cov}_n/(\sigma_{x,n}\sigma_{y,n})$$. Use the same λ for variances and covariances to keep the matrix positive semi-definite.
