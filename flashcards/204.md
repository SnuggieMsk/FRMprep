**Q1.** From a bivariate probability matrix, how do you get a marginal and a conditional distribution?
> **A:** Marginal: sum across the other variable, $$f_X(x) = \sum_y f(x,y)$$. Conditional: $$f_{Y\mid X}(y\mid x) = \dfrac{f(x,y)}{f_X(x)}$$.

**Q2.** How do you check independence from a probability matrix?
> **A:** $$f(x,y) = f_X(x)f_Y(y)$$ must hold for EVERY cell. One failing cell kills independence.

**Q3.** Give the covariance formula and its relationship to correlation.
> **A:** $$\mathrm{Cov}(X,Y) = E[XY] - E[X]E[Y]$$; $$\rho_{XY} = \dfrac{\mathrm{Cov}(X,Y)}{\sigma_X\sigma_Y}$$, with $$-1 \le \rho \le 1$$.

**Q4.** Does independence imply zero covariance? Does zero covariance imply independence?
> **A:** Independence ⇒ zero covariance always. Zero covariance does NOT imply independence in general (it only rules out linear dependence). Exception: jointly normal variables — zero correlation does imply independence.

**Q5.** Give an example where $$\rho = 0$$ but the variables are perfectly dependent.
> **A:** $$Y = X^2$$ with symmetric $$X$$: $$\rho = 0$$ yet $$Y$$ is fully determined by $$X$$. "Uncorrelated" means no LINEAR relationship.

**Q6.** How do linear transformations affect covariance and correlation?
> **A:** $$\mathrm{Cov}(aX+b, cY+d) = ac\,\mathrm{Cov}(X,Y)$$; $$\rho(aX+b, cY+d) = \mathrm{sign}(ac)\,\rho(X,Y)$$ — magnitude unchanged, sign can flip.

**Q7.** Give the variance of a weighted sum $$aX + bY$$.
> **A:** $$\mathrm{Var}(aX+bY) = a^2\sigma_X^2 + b^2\sigma_Y^2 + 2ab\,\mathrm{Cov}(X,Y)$$, with $$\mathrm{Cov}(X,Y) = \rho\sigma_X\sigma_Y$$.

**Q8.** Two-asset portfolio: $$\sigma_A = 20\%$$, $$\sigma_B = 12\%$$, $$\rho = 0.3$$, weights 60/40. Find $$\sigma_P$$.
> **A:** $$\sigma_P^2 = 0.36(0.04) + 0.16(0.0144) + 2(0.6)(0.4)(0.0072) = 0.02016$$, so $$\sigma_P = 14.20\%$$ (below the 16.8% weighted average — diversification).

**Q9.** For iid $$X_1,\dots,X_n$$ with mean $$\mu$$ and variance $$\sigma^2$$, give the mean, variance, and standard deviation of the sum.
> **A:** $$E[\sum X_i] = n\mu$$, $$\mathrm{Var}(\sum X_i) = n\sigma^2$$, $$\sigma_{\text{sum}} = \sigma\sqrt{n}$$ — the source of square-root-of-time scaling.

**Q10.** When does the $$\sqrt{t}$$ volatility scaling rule break?
> **A:** It requires iid returns (zero autocorrelation, constant variance). Positive autocorrelation makes true risk exceed $$\sigma\sqrt{t}$$; mean reversion makes it lower.

**Q11.** $$\sigma_X = 5$$, $$\sigma_Y = 8$$, $$\rho = -0.25$$. Find $$\mathrm{Var}(X+Y)$$.
> **A:** $$\mathrm{Cov} = -0.25(5)(8) = -10$$; $$\mathrm{Var} = 25 + 64 + 2(-10) = 69$$.

**Q12.** Daily returns are iid with daily variance 0.0004. Find the 25-day return standard deviation.
> **A:** $$\sigma_d = 0.02$$; $$\sigma_{25} = 0.02\sqrt{25} = 0.10$$.

**Q13.** Define the conditional expectation $$E[Y \mid X = x]$$ for a discrete bivariate.
> **A:** $$E[Y \mid X = x] = \sum_y y\, f_{Y\mid X}(y \mid x)$$.
