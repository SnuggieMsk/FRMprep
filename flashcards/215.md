**Q1.** Give the logistic regression probability and log-odds forms.
> **A:** $$P(Y=1\mid X) = \dfrac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots)}}$$; equivalently $$\ln\dfrac{p}{1-p} = \beta_0 + \beta_1 X_1 + \cdots$$. Estimated by maximum likelihood, not OLS.

**Q2.** Why use logistic regression instead of linear regression for a 0/1 outcome?
> **A:** Plain linear regression can predict probabilities below 0 or above 1 and forces constant marginal effects; the sigmoid keeps predictions in $$(0,1)$$ with varying marginal effects.

**Q3.** How does a decision tree choose splits?
> **A:** Recursively splits the feature space with binary questions, choosing the split that best purifies child nodes — minimizing Gini impurity $$\sum_k p_k(1-p_k)$$ or entropy $$-\sum_k p_k\ln p_k$$ (classification), or MSE (regression).

**Q4.** Distinguish bagging, random forests, and boosting.
> **A:** Bagging: train trees on bootstrap resamples, average/vote. Random forest: bagging plus a random feature subset at each split (decorrelates trees). Boosting: build shallow trees sequentially, each fitting the previous ensemble's errors (reduces bias too, can overfit if run too long).

**Q5.** Describe K-nearest neighbors and the effect of $$K$$.
> **A:** Classify by majority vote of the $$K$$ closest training points (standardized, Euclidean); "lazy" — no training phase. Small $$K$$ = flexible/high variance; large $$K$$ = smooth/high bias. Costly at prediction; struggles in high dimensions.

**Q6.** What does an SVM optimize, and what is the kernel trick?
> **A:** SVM maximizes the margin to the nearest training points (support vectors). Soft-margin tolerates misclassification via a cost parameter; the kernel trick builds nonlinear boundaries by implicitly mapping to higher dimensions.

**Q7.** Describe a neural network neuron and how networks are trained.
> **A:** Each neuron computes $$a = g(w^\top x + b)$$ with a nonlinear activation (sigmoid, tanh, ReLU $$=\max(0,z)$$). Trained by minimizing a loss via gradient descent, with gradients from backpropagation; the learning rate sets step size.

**Q8.** Lay out the confusion matrix and define accuracy and precision.
> **A:** Rows = actual ($$+$$: TP/FN; $$-$$: FP/TN). $$\text{Accuracy} = \dfrac{TP+TN}{TP+TN+FP+FN}$$; $$\text{Precision} = \dfrac{TP}{TP+FP}$$.

**Q9.** Define recall and the F1 score.
> **A:** $$\text{Recall} = \dfrac{TP}{TP+FN}$$; $$F_1 = \dfrac{2\cdot\text{Precision}\cdot\text{Recall}}{\text{Precision}+\text{Recall}}$$.

**Q10.** What are the ROC curve and AUC?
> **A:** ROC: true-positive rate vs. false-positive rate as the threshold sweeps. AUC: probability a random positive is scored above a random negative — 1.0 perfect, 0.5 coin flip.

**Q11.** Why is accuracy misleading with imbalanced classes?
> **A:** If 2% default, "always predict no default" scores 98% accuracy with zero recall. Use precision/recall, F1, and AUC; lowering the threshold raises recall at the cost of precision.

**Q12.** Logistic PD model: $$\ln\dfrac{p}{1-p} = -4 + 0.8\times\text{leverage}$$. Find $$p$$ at leverage = 5.
> **A:** $$z = -4 + 0.8(5) = 0$$; $$p = \dfrac{1}{1+e^0} = 0.50$$.

**Q13.** Model: TP = 30, FN = 20, FP = 70, TN = 880. Compute precision, recall, and F1.
> **A:** Precision $$= 30/100 = 30\%$$; recall $$= 30/50 = 60\%$$; $$F_1 = \dfrac{2(0.30)(0.60)}{0.90} = 0.40$$.

**Q14.** Describe reinforcement learning's core elements.
> **A:** An agent observes a state, takes an action, receives a reward, and learns a policy maximizing cumulative discounted reward — balancing exploration vs. exploitation. Q-learning values state–action pairs. Uses: trade execution, dynamic hedging, market making.
