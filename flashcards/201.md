**Q1.** Define mutually exclusive events and give the key probability identity.
> **A:** Events that cannot occur together: $$P(A \cap B) = 0$$, so $$P(A \cup B) = P(A) + P(B)$$.

**Q2.** Define independent events.
> **A:** Events that do not inform each other: $$P(A \cap B) = P(A)P(B)$$, equivalently $$P(A \mid B) = P(A)$$.

**Q3.** Why are mutually exclusive events (with positive probability) NOT independent?
> **A:** If $$A$$ occurs, $$B$$ cannot, so knowing $$A$$ changes $$B$$'s probability to 0 — they are strongly dependent, nearly the opposite of independent.

**Q4.** State the addition rule for any two events.
> **A:** $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$

**Q5.** Define conditional probability.
> **A:** $$P(A \mid B) = \dfrac{P(A \cap B)}{P(B)}, \quad P(B) > 0$$

**Q6.** State the multiplication rule.
> **A:** $$P(A \cap B) = P(A \mid B)\,P(B) = P(B \mid A)\,P(A)$$

**Q7.** State the total probability rule for a partition $$B_1,\dots,B_n$$.
> **A:** $$P(A) = \sum_{i=1}^{n} P(A \mid B_i)\,P(B_i)$$

**Q8.** State Bayes' theorem.
> **A:** $$P(B_j \mid A) = \dfrac{P(A \mid B_j)\,P(B_j)}{\sum_i P(A \mid B_i)\,P(B_i)}$$ — the denominator is the total probability rule.

**Q9.** What is the difference between an unconditional (marginal) and a conditional probability?
> **A:** $$P(A)$$ uses no extra information; $$P(A \mid B)$$ restricts the sample space to outcomes where $$B$$ occurred (e.g., default rate vs. default rate given recession).

**Q10.** Default probability is 1% in expansion, 8% in recession; recession probability is 25%. What is the unconditional default probability?
> **A:** $$P(D) = 0.08(0.25) + 0.01(0.75) = 0.0275 = 2.75\%$$

**Q11.** Does conditional independence imply unconditional independence?
> **A:** No. Two bonds may default independently given the economy yet be unconditionally correlated because both depend on that common state.

**Q12.** A test flags 90% of rogue traders and 5% of honest ones; 1% are rogue. P(rogue | flagged)?
> **A:** $$\dfrac{0.90 \times 0.01}{0.90(0.01) + 0.05(0.99)} = \dfrac{0.009}{0.0585} = 15.4\%$$

**Q13.** Quick check: how do you verify independence from probabilities?
> **A:** Test whether $$P(A \cap B) = P(A)P(B)$$. If it holds the events are independent (and therefore not mutually exclusive).
