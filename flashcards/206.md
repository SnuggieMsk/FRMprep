**Q1.** What must the null hypothesis always contain, and can a test "accept" $$H_0$$?
> **A:** $$H_0$$ always contains the equality (e.g., $$\mu = \mu_0$$). A test can only reject or fail to reject $$H_0$$ — never "accept" it.

**Q2.** Compare one-tailed and two-tailed 5% critical values, and how wording selects the test.
> **A:** Two-tailed 5%: 1.96; one-tailed 5%: 1.645. "Differs from" ⇒ two-tailed; "exceeds/less than" ⇒ one-tailed. A statistic of 1.80 rejects one-sided but not two-sided.

**Q3.** Give the z- and t-statistics for testing a population mean.
> **A:** Known variance/large $$n$$: $$z = \dfrac{\bar X - \mu_0}{\sigma/\sqrt{n}}$$. Unknown variance/small $$n$$: $$t = \dfrac{\bar X - \mu_0}{s/\sqrt{n}}$$ with $$n-1$$ d.o.f.

**Q4.** Define Type I and Type II errors and relate them to size and power.
> **A:** Type I: reject a true $$H_0$$ (prob $$\alpha$$ = size). Type II: fail to reject a false $$H_0$$ (prob $$\beta$$). Power $$= 1 - \beta$$.

**Q5.** What raises the power of a test, and what is the trade-off at fixed $$n$$?
> **A:** Power rises with larger sample size, larger true deviation from $$H_0$$, and larger $$\alpha$$. At fixed $$n$$, decreasing $$\alpha$$ increases $$\beta$$ — only more data is a free lunch.

**Q6.** Define a p-value and the reject rule. What is it NOT?
> **A:** Probability, assuming $$H_0$$ true, of a statistic at least as extreme as observed; reject when p-value $$< \alpha$$. It is NOT the probability that $$H_0$$ is true.

**Q7.** State the duality between a two-sided test and a confidence interval.
> **A:** A size-$$\alpha$$ test rejects $$H_0: \mu = \mu_0$$ exactly when $$\mu_0$$ lies outside the $$(1-\alpha)$$ CI. The CI is the set of all nulls not rejected.

**Q8.** A strategy's 25 monthly returns average 0.80% with $$s = 2.0\%$$. Test $$H_0: \mu = 0$$ two-sided at 5% ($$t_{0.025,24} = 2.064$$).
> **A:** $$t = \dfrac{0.80}{2.0/\sqrt{25}} = \dfrac{0.80}{0.40} = 2.00 < 2.064$$ → fail to reject. (One-sided $$t_{0.05,24} = 1.711$$ would reject — the tail choice flips the answer.)

**Q9.** A sample of 36 returns has mean 1.2% and SD 3.6%. Compute the t-statistic for $$H_0: \mu = 0$$.
> **A:** $$t = \dfrac{1.2}{3.6/\sqrt{36}} = \dfrac{1.2}{0.6} = 2.0$$.

**Q10.** Give the two-sample z-statistic for a difference of means (independent, large $$n$$).
> **A:** $$z = \dfrac{(\bar X_1 - \bar X_2) - (\mu_1 - \mu_2)_0}{\sqrt{s_1^2/n_1 + s_2^2/n_2}}$$. For paired data, test the mean of the differences instead.

**Q11.** What is the multiple-testing problem, and what is the Bonferroni fix?
> **A:** With $$k$$ independent true nulls, $$P(\text{at least one rejection}) = 1 - (1-\alpha)^k$$ (e.g., $$k=10$$, 5% → 40.1%). Bonferroni: test each at $$\alpha/k$$.

**Q12.** A 95% CI for a regression coefficient is $$(0.4, 2.6)$$. Does a two-sided 5% test of $$H_0: \beta = 0$$ reject?
> **A:** Yes — by duality, 0 lies outside the 95% CI, so reject at 5%.

**Q13.** Returns $$N(\mu, 2^2)$$, $$n = 16$$ so $$SE = 0.5$$; one-sided 5% test of $$H_0:\mu=0$$ rejects when $$\bar X > 0.8225$$. If true $$\mu = 1$$, find power.
> **A:** Power $$= P(Z > \tfrac{0.8225 - 1}{0.5}) = P(Z > -0.355) = 0.639$$, so $$\beta \approx 36.1\%$$.

**Q14.** A VaR model expects 1% exceptions; over 500 days you see 9 ($$\hat p = 0.018$$). Test $$H_0: p = 0.01$$ two-sided at 5%.
> **A:** $$SE = \sqrt{0.01(0.99)/500} = 0.00445$$; $$z = \dfrac{0.008}{0.00445} = 1.80$$; p-value $$\approx 0.072 > 0.05$$ → fail to reject.
