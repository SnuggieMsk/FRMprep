**Q1.** A stock price falls from \$50 to \$45 in one day. The continuously compounded (log) return is closest to:
- A. $$-10.00\%$$
- B. $$-10.54\%$$
- C. $$-9.53\%$$
- D. $$-11.11\%$$

**Answer: B**

The question asks for the log (continuously compounded) return, not the simple return.

The log-return formula is:
$$r = \ln\!\left(\frac{P_t}{P_{t-1}}\right) = \ln\!\left(\frac{45}{50}\right) = \ln(0.90)$$

Now compute $$\ln(0.90)$$:
$$\ln(0.90) = -0.10536 = -10.54\%$$

So the answer is B.

Why the others are wrong:
- A. $$-10.00\%$$ is the simple return: $$(45-50)/50 = -0.10$$. The question specifically asked for the log return.
- C. $$-9.53\%$$ would be $$\ln(50/45) \times (-1)$$ done incorrectly, or a sign/ratio mix-up. The base is the OLD price (50), not the new one.
- D. $$-11.11\%$$ is $$(45-50)/45$$ — dividing by the wrong (new) price.

Log returns are always slightly more negative than simple returns for a price drop, because $$\ln(1+R)$$ is a bit below $$R$$ when $$R$$ is negative.

📌 Exam tip: Log return $$= \ln(P_t/P_{t-1})$$, always using the starting price as the base. For a loss, the log return is more negative than the simple return.

**Q2.** Which statement correctly contrasts simple and log returns?
- A. Log returns aggregate correctly across assets in a portfolio.
- B. Simple returns add up across time periods.
- C. Log returns add up across time periods, while simple returns aggregate correctly across assets.
- D. Both add across time and across assets identically.

**Answer: C**

The question asks which type of return is convenient for adding across time versus combining across assets.

Two key facts:
- Log returns add across time: the multi-period log return is the sum of the single-period log returns, $$r_{0,T} = \sum_t r_t$$. This makes them ideal for time aggregation.
- Simple returns aggregate across assets: a portfolio's simple return is the weighted average of the components' simple returns. This is not true for log returns.

So C states both facts correctly.

Why the others are wrong:
- A. It is simple returns (not log returns) that aggregate cleanly across assets in a portfolio.
- B. It is log returns (not simple returns) that add across time.
- D. The two return types behave differently; they do not aggregate identically.

Think of log returns as good for "stacking days end-to-end" and simple returns as good for "blending assets in a basket."

📌 Exam tip: Memorize the split — Log returns: add over TIME. Simple returns: add over ASSETS (portfolios). Picking the wrong one is a classic trap.

**Q3.** A stock has a daily return volatility of 1.5%. Assuming returns are independent and identically distributed with 252 trading days per year, the annualized volatility is closest to:
- A. 23.8%
- B. 18.0%
- C. 1.5%
- D. 378%

**Answer: A**

The question asks you to annualize a daily volatility using the square-root-of-time rule.

Under iid returns, variance scales with time, so volatility (standard deviation) scales with the square root of time:
$$\sigma_{\text{annual}} = \sigma_{\text{daily}} \times \sqrt{252}$$

First find $$\sqrt{252} \approx 15.87$$. Then:
$$\sigma_{\text{annual}} = 1.5\% \times 15.87 = 23.8\%$$

So the answer is A.

Why the others are wrong:
- B. 18.0% comes from multiplying by $$\sqrt{144} = 12$$ (treating it like monthly-to-annual scaling). The wrong number of periods was used.
- C. 1.5% is just the daily figure left un-scaled.
- D. 378% comes from multiplying by 252 directly ($$1.5\% \times 252$$) instead of by $$\sqrt{252}$$ — scaling variance like volatility.

Remember: you scale volatility by the square root of the time factor, never by the time factor itself.

📌 Exam tip: $$\sigma_{\text{annual}} = \sigma_{\text{daily}}\sqrt{252}$$. The classic error is multiplying by 252 (that scales variance, not volatility).

**Q4.** The square-root-of-time rule for scaling volatility relies on which key assumption?
- A. Returns are positively autocorrelated.
- B. Returns are independent and identically distributed (iid).
- C. Volatility clusters strongly over time.
- D. Returns mean-revert toward a long-run average.

**Answer: B**

The question asks what condition must hold for the $$\sqrt{t}$$ rule to be valid.

The rule $$\sigma_T = \sigma_1\sqrt{T}$$ comes from variance adding up across periods, which requires the period returns to be uncorrelated and to have constant variance — that is, iid. The answer is B.

Why the others are wrong:
- A. Positive autocorrelation breaks the rule: shocks reinforce each other, so the rule understates true long-horizon risk.
- C. Volatility clustering (GARCH-style) also breaks the rule: scaling today's unusually high volatility by $$\sqrt{t}$$ ignores the eventual pull back toward the long-run level.
- D. Mean reversion breaks it the other way: it makes the rule overstate long-horizon risk because gains/losses tend to reverse.

It is like estimating how far a kid wanders if each step is truly random and independent: only then does the spread grow neatly with $$\sqrt{\text{steps}}$$. If steps are linked, the simple rule misleads.

📌 Exam tip: State the iid assumption before using $$\sqrt{t}$$. Positive autocorrelation → understates risk; mean reversion → overstates risk.

**Q5.** Using an EWMA model with $$\lambda = 0.94$$, yesterday's variance estimate was $$\sigma_{t-1}^2 = 0.0001$$ (i.e., $$\sigma_{t-1} = 1.0\%$$) and yesterday's return was $$r_{t-1} = 2.0\%$$. Today's variance estimate is closest to:
- A. 0.000118
- B. 0.000100
- C. 0.000400
- D. 0.000094

**Answer: A**

The question asks you to update a variance forecast one day forward using EWMA.

The EWMA updating formula is:
$$\sigma_t^2 = \lambda\,\sigma_{t-1}^2 + (1-\lambda)\,r_{t-1}^2$$

Plug in $$\lambda = 0.94$$, $$\sigma_{t-1}^2 = (0.01)^2 = 0.0001$$, and $$r_{t-1}^2 = (0.02)^2 = 0.0004$$:
$$\sigma_t^2 = 0.94 \times 0.0001 + 0.06 \times 0.0004$$

Compute each piece:
$$0.94 \times 0.0001 = 0.000094$$
$$0.06 \times 0.0004 = 0.000024$$

Add them:
$$\sigma_t^2 = 0.000094 + 0.000024 = 0.000118$$

So the answer is A.

Why the others are wrong:
- B. 0.000100 is just yesterday's variance unchanged — it ignores the big 2% return that should push the estimate up.
- C. 0.000400 is just yesterday's squared return — it ignores the heavy 0.94 weight on the prior variance.
- D. 0.000094 is only the first term ($$0.94 \times 0.0001$$); the $$(1-\lambda)r^2$$ piece was forgotten.

Think of EWMA as a running average where today's estimate is mostly the old estimate (94%) nudged by the newest squared return (6%).

📌 Exam tip: EWMA weights must sum to 1: $$\lambda + (1-\lambda)$$. Always square the return ($$r^2$$) before plugging it in.

**Q6.** A GARCH(1,1) model is $$\sigma_t^2 = \omega + \alpha r_{t-1}^2 + \beta\sigma_{t-1}^2$$ with $$\omega = 0.000003$$, $$\alpha = 0.08$$, and $$\beta = 0.90$$. The long-run (unconditional) daily volatility is closest to:
- A. 2.00%
- B. 0.015%
- C. 1.22%
- D. 0.55%

**Answer: C**

The question asks for the long-run volatility implied by a GARCH(1,1) model.

The long-run (unconditional) variance is:
$$\sigma_{LR}^2 = \frac{\omega}{1 - \alpha - \beta}$$

First compute the denominator:
$$1 - \alpha - \beta = 1 - 0.08 - 0.90 = 0.02$$

Then divide:
$$\sigma_{LR}^2 = \frac{0.000003}{0.02} = 0.00015$$

The long-run volatility is the square root:
$$\sigma_{LR} = \sqrt{0.00015} = 0.01225 = 1.22\%$$

So the answer is C.

Why the others are wrong:
- A. 2.00% would require $$\sigma_{LR}^2 = 0.0004$$, far larger than the correct 0.00015 — it comes from using the wrong $$\omega$$ or denominator.
- B. 0.015% confuses the variance value (0.00015) with a volatility — it forgets to take the square root and misreads the decimal.
- D. 0.55% would come from a much larger denominator (treating persistence differently).

📌 Exam tip: Long-run variance $$= \omega/(1-\alpha-\beta)$$; then take the square root to get volatility. Always finish with the square root.

**Q7.** In a GARCH(1,1) model the persistence is measured by $$\alpha + \beta$$. If the current volatility is far above the long-run level, multi-step forecasts of volatility will:
- A. Stay constant at the current level forever.
- B. Decay geometrically toward the long-run level at rate $$(\alpha + \beta)^h$$.
- C. Increase without bound.
- D. Jump immediately to the long-run level after one step.

**Answer: B**

The question asks how GARCH volatility forecasts behave over multiple steps when volatility starts high.

GARCH adds a pull toward the long-run variance $$\sigma_{LR}^2$$. When current volatility is above that level, forecasts gradually decline back toward it. The speed depends on persistence: the gap closes geometrically at rate $$(\alpha+\beta)^h$$ as the horizon $$h$$ grows. The answer is B.

Why the others are wrong:
- A. Staying constant forever describes EWMA (no mean reversion), the special case $$\alpha + \beta = 1$$, $$\omega = 0$$ — not a stationary GARCH where $$\alpha + \beta < 1$$.
- C. GARCH forecasts converge; they do not explode (that would require $$\alpha + \beta \ge 1$$).
- D. The reversion is gradual, not instantaneous. It takes many steps to close the gap when persistence is high.

Think of a cup of hot coffee (current high vol) cooling toward room temperature (long-run level): it does not drop to room temperature instantly — it eases down, faster or slower depending on insulation (persistence).

📌 Exam tip: GARCH mean-reverts toward $$\sigma_{LR}^2$$ at rate $$(\alpha+\beta)^h$$. High persistence (close to 1) = slow reversion. EWMA ($$\alpha+\beta=1$$) never reverts.

**Q8.** How does the EWMA model relate to GARCH(1,1)?
- A. EWMA is GARCH(1,1) with $$\omega = 0$$ and $$\alpha + \beta = 1$$, so it has no mean reversion.
- B. EWMA has more parameters than GARCH(1,1).
- C. EWMA weights all past squared returns equally.
- D. EWMA always reverts to the long-run variance faster than GARCH.

**Answer: A**

The question asks how EWMA fits inside the GARCH framework.

EWMA is a special, restricted case of GARCH(1,1). Setting $$\omega = 0$$, $$\alpha = 1-\lambda$$, and $$\beta = \lambda$$ gives:
$$\alpha + \beta = (1-\lambda) + \lambda = 1$$

With $$\omega = 0$$ and $$\alpha+\beta = 1$$, there is no long-run variance to pull toward, so EWMA has no mean reversion — its multi-step forecast is just today's variance. The answer is A.

Why the others are wrong:
- B. EWMA has FEWER parameters (just $$\lambda$$) than GARCH(1,1) (which has $$\omega, \alpha, \beta$$).
- C. EWMA weights past squared returns with geometrically DECLINING weights $$(1-\lambda)\lambda^k$$, not equally. (Equal weighting describes a simple moving average.)
- D. EWMA does not mean-revert at all, so it cannot revert "faster." Its forecast stays flat.

Think of EWMA as a "stripped-down" GARCH with the mean-reversion engine removed.

📌 Exam tip: EWMA = integrated GARCH ($$\omega=0$$, $$\alpha+\beta=1$$) → no mean reversion, flat long-horizon forecast. GARCH adds $$\omega$$ and pulls toward $$\sigma_{LR}^2$$.

**Q9.** Two variables are related by $$Y = X^3$$, a strictly increasing (monotonic) but nonlinear transformation. Which statement is correct?
- A. The Pearson correlation equals 1, but the Spearman correlation is below 1.
- B. The Spearman correlation equals 1, but the Pearson correlation is below 1.
- C. Both Pearson and Spearman correlations equal 1.
- D. Both correlations equal 0.

**Answer: B**

The question compares Pearson and Spearman (rank) correlation for a monotonic but nonlinear relationship.

Spearman correlation works on ranks. Because $$Y = X^3$$ is strictly increasing, the largest $$X$$ gives the largest $$Y$$, the second-largest gives the second-largest, and so on — the ranks line up perfectly. So Spearman $$= 1$$.

Pearson correlation measures linear association. Since $$X^3$$ is a curved (nonlinear) relationship, the points do not lie on a straight line, so Pearson is below 1. The answer is B.

Why the others are wrong:
- A. This reverses the two. Pearson is the one below 1 (because the relationship is curved), while Spearman is exactly 1 (because ranks are preserved).
- C. Pearson cannot be 1 unless the relationship is perfectly linear, which $$X^3$$ is not.
- D. The variables move together perfectly in rank order, so correlations are strongly positive, certainly not 0.

Think of ranks like finishing positions in a race: if a faster $$X$$ always means a higher $$Y$$, the finishing order is identical (Spearman = 1) even though the exact time gaps stretch unevenly (Pearson < 1).

📌 Exam tip: Rank measures (Spearman, Kendall) = 1 for ANY strictly increasing transform. Pearson = 1 only for a perfectly linear relationship.

**Q10.** What does the implied volatility of an option represent?
- A. A backward-looking estimate computed from historical returns.
- B. The volatility that makes a pricing model's value match the observed market option price — a forward-looking, market-implied figure.
- C. The realized standard deviation of the option's price over the past year.
- D. The volatility assumed by the EWMA model.

**Answer: B**

The question asks what implied volatility actually is.

Implied volatility is the value of $$\sigma$$ you must plug into an option pricing model (like Black–Scholes–Merton) so that the model's price equals the price observed in the market. Because it is backed out of current market prices, it reflects the market's forward-looking, risk-neutral expectation of future volatility. The answer is B.

Why the others are wrong:
- A. A backward-looking estimate from historical returns is historical (realized) volatility — the opposite of implied volatility.
- C. The realized standard deviation of past prices is again historical, not implied.
- D. EWMA produces a historical/statistical estimate from past returns, not a market-implied one.

Think of it like reverse-engineering: you see the option's market price (the "answer") and work backward to find the volatility (the "input") that produces it — telling you what volatility the market is pricing in.

📌 Exam tip: Implied vol = forward-looking, extracted from market prices. The variation across strikes (the volatility smile/skew) shows the market does not fully believe in lognormal returns.
