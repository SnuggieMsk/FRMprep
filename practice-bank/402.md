**Q1.** A trading desk holds $25 million in an equity index with a daily volatility of 1.6%. Using $z_{0.95} = 1.645$, the delta-normal 95% one-day VaR is closest to:
- A. $400,000
- B. $658,000
- C. $930,000
- D. $784,000

**Answer: B**

The question asks for a single-position delta-normal VaR.

Step 1 — dollar standard deviation:

$$\sigma_{\$} = 0.016 \times \$25{,}000{,}000 = \$400{,}000$$

Step 2 — multiply by the 95% z-score:

$$\text{VaR}_{0.95} = 1.645 \times \$400{,}000 = \$658{,}000$$

So B is correct.

- A ($400,000) is just the dollar standard deviation, with no z-multiplier.
- C ($930,000) uses $z = 2.326$ (the 99% multiplier) instead of 1.645.
- D ($784,000) uses $z = 1.96$ (a two-sided value), not the one-tailed 95% multiplier.

Two clean steps: turn the percent into dollars, then stretch by the confidence multiplier.

📌 Exam tip: Delta-normal VaR for one position = z × (value × volatility). Use 1.645 for 95% and 2.326 for 99%.

**Q2.** A portfolio holds $60M in asset 1 (daily σ = 2%) and $40M in asset 2 (daily σ = 1%), with a correlation of 0.3. The portfolio's dollar standard deviation is closest to:
- A. $1.60M
- B. $1.37M
- C. $1.26M
- D. $2.00M

**Answer: B**

The question asks you to combine two positions using volatilities and correlation.

Step 1 — dollar standard deviations of each:

$$\sigma_1 = 0.02 \times \$60\text{M} = \$1.2\text{M}, \qquad \sigma_2 = 0.01 \times \$40\text{M} = \$0.4\text{M}$$

Step 2 — combine with the two-asset formula:

$$\sigma_P = \sqrt{\sigma_1^2 + \sigma_2^2 + 2\rho\,\sigma_1\sigma_2}$$

$$= \sqrt{1.2^2 + 0.4^2 + 2(0.3)(1.2)(0.4)}$$

$$= \sqrt{1.44 + 0.16 + 0.288} = \sqrt{1.888} = \$1.374\text{M}$$

So B is correct.

- A ($1.60M) just adds the two dollar σs (1.2 + 0.4) — that would be the case only if correlation were 1.
- C ($1.26M) wrongly subtracts the cross term, as if correlation were negative.
- D ($2.00M) ignores the formula entirely.

Analogy: combining two risks isn't simple addition unless they move in perfect lockstep. With only partial correlation, they partly cancel, so the combined risk is less than the sum.

📌 Exam tip: With $0 \le \rho < 1$, portfolio σ is strictly less than the sum of the σs — that gap is the diversification benefit.

**Q3.** Using the portfolio from the previous question ($\sigma_P = \$1.374$M), the diversification benefit at 99% VaR (using $z = 2.326$) compared with the undiversified VaR is closest to:
- A. $0
- B. $0.526M
- C. $1.20M
- D. $3.20M

**Answer: B**

The question asks for the dollar reduction in VaR from diversification.

Diversified VaR uses the combined σ:

$$\text{VaR}_{\text{div}} = 2.326 \times 1.374 = \$3.196\text{M}$$

Undiversified VaR adds the individual VaRs (treats them as perfectly correlated):

$$\text{VaR}_{\text{undiv}} = 2.326 \times (1.2 + 0.4) = 2.326 \times 1.6 = \$3.722\text{M}$$

Diversification benefit = the difference:

$$3.722 - 3.196 = \$0.526\text{M}$$

So B is correct.

- A ($0) would only hold if correlation were 1 (no benefit).
- C ($1.20M) is asset 1's dollar σ, unrelated to the benefit.
- D ($3.20M) is the diversified VaR itself, not the benefit.

Analogy: combining the desks saves about half a million in "risk capital" because they don't always lose money on the same day.

📌 Exam tip: Diversification benefit = (sum of individual VaRs) − (portfolio VaR). It is zero when ρ = 1 and grows as ρ falls.

**Q4.** From 500 daily losses generated by historical simulation, the 99% one-day VaR is best estimated by the:
- A. Single worst loss
- B. 5th worst loss
- C. 10th worst loss
- D. Average of all 500 losses

**Answer: B**

The question tests the rank used in historical-simulation VaR.

Sort the simulated losses from worst to best. The VaR rank is $n \times (1 - \alpha)$:

$$500 \times (1 - 0.99) = 500 \times 0.01 = 5$$

So the 99% VaR is the 5th worst loss. B is correct.

- A (worst loss) corresponds to a far higher confidence than 99% with this sample.
- C (10th worst) would be the 98% VaR ($500 \times 0.02 = 10$), not 99%.
- D (average of all losses) is roughly the mean loss, not a tail quantile.

Analogy: line up the 500 days from most painful to least painful. At 99% confidence you accept that the worst 1% (5 days) can breach the wall, so the wall sits at the 5th worst day.

📌 Exam tip: Historical-sim VaR rank = n × (1 − α). For ES, average the worst n × (1 − α) losses.

**Q5.** A historical simulation produces 100 daily losses; the six worst (in $ thousands) are 1,420; 1,180; 990; 870; 760; 700. The 95% expected shortfall is closest to:
- A. $760K
- B. $1,044K
- C. $700K
- D. $920K

**Answer: B**

The question asks for ES under historical simulation.

Step 1 — find how many losses make up the tail:

$$n \times (1 - \alpha) = 100 \times 0.05 = 5$$

So the 5% tail is the worst 5 losses.

Step 2 — ES is the average of those worst 5 losses:

$$\text{ES}_{0.95} = \frac{1{,}420 + 1{,}180 + 990 + 870 + 760}{5} = \frac{5{,}220}{5} = \$1{,}044\text{K}$$

So B is correct.

- A ($760K) is the 5th worst loss — that is the VaR, not the ES.
- C ($700K) is the 6th worst loss, outside the 5% tail.
- D ($920K) wrongly averages a different set of numbers (e.g., includes the 6th loss).

Analogy: VaR is where the tail "begins" (the 5th worst day); ES is the average pain across all the days in that tail.

📌 Exam tip: Historical-sim ES = average of the worst n × (1 − α) losses. It always comes out larger than the VaR (the cutoff loss).

**Q6.** A one-day 99% VaR is $2 million. Assuming i.i.d. returns with zero mean, the 25-day 99% VaR under the square-root-of-time rule is closest to:
- A. $50M
- B. $10M
- C. $31.6M
- D. $4M

**Answer: B**

The question tests time-scaling of VaR.

Under the square-root rule:

$$\text{VaR}_{T\text{-day}} = \text{VaR}_{1\text{-day}} \times \sqrt{T}$$

Plug in $T = 25$:

$$\$2\text{M} \times \sqrt{25} = \$2\text{M} \times 5 = \$10\text{M}$$

So B is correct.

- A ($50M) multiplies by 25 (i.e., by T, not √T) — the single most common trap.
- C ($31.6M) multiplies by $\sqrt{250}$ or similar, the wrong horizon.
- D ($4M) multiplies by 2, mis-reading √25 = 5 as 2.

Analogy: risk grows with the square root of time, not time itself — like how a random walk drifts away in proportion to √(steps), not steps.

📌 Exam tip: Scale VaR by √T, never by T. The "multiply by T" answer is always offered as a distractor.

**Q7.** Which limitation makes the delta-normal method least suitable for a portfolio dominated by options?
- A. It is too slow to compute
- B. It requires too much historical data
- C. It linearizes payoffs and ignores convexity (gamma), misrepresenting non-linear P&L
- D. It cannot use correlations

**Answer: C**

The question asks why delta-normal struggles with options.

The delta-normal method maps each position to a linear (delta-based) exposure and assumes the resulting P&L is normal. Options have curved (convex) payoffs: their value does not change proportionally with the underlying. By using only delta and ignoring gamma, the method misstates option risk and the skewed P&L for large moves. C is correct.

- A is false — delta-normal is the fastest method.
- B is false — it needs volatilities and correlations, not long histories like historical simulation.
- D is false — handling correlations is actually a strength of delta-normal.

Analogy: approximating a curved road with a straight ruler works for a short stretch (small moves) but fails badly over a long, winding section (large moves) — that's gamma the ruler misses.

📌 Exam tip: For options/non-linear books, prefer full revaluation (historical sim or Monte Carlo). Delta-normal's weakness is linearization, not speed.

**Q8.** Which statement about Monte Carlo simulation for VaR is most accurate?
- A. It makes no distributional assumptions at all
- B. It is the fastest of the three methods
- C. It can handle any instrument and distribution but is computationally heavy and exposed to model risk
- D. It is limited by the length of the historical data window

**Answer: C**

The question asks for the correct characterization of Monte Carlo.

Monte Carlo specifies stochastic processes for the risk factors, simulates many paths, fully revalues the portfolio on each, and reads VaR/ES off the simulated distribution. It is the most flexible method — any instrument, any distribution, any horizon — but it is slow and only as good as the assumed model ("garbage in, garbage out"). C is correct.

- A is wrong: you must specify a distribution/process — that is an assumption.
- B is wrong: Monte Carlo is the slowest, not the fastest (delta-normal is fastest).
- D describes historical simulation, which is limited by its data window; Monte Carlo is not.

Analogy: Monte Carlo is like a flight simulator — it can model any scenario you program, but the results are only trustworthy if the underlying physics (your model) is right.

📌 Exam tip: Monte Carlo = most flexible, slowest, biggest model risk. Historical sim's main weakness is an unrepresentative window; delta-normal's is thin tails.

**Q9.** Over 250 trading days, a bank backtests its 99% one-day VaR model. The expected number of exceptions (days the loss exceeds VaR) is closest to:
- A. 0.25
- B. 2.5
- C. 25
- D. 12.5

**Answer: B**

The question asks for the expected number of VaR breaches in backtesting.

The expected number of exceptions is the sample size times the tail probability:

$$\text{Expected exceptions} = n \times (1 - \alpha) = 250 \times (1 - 0.99) = 250 \times 0.01 = 2.5$$

So B is correct.

- A (0.25) uses $1 - \alpha = 0.001$ — off by a factor of ten.
- C (25) uses $1 - \alpha = 0.10$ (a 90% model), the wrong confidence.
- D (12.5) uses $1 - \alpha = 0.05$ (a 95% model), not the 99% stated.

Analogy: if the wall is built so floods should top it 1 day in 100, then over 250 days you'd expect floods to top it about 2.5 times.

📌 Exam tip: Expected exceptions = n × (1 − α). Far too many breaches → model understates risk; far too few → overly conservative (wasted capital).

**Q10.** Why is backtesting a 99% VaR model statistically harder than backtesting a 95% VaR model over the same period?
- A. The 99% model produces more exceptions, creating noise
- B. Exceptions at 99% are rare, giving low statistical power to detect a bad model
- C. The square-root rule does not apply at 99%
- D. The 99% model is always more accurate, so no testing is needed

**Answer: B**

The question asks about the statistical-power problem at high confidence levels.

At 99%, exceptions are expected only about 1% of the time, so over a typical sample you observe very few breaches (e.g., 2.5 in 250 days). With so few data points, it is hard to tell a good model from a bad one quickly — this is low statistical power. Testing at 95% produces more expected exceptions and thus more information. B is correct.

- A is backwards: the 99% model produces fewer exceptions, not more.
- C is irrelevant — the square-root rule is about scaling horizons, not about backtest power.
- D is wrong: a higher confidence level does not make a model more accurate, and all models still require testing.

Analogy: trying to judge a rare-event predictor (like "earthquakes this big") is hard precisely because the events almost never happen — you can't gather enough cases to grade it.

📌 Exam tip: Higher confidence → rarer exceptions → lower backtest power. Also check exception independence; clustered breaches signal missed volatility dynamics even if the count looks fine.
