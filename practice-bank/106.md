**Q1.** Relative to the CAPM, the arbitrage pricing theory (APT) does NOT require:
- A. A linear relation between expected return and factor betas
- B. That all investors hold the market portfolio under homogeneous expectations
- C. The absence of arbitrage opportunities
- D. A factor structure for returns

**Answer: B**

The question asks what APT manages to *avoid* assuming. APT is built on no-arbitrage logic, not equilibrium: it only needs a factor structure, enough assets to diversify, and the absence of arbitrage. It does NOT require everyone to hold the market portfolio or to share homogeneous expectations — those are CAPM's heavy assumptions.

Think of APT like a referee enforcing "no free lunches": you only need a few sharp traders to pounce on mispricing, not every investor behaving identically.

- A is wrong (as the answer): APT *does* require linear pricing in factor betas — that's its conclusion.
- C is wrong (as the answer): no-arbitrage IS the central APT assumption.
- D is wrong (as the answer): a factor structure for returns IS required by APT.

📌 Exam tip: APT drops CAPM's market-portfolio and homogeneous-expectations machinery. It keeps: factor structure, diversification, no arbitrage, and linear pricing. The price of this generality is that APT won't tell you *what* the factors are.

**Q2.** Expected inflation was 3%, and actual inflation also prints 3%. A stock has an inflation factor beta of −1.2. Under a factor model, the effect of this inflation announcement on the stock's return is:
- A. −3.6%
- B. +3.6%
- C. 0%
- D. −1.2%

**Answer: C**

The question tests the most important idea in factor models: only the *surprise* (unexpected) part of a factor moves returns. The factor value is the surprise = actual − expected:

$$F_{INF} = \text{actual} - \text{expected} = 3\% - 3\% = 0\%$$

Then the effect = beta × surprise = −1.2 × 0% = 0%. Since inflation came in exactly as expected, there is no surprise, so no impact — no matter how big the beta is.

It is like a weather forecast: if rain was predicted and it rains, no one is surprised, so no one changes plans. Only *unexpected* weather shifts behavior.

- A is wrong: −3.6% = −1.2 × 3%, the trap of multiplying beta by the *actual level* (3%) instead of the surprise (0%).
- B is wrong: +3.6% makes the same level-vs-surprise error and also flips the sign.
- D is wrong: −1.2% just reports the beta as if it were the return effect.

📌 Exam tip: Always compute surprise = actual − expected BEFORE multiplying by beta. Expected = actual ⇒ surprise = 0 ⇒ zero effect, regardless of how large the level "sounds."

**Q3.** A stock has a beta of 0.9 on factor 1 (premium 5%) and 0.2 on factor 2 (premium 1%). With a risk-free rate of 4%, the APT expected return is:
- A. 8.7%
- B. 4.7%
- C. 9.5%
- D. 10.7%

**Answer: A**

The question is a direct multifactor expected-return calculation. The APT expected return is the risk-free rate plus the sum of (each beta × its factor premium):

$$E[R] = R_f + \beta_1\lambda_1 + \beta_2\lambda_2$$
$$E[R] = 4\% + 0.9(5\%) + 0.2(1\%)$$
$$E[R] = 4\% + 4.5\% + 0.2\% = 8.7\%$$

- B is wrong: 4.7% forgets the factor-1 term (0.9 × 5% = 4.5%) almost entirely.
- C is wrong: 9.5% comes from an arithmetic slip in adding the premium contributions.
- D is wrong: 10.7% over-adds (e.g., using a wrong beta or premium) beyond the correct 8.7%.

📌 Exam tip: APT return = R_f + Σ(βₖ × λₖ). Multiply each factor beta by its own premium, sum them, then add R_f. Keep each factor's beta paired with its correct premium.

**Q4.** In the Fama–French three-factor model, a portfolio with a significantly negative HML loading and a near-zero SMB loading is best described as tilted toward:
- A. Small-cap value
- B. Large-cap value
- C. Growth
- D. High-dividend stocks

**Answer: C**

The question asks you to read style tilts off Fama–French loadings. HML ("high minus low") is the value premium: a *positive* HML beta means a value tilt, while a *negative* HML beta means a growth tilt. A near-zero SMB ("small minus big") beta says nothing strong about size. So negative HML + ~zero SMB = growth tilt.

- A is wrong: small-cap value would need a *positive* SMB and a *positive* HML — the opposite of what's given.
- B is wrong: large-cap value would need a *positive* HML (value), but here HML is negative.
- D is wrong: high-dividend is not what HML/SMB measure; nothing here points to a dividend tilt.

📌 Exam tip: Positive HML = value tilt; negative HML = growth tilt. Positive SMB = small-cap tilt; negative SMB = large-cap tilt. Read the signs carefully — they flip the interpretation.

**Q5.** A fund has Fama–French loadings of βₘ = 1.1, β(SMB) = 0.6, β(HML) = −0.3. With premiums of market 6%, SMB 2.5%, HML 3.5%, and R_f = 2%, the expected return is closest to:
- A. 9.05%
- B. 11.15%
- C. 7.05%
- D. 10.10%

**Answer: A**

The question is a Fama–French expected-return calculation. Add R_f plus each loading times its premium, being careful with the negative HML term:

$$E[R] = R_f + \beta_m(E[R_m]-R_f) + \beta_{SMB}E[SMB] + \beta_{HML}E[HML]$$
$$E[R] = 2\% + 1.1(6\%) + 0.6(2.5\%) + (-0.3)(3.5\%)$$
$$E[R] = 2\% + 6.6\% + 1.5\% - 1.05\%$$
$$E[R] = 9.05\%$$

- B is wrong: 11.15% adds the HML term instead of subtracting it (treating −0.3 as +0.3): the classic negative-loading trap.
- C is wrong: 7.05% drops or mis-signs one of the positive terms.
- D is wrong: 10.10% comes from an arithmetic slip in combining the terms.

📌 Exam tip: In Fama–French, a NEGATIVE loading SUBTRACTS from expected return. The most common mistake is flipping the sign of the HML (or SMB) term — watch it closely.

**Q6.** In a multifactor return model $$R_i = E[R_i] + \beta_{i1}F_1 + \cdots + \beta_{iK}F_K + e_i$$, the term $$e_i$$ represents:
- A. The expected return priced ex ante
- B. The systematic factor surprise
- C. The firm-specific (idiosyncratic) return, uncorrelated across assets
- D. The factor risk premium

**Answer: C**

The question asks you to identify the error/residual term in a factor model. The $$e_i$$ is the firm-specific (idiosyncratic) return — the part of the return driven by company-specific news, uncorrelated across assets and with the factors. In a well-diversified portfolio it largely washes out.

Think of it as the "personal news" affecting one company (a CEO resignation), separate from economy-wide news (the factors).

- A is wrong: the expected return priced ex ante is $$E[R_i]$$, the first term, not $$e_i$$.
- B is wrong: the systematic factor surprise is $$F_k$$ (with beta loading), not the residual.
- D is wrong: the factor risk premium is $$\lambda_k$$, which appears in the *pricing* equation, not as the residual in the return-generating equation.

📌 Exam tip: In the return-generating model: $$E[R_i]$$ = ex-ante expected return; $$F_k$$ = factor surprise (E[F]=0); $$\beta_{ik}$$ = loading; $$e_i$$ = idiosyncratic, diversifiable residual.

**Q7.** A $100 million portfolio has a GDP-factor beta of 0.8. To fully hedge the GDP exposure using a pure GDP factor portfolio (which has GDP beta of 1 and zero loading on other factors), the manager should:
- A. Buy $80 million of the GDP factor portfolio
- B. Short $80 million of the GDP factor portfolio
- C. Short $100 million of the GDP factor portfolio
- D. Buy $20 million of the GDP factor portfolio

**Answer: B**

The question asks how to zero out a single factor exposure. The portfolio's dollar GDP exposure is its beta times its value: 0.8 × $100m = $80m of GDP exposure. To cancel it, take an *offsetting* (short) position of the same size in the pure GDP factor portfolio:

$$\text{Hedge} = 0.8 \times \$100\text{m} = \$80\text{m short}$$

Net GDP beta after hedging: 0.8 − 0.8 = 0. Because the pure factor portfolio has zero loading on other factors, any other exposures stay untouched.

- A is wrong: buying (going long) would *add* to the GDP exposure, raising net beta to 1.6, not zero.
- C is wrong: shorting $100m would over-hedge (net beta = 0.8 − 1.0 = −0.2), flipping the exposure negative.
- D is wrong: $20m is unrelated to the 0.8 × $100m calculation.

📌 Exam tip: To hedge a factor, short (β × portfolio value) of a *pure* factor portfolio so net beta = 0. A pure factor portfolio (β = 1 on one factor, 0 elsewhere) lets you hedge one factor without disturbing the others.

**Q8.** Which of the following is a genuine challenge of using multifactor models for hedging?
- A. Factor betas are known exactly and never change over time
- B. Factor betas are estimated with error and tend to drift over time
- C. Hedging multiple factors requires only a single position
- D. Idiosyncratic risk is automatically removed by hedging the factors

**Answer: B**

The question asks for a real-world limitation of multifactor hedging. Factor betas come from regressions, so they are estimated with error, and they drift as a firm's business and the economy change — making a hedge that fits today imperfect tomorrow.

It is like tailoring a suit to someone whose measurements keep changing: it fits at first but gradually goes off.

- A is wrong: it states the opposite — betas are *not* known exactly and *do* change.
- C is wrong: hedging multiple factors generally requires *multiple* positions (one per factor), which adds transaction costs and shorting constraints.
- D is wrong: hedging the factors leaves only idiosyncratic risk and alpha; idiosyncratic risk is reduced by holding *many names*, not by factor hedging.

📌 Exam tip: Multifactor hedging challenges — betas estimated with error and drift, possible factor misspecification (omitted factors), many positions needed (costs/shorting limits), and correlated factor proxies. Idiosyncratic risk is diversified away, not hedged.

**Q9.** A stock has a beta of 1.2 on the GDP factor (premium 4%) and −0.5 on the inflation factor (premium 2%), with a risk-free rate of 3%. Its APT expected return is:
- A. 6.8%
- B. 8.8%
- C. 7.8%
- D. 5.8%

**Answer: A**

The question is a two-factor APT expected-return calculation, with one negative beta to watch. Add R_f plus each beta times its premium:

$$E[R] = R_f + \beta_{GDP}\lambda_{GDP} + \beta_{INF}\lambda_{INF}$$
$$E[R] = 3\% + 1.2(4\%) + (-0.5)(2\%)$$
$$E[R] = 3\% + 4.8\% - 1.0\%$$
$$E[R] = 6.8\%$$

- B is wrong: 8.8% adds the inflation term (+1.0%) instead of subtracting it — the negative-beta trap.
- C is wrong: 7.8% drops the inflation term entirely (ignores the −0.5 contribution).
- D is wrong: 5.8% subtracts too much or mishandles a term.

📌 Exam tip: A negative factor beta SUBTRACTS from expected return. Keep the sign attached to the beta: (−0.5)(2%) = −1.0%, not +1.0%.

**Q10.** In the Fama–French three-factor model, the SMB factor is constructed to capture which premium?
- A. The value premium (high book-to-market minus low)
- B. The size premium (small-cap minus large-cap returns)
- C. The momentum premium (winners minus losers)
- D. The market risk premium

**Answer: B**

The question asks what SMB stands for and measures. SMB means "small minus big" — the return of small-cap stocks minus large-cap stocks — so it captures the size premium: historically, small companies earned more than the CAPM predicted.

- A is wrong: the value premium is captured by HML ("high minus low" book-to-market), not SMB.
- C is wrong: momentum (winners minus losers) is the Carhart fourth factor (UMD/WML), not part of the three-factor SMB.
- D is wrong: the market risk premium is the CAPM market factor (E[R_m] − R_f), separate from SMB.

📌 Exam tip: SMB = Small Minus Big = size premium. HML = High Minus Low (book-to-market) = value premium. Momentum (UMD/WML) is the common fourth (Carhart) factor.
