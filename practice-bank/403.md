**Q1.** Using the EWMA model with $\lambda = 0.94$, yesterday's volatility estimate was 1.2% per day and yesterday's return was −2%. The updated daily volatility estimate is closest to:
- A. 1.20%
- B. 1.26%
- C. 1.60%
- D. 2.00%

**Answer: B**

The question asks you to update volatility one step with EWMA.

The EWMA recursion works in variances:

$$\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$$

Plug in $\lambda = 0.94$, $\sigma_{n-1} = 0.012$, $r_{n-1} = -0.02$ (square it, so the sign disappears):

$$\sigma_n^2 = 0.94 \times (0.012)^2 + 0.06 \times (0.02)^2$$

$$= 0.94 \times 0.000144 + 0.06 \times 0.0004$$

$$= 0.00013536 + 0.000024 = 0.00015936$$

Take the square root:

$$\sigma_n = \sqrt{0.00015936} = 0.01262 = 1.262\%$$

So B is correct.

- A (1.20%) is yesterday's estimate, ignoring the update.
- C (1.60%) ignores the math entirely.
- D (2.00%) is just the latest return's magnitude, not the blended estimate.

Analogy: EWMA is a "weighted memory" — it keeps 94% of yesterday's view and adds 6% of the newest day's surprise. A big move nudges the estimate up a little, not all the way.

📌 Exam tip: Always work in variances (square σ and r), blend, then take the square root at the very end. Squaring kills the minus sign on the return.

**Q2.** In the EWMA model, the parameter $\lambda$ (the decay factor):
- A. Must be greater than 1 for stability
- B. Controls how quickly old observations lose weight; higher λ means slower reaction
- C. Is the long-run variance
- D. Equals zero for daily data

**Answer: B**

The question tests the meaning of the decay factor.

In $\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$, a high $\lambda$ (close to 1) puts most weight on the prior estimate, so volatility reacts slowly and has a long memory; a low $\lambda$ reacts fast but is noisy. The RiskMetrics standard is $\lambda = 0.94$ for daily data. B is correct.

- A is wrong: $\lambda$ lies strictly between 0 and 1.
- C is wrong: EWMA has no long-run variance (no mean reversion) — that's a GARCH feature.
- D is wrong: for daily data $\lambda$ is around 0.94, not zero.

Analogy: $\lambda$ is like the stubbornness of your opinion. High stubbornness (high λ) means new news barely moves you; low stubbornness means you flip with every headline.

📌 Exam tip: Higher λ → slower, smoother, longer memory. Lower λ → faster, noisier. RiskMetrics uses λ = 0.94 daily.

**Q3.** A GARCH(1,1) model has $\omega = 0.000002$, $\alpha = 0.13$, and $\beta = 0.86$. The long-run (unconditional) daily volatility is closest to:
- A. 0.0002%
- B. 1.41%
- C. 2.00%
- D. 0.02%

**Answer: B**

The question asks for the long-run volatility from GARCH parameters.

First find the long-run variance:

$$V_L = \frac{\omega}{1 - \alpha - \beta} = \frac{0.000002}{1 - 0.13 - 0.86} = \frac{0.000002}{0.01} = 0.0002$$

Then take the square root to get volatility:

$$\sigma_L = \sqrt{0.0002} = 0.01414 = 1.414\%$$

So B is correct.

- A (0.0002%) reports the variance as if it were the volatility, and mislabels its scale — forgetting the square root.
- C (2.00%) ignores the formula.
- D (0.02%) misplaces the decimal and skips the square root.

Analogy: the long-run variance is the "home base" the volatility eventually drifts back to. Variance is in squared units; you must square-root it to get a volatility you can quote.

📌 Exam tip: $V_L = \omega/(1 - \alpha - \beta)$ gives a variance — always take the square root for the volatility. The "forgot to square-root" answer is a favorite trap.

**Q4.** Using the GARCH(1,1) model with $\omega = 0.000002$, $\alpha = 0.13$, $\beta = 0.86$, current daily volatility 1.6%, and today's return +1%, the updated daily volatility is closest to:
- A. 1.41%
- B. 1.53%
- C. 1.60%
- D. 0.024%

**Answer: B**

The question asks for a one-step GARCH update.

The GARCH(1,1) recursion (in variances):

$$\sigma_n^2 = \omega + \alpha\, r_{n-1}^2 + \beta\, \sigma_{n-1}^2$$

Plug in $r_{n-1} = 0.01$ and $\sigma_{n-1} = 0.016$:

$$\sigma_n^2 = 0.000002 + 0.13 \times (0.01)^2 + 0.86 \times (0.016)^2$$

$$= 0.000002 + 0.13 \times 0.0001 + 0.86 \times 0.000256$$

$$= 0.000002 + 0.000013 + 0.00022016 = 0.00023516$$

Square root:

$$\sigma_n = \sqrt{0.00023516} = 0.01534 = 1.534\%$$

So B is correct. Volatility falls from 1.60% toward the 1.41% long-run level because today's 1% return was small relative to the prior estimate — mean reversion at work.

- A (1.41%) is the long-run volatility, not the one-step update.
- C (1.60%) is the unchanged current volatility.
- D (0.024%) quotes the variance figure mislabeled as a volatility (forgot the square root).

📌 Exam tip: α multiplies the squared return; β multiplies the prior variance. Don't swap them, and don't forget to square-root the final variance.

**Q5.** Compared with the GARCH(1,1) model, the EWMA model:
- A. Includes mean reversion toward a long-run variance
- B. Sets $\omega = 0$, so forecasts do not revert to a long-run level
- C. Requires three estimated parameters
- D. Weights all past observations equally

**Answer: B**

The question asks how EWMA relates to GARCH(1,1).

EWMA is a special case of GARCH(1,1) with $\omega = 0$, $\alpha = 1 - \lambda$, and $\beta = \lambda$. Because $\omega = 0$, there is no constant anchor, so EWMA forecasts have no long-run level to revert to — every future day's forecast equals today's estimate. B is correct.

- A is wrong: EWMA has no mean reversion (that is precisely the GARCH addition).
- C is wrong: EWMA uses only one parameter (λ); GARCH uses three (ω, α, β).
- D describes the equal-weighted historical method, not EWMA, which uses geometrically declining weights.

Analogy: EWMA is like a thermometer with no thermostat — it tracks temperature but has no "target" to pull back toward. GARCH adds the thermostat (the long-run variance).

📌 Exam tip: EWMA = GARCH with ω = 0, α = 1 − λ, β = λ. Key consequence: EWMA has no mean reversion; GARCH does.

**Q6.** Empirically observed fat tails (excess kurtosis) in daily asset returns are best explained by:
- A. Returns being conditionally fat-tailed only
- B. Time-varying volatility mixing normal distributions of different variances
- C. Positive skewness in the data
- D. Returns being perfectly i.i.d. normal

**Answer: B**

The question asks for the main driver of unconditional fat tails.

Returns can be conditionally normal (normal each day given that day's volatility) yet unconditionally fat-tailed, because mixing normals with different variances creates excess kurtosis. Volatility clustering and regime switching produce exactly this mix of calm and turbulent periods. B is correct.

- A is wrong: the standard story is that conditional distributions are roughly normal; it's the changing variance that produces fat tails.
- C describes skew (asymmetry), a different feature from fat tails (kurtosis).
- D is wrong: perfectly i.i.d. normal returns would have no excess kurtosis at all.

Analogy: blend many bell curves of different widths and the combined shape gets a sharp peak and heavy tails — even though each ingredient was a tidy bell curve.

📌 Exam tip: Fat tails arise largely from a changing σ over time. This is why tracking conditional volatility (EWMA/GARCH) makes standardized returns look more normal.

**Q7.** Implied volatility differs from historical (statistical) volatility because implied volatility is:
- A. Backward-looking and based only on past returns
- B. Forward-looking, derived from current option prices by inverting an option pricing model
- C. Always lower than realized volatility
- D. Computed using the EWMA recursion

**Answer: B**

The question contrasts implied with statistical volatility.

Implied volatility is backed out of observed option prices by inverting a model such as Black-Scholes-Merton. Because option prices reflect the market's view over the option's remaining life, implied volatility is forward-looking, unlike historical estimates that use past returns. B is correct.

- A describes historical volatility, not implied.
- C is wrong: implied volatility tends to sit above subsequent realized volatility on average (it embeds a risk premium), but it is not "always lower."
- D is wrong: EWMA is a statistical (backward-looking) method, not how implied vol is obtained.

Analogy: historical volatility is the rear-view mirror (where prices have been); implied volatility is the market's forecast through the windshield (where it expects them to go).

📌 Exam tip: Implied vol = market's forward-looking view from option prices (e.g., the VIX). The volatility smile/skew shows implied vol varying by strike, violating BSM's constant-σ assumption.

**Q8.** EWMA with $\lambda = 0.9$: the previous daily volatility estimate is 2% and the latest return is 3%. The updated volatility is closest to:
- A. 2.10%
- B. 2.12%
- C. 2.50%
- D. 3.00%

**Answer: B**

The question is a straightforward EWMA update with a different λ.

Variance recursion:

$$\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$$

Plug in $\lambda = 0.9$, $\sigma_{n-1} = 0.02$, $r_{n-1} = 0.03$:

$$\sigma_n^2 = 0.9 \times (0.02)^2 + 0.1 \times (0.03)^2$$

$$= 0.9 \times 0.0004 + 0.1 \times 0.0009$$

$$= 0.00036 + 0.00009 = 0.00045$$

Square root:

$$\sigma_n = \sqrt{0.00045} = 0.02121 = 2.121\%$$

So B is correct.

- A (2.10%) comes from linearly averaging the σs (0.9×2% + 0.1×3% = 2.10%) instead of working in variances — the classic error.
- C (2.50%) is a plain average of 2% and 3%.
- D (3.00%) is just the latest return.

📌 Exam tip: Never average the volatilities directly. Square first, blend the variances, then square-root. Averaging σ gives a slightly-off answer planted as a distractor.

**Q9.** A GARCH(1,1) model has $\omega = 0.000003$, $\alpha = 0.04$, and $\beta = 0.94$. The long-run daily volatility is closest to:
- A. 1.22%
- B. 0.015%
- C. 0.039%
- D. 2.24%

**Answer: A**

The question asks for the long-run volatility.

Long-run variance:

$$V_L = \frac{\omega}{1 - \alpha - \beta} = \frac{0.000003}{1 - 0.04 - 0.94} = \frac{0.000003}{0.02} = 0.00015$$

Square root for volatility:

$$\sigma_L = \sqrt{0.00015} = 0.01225 = 1.225\%$$

So A is correct.

- B (0.015%) reports the variance (0.00015) mislabeled and forgets the square root.
- C (0.039%) uses a wrong denominator or skips the square root.
- D (2.24%) doubles the correct answer or uses the wrong arithmetic.

📌 Exam tip: Check that α + β < 1 (here 0.98, so stationary). Then $V_L = \omega/(1 - \alpha - \beta)$, and square-root it for volatility.

**Q10.** When updating a covariance matrix with EWMA, it is recommended to use the same decay factor λ for variances and covariances mainly to:
- A. Reduce computational cost
- B. Keep the resulting covariance matrix internally consistent (positive semi-definite)
- C. Make all correlations equal to 1
- D. Eliminate the need to estimate volatility

**Answer: B**

The question asks why a single λ is used across variances and covariances.

Covariances update with the same machinery: $\text{cov}_n = \lambda\,\text{cov}_{n-1} + (1-\lambda)\,x_{n-1}y_{n-1}$, and correlation is $\rho_n = \text{cov}_n/(\sigma_{x,n}\sigma_{y,n})$. Using the same λ for every variance and covariance keeps the whole matrix consistent so it stays positive semi-definite — meaning it produces sensible (non-negative) portfolio variances. B is correct.

- A is a minor side effect at best, not the main reason.
- C is wrong and undesirable — correlations spiking to 1 in crises is a risk concern, not a goal.
- D is wrong: you still need volatilities to form correlations.

Analogy: if you measure each side of a triangle with a different ruler, the triangle won't close properly. Using one consistent ruler (λ) keeps the covariance "triangle" valid.

📌 Exam tip: Same λ across variances and covariances → a consistent, positive-semi-definite covariance matrix. Remember correlations tend to spike toward 1 in crises, so dynamic monitoring matters for portfolio VaR.
