**Q1.** Two assets each have a standard deviation of 25%. An equally weighted portfolio of the two will also have a standard deviation of exactly 25% only if their correlation is:
- A. 0
- B. −1
- C. +1
- D. 0.5

**Answer: C**

The question asks: when does combining two assets give NO diversification benefit (so the portfolio's risk equals the simple weighted average)? That happens only when the assets are perfectly positively correlated, ρ = +1. With any correlation below +1, the portfolio standard deviation drops below the weighted average — that drop is the diversification benefit.

Think of two friends whose moods move in perfect lockstep (ρ = +1): averaging them gives you no smoothing. But if their moods differ, the average is steadier than either alone.

- A is wrong: with ρ = 0 the portfolio risk falls well below 25% (diversification helps).
- B is wrong: with ρ = −1 the assets offset strongly; risk falls even further (it can reach zero with the right weights).
- D is wrong: ρ = 0.5 still lowers risk below 25% — only ρ = +1 gives no reduction.

📌 Exam tip: Portfolio σ equals the weighted average of the individual σ's ONLY when ρ = +1. Any ρ < 1 produces a diversification benefit (lower portfolio σ).

**Q2.** A fairly priced individual stock that carries substantial idiosyncratic (diversifiable) risk will plot:
- A. On both the CML and the SML
- B. On the SML but below the CML
- C. Above the CML
- D. Below the SML

**Answer: B**

The question tests the difference between the SML and the CML. All fairly priced assets lie on the security market line (SML), because the SML prices return against *systematic* risk (beta), which applies to every asset. But the capital market line (CML) is reached only by *efficient* portfolios (mixes of the risk-free asset and the market). A single stock carries diversifiable risk that earns no reward, so it sits below the CML.

Picture the CML as a "first-class only" line for efficient portfolios; a lone stock with extra (uncompensated) risk doesn't qualify, so it falls short of it — yet it's still correctly priced on the SML.

- A is wrong: a single stock with diversifiable risk does NOT reach the CML, so it can't be on both.
- C is wrong: nothing fairly priced plots above the CML — the CML is the best risk-return frontier available.
- D is wrong: below the SML means *overpriced*; the stock here is fairly priced, so it sits *on* the SML.

📌 Exam tip: All fairly priced assets sit ON the SML (priced by beta). Only efficient portfolios sit ON the CML (priced by total risk σ). A single stock's diversifiable risk pushes it below the CML.

**Q3.** Stock Y has covariance with the market of 0.036 and the market standard deviation is 0.15. With a risk-free rate of 2% and expected market return of 8%, the CAPM expected return of Y is closest to:
- A. 8.0%
- B. 9.6%
- C. 11.6%
- D. 4.4%

**Answer: C**

The question is a two-step CAPM calculation: first find beta, then plug into the CAPM formula.

Step 1 — beta:
$$\beta_Y = \frac{\mathrm{Cov}(R_Y, R_m)}{\sigma_m^2} = \frac{0.036}{0.15^2} = \frac{0.036}{0.0225} = 1.6$$

Step 2 — CAPM expected return:
$$E[R_Y] = R_f + \beta_Y\,(E[R_m] - R_f) = 2\% + 1.6\,(8\% - 2\%)$$
$$E[R_Y] = 2\% + 1.6 \times 6\% = 2\% + 9.6\% = 11.6\%$$

- A is wrong: 8.0% just uses the market return, as if beta were 1 (it forgot to compute beta = 1.6).
- B is wrong: 9.6% is only the risk-premium part (1.6 × 6%); it forgot to add the 2% risk-free rate.
- D is wrong: 4.4% comes from a wrong beta — e.g., dividing 0.036 by 0.15 (= 0.24×... ) or other arithmetic slips.

📌 Exam tip: Beta = Cov / σ_market² (square the market σ!). Then CAPM: R_f + β(market premium). Don't forget to add R_f back at the end.

**Q4.** Which of the following is NOT an assumption of the CAPM?
- A. Investors have homogeneous expectations
- B. There is unlimited borrowing and lending at the risk-free rate
- C. Investors have heterogeneous, multi-period horizons
- D. There are no taxes or transaction costs

**Answer: C**

The question asks you to spot the statement that contradicts CAPM's assumptions. The CAPM assumes a single common holding period and homogeneous (identical) expectations across investors. So "heterogeneous, multi-period horizons" is the opposite of what CAPM assumes — that is the NOT.

- A is wrong (as the answer) because homogeneous expectations IS a genuine CAPM assumption.
- B is wrong (as the answer) because unlimited risk-free borrowing and lending IS a CAPM assumption.
- D is wrong (as the answer) because no taxes or transaction costs IS a CAPM assumption.

📌 Exam tip: CAPM assumes single-period, homogeneous expectations, no taxes/costs, price-taking investors, and unlimited risk-free borrowing/lending. "Heterogeneous, multi-period" violates the single-period and homogeneous-expectations assumptions.

**Q5.** An investor puts 60% in fund A (E[R] = 10%) and 40% in fund B (E[R] = 5%). The expected return of the portfolio is:
- A. 7.5%
- B. 8.0%
- C. 15.0%
- D. 6.5%

**Answer: B**

The question asks for a simple weighted-average expected return. Portfolio expected return is just each weight times each asset's expected return, summed:

$$E[R_p] = w_A E[R_A] + w_B E[R_B] = 0.60(10\%) + 0.40(5\%)$$
$$E[R_p] = 6\% + 2\% = 8\%$$

- A is wrong: 7.5% is the simple (unweighted) average of 10% and 5%, ignoring the 60/40 weights.
- C is wrong: 15% just adds the two returns together — you must weight them, not sum them.
- D is wrong: 6.5% comes from flipping the weights (0.40×10% + 0.60×5% = 4% + 3% = 7%, or another slip); the correct weighting gives 8%.

📌 Exam tip: Expected return is ALWAYS the weighted average of component returns. (Unlike variance, there's no correlation term for the mean.) Apply the weights correctly — don't take a plain average.

**Q6.** A portfolio holds 50% in a stock with beta 1.4, 30% in a stock with beta 0.8, and 20% in T-bills (beta 0). The portfolio beta is:
- A. 0.94
- B. 1.10
- C. 0.73
- D. 1.40

**Answer: A**

The question asks for portfolio beta, which is the weighted average of the component betas:

$$\beta_p = w_1\beta_1 + w_2\beta_2 + w_3\beta_3$$
$$\beta_p = 0.50(1.4) + 0.30(0.8) + 0.20(0)$$
$$\beta_p = 0.70 + 0.24 + 0 = 0.94$$

- B is wrong: 1.10 comes from mishandling the weights or ignoring that T-bills have beta 0.
- C is wrong: 0.73 likely drops or misweights a term.
- D is wrong: 1.40 is just the first stock's beta — it ignores the other holdings entirely.

📌 Exam tip: Portfolio beta = weighted average of component betas. T-bills (risk-free) have beta 0, so they pull the portfolio beta toward 0. The weights must sum to 1.

**Q7.** Stock X is twice as volatile as the market (σ_X = 30% vs. σ_m = 15%) but has a correlation of only 0.5 with the market. Its beta is:
- A. 2.0
- B. 1.0
- C. 0.5
- D. 1.5

**Answer: B**

The question tests that beta depends on correlation, not just volatility. Beta is computed as:

$$\beta_X = \rho_{Xm}\,\frac{\sigma_X}{\sigma_m} = 0.5 \times \frac{0.30}{0.15} = 0.5 \times 2.0 = 1.0$$

So even though X is twice as volatile as the market, half of that volatility is diversifiable (uncorrelated) and earns no premium — its beta is just 1.0.

- A is wrong: 2.0 uses only the volatility ratio (σ_X/σ_m) and forgets to multiply by the correlation of 0.5.
- C is wrong: 0.5 mistakes the correlation itself for the beta.
- D is wrong: 1.5 is a miscalculation that doesn't follow from these numbers.

📌 Exam tip: β = ρ × (σ_asset / σ_market). High total volatility does NOT mean high beta — only the part correlated with the market counts. Don't confuse σ with β.

**Q8.** A stock's CAPM-required return is 9%, but analysts forecast it to return 11%. According to the CAPM framework, this stock:
- A. Is overpriced and plots below the SML
- B. Has a positive alpha of +2% and plots above the SML
- C. Has a beta of 2.0
- D. Lies exactly on the SML

**Answer: B**

The question asks how to interpret a forecast return that exceeds the CAPM-required return. Alpha is the forecast (expected) return minus the CAPM-required return:

$$\alpha = 11\% - 9\% = +2\%$$

A positive alpha means the stock offers more return than its systematic risk requires, so it is underpriced and plots above the SML — an attractive buy.

- A is wrong: below the SML means a *negative* alpha (overpriced); here alpha is positive.
- C is wrong: nothing in the numbers tells you beta is 2.0; you can't infer beta from alpha alone.
- D is wrong: lying exactly on the SML would mean alpha = 0 (forecast equals required); here they differ by 2%.

📌 Exam tip: Alpha = forecast return − CAPM-required return. Positive alpha → above the SML → underpriced (buy). Negative alpha → below the SML → overpriced.

**Q9.** When a risk-free asset is combined with risky assets and all investors share the same (homogeneous) expectations, every investor holds the same risky portfolio — the market portfolio — and adjusts risk only via the risk-free weight. This result is known as:
- A. The Roll critique
- B. The two-fund separation theorem
- C. The efficient frontier
- D. Arbitrage pricing theory

**Answer: B**

The question describes the idea that everyone holds the same tangency (market) portfolio and only varies how much they put in the risk-free asset. That is the two-fund separation theorem: investing decisions "separate" into choosing the single optimal risky portfolio (the market) and then choosing the split between it and the risk-free asset.

It is like everyone ordering the same "house special" dish but choosing how spicy to make it — the dish is fixed, only the heat level varies.

- A is wrong: the Roll critique says the true market portfolio is unobservable, so CAPM isn't properly testable — a *limitation*, not this result.
- C is wrong: the efficient frontier is the set of best risky-only portfolios; the separation theorem is about adding the risk-free asset.
- D is wrong: APT is a multifactor no-arbitrage theory (Chapter 6), not this two-fund result.

📌 Exam tip: Adding a risk-free asset turns the frontier into a straight line; with homogeneous expectations the tangency portfolio = the market portfolio. Everyone holds the same risky mix → two-fund separation.

**Q10.** A stock with a beta of −0.4 would, under the CAPM, have an expected return that is:
- A. Above the expected market return
- B. Below the risk-free rate
- C. Exactly equal to the risk-free rate
- D. Negative in all market conditions

**Answer: B**

The question tests what a negative beta implies. Plug a negative beta into the CAPM: since the market premium (E[R_m] − R_f) is positive, multiplying it by a negative beta gives a negative risk premium, pulling the expected return *below* the risk-free rate.

$$E[R] = R_f + (-0.4)(E[R_m] - R_f) = R_f - 0.4(\text{positive number}) < R_f$$

A negative-beta asset is a hedge: it tends to rise when the market falls, so investors accept a low (even sub-risk-free) expected return for that valuable insurance.

- A is wrong: a return above the market return would require a beta greater than 1, not negative.
- C is wrong: equal to the risk-free rate requires beta = 0, not −0.4.
- D is wrong: a below-risk-free *expected* return does not mean the return is negative in all conditions — the asset can still have positive returns.

📌 Exam tip: β = 0 → return = R_f; β = 1 → return = market; β < 0 → return BELOW R_f (a hedge asset, valuable because it pays off when markets fall).
