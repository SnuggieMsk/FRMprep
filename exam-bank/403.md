**Q1.** An EWMA model uses λ = 0.94. The current variance estimate is $$\sigma_{n-1}^2 = 0.000196$$ (i.e., σ = 1.40%/day). The latest daily return is −3.00%. The updated daily volatility estimate is closest to:

- A. 1.46%
- B. 1.53%
- C. 2.13%
- D. 1.40%

**Answer: B**

The ask: apply the EWMA recursion in variances, then convert to volatility at the end.

1. Recursion: $$\sigma_n^2 = \lambda\,\sigma_{n-1}^2 + (1-\lambda)\,r_{n-1}^2$$.
2. Prior variance term: $$0.94 \times 0.000196 = 0.00018424$$.
3. New return term: $$r^2 = (-0.03)^2 = 0.0009$$; $$0.06 \times 0.0009 = 0.000054$$.
4. Sum: $$\sigma_n^2 = 0.00018424 + 0.000054 = 0.00023824$$.
5. Convert: $$\sigma_n = \sqrt{0.00023824} = 0.01544 = 1.54\%$$ (closest to 1.53%).

- A. 1.46% linearly interpolates the volatilities ($$0.94 \times 1.40 + 0.06 \times 3.00 = 1.496$$) instead of working in variances.
- C. 2.13% forgets to apply the weights (averages or over-weights the new return).
- D. 1.40% ignores the new return entirely.
- B is correct.

📌 Exam tip: EWMA and GARCH operate on *variances*, not volatilities. Square the return, weight the variances, sum, then square-root at the very end. Linear interpolation of σ is the most common wrong path.

**Q2.** A GARCH(1,1) model is estimated as ω = 0.000004, α = 0.08, β = 0.90. The long-run (unconditional) daily volatility is closest to:

- A. 0.020%/day
- B. 1.414%/day
- C. 0.0002%/day
- D. 0.447%/day

**Answer: B**

The ask: compute the long-run volatility from GARCH parameters.

1. Long-run variance: $$V_L = \frac{\omega}{1 - \alpha - \beta}$$.
2. Denominator: $$1 - 0.08 - 0.90 = 0.02$$.
3. $$V_L = \frac{0.000004}{0.02} = 0.0002$$.
4. Convert: $$\sigma_L = \sqrt{0.0002} = 0.01414 = 1.414\%$$/day.

- A. 0.020% reports $$V_L$$-related figure as a percent without square-rooting properly (or 0.0002 mislabeled).
- C. 0.0002% reports the *variance* as if it were volatility (×100% confusion).
- D. 0.447% mis-divides (e.g., uses $$1 - \alpha\beta$$ or a different denominator).
- B is correct.

📌 Exam tip: $$V_L = \omega/(1-\alpha-\beta)$$ gives a *variance*; you must take its square root for volatility. Quoting the variance as "volatility" (forgetting the √) is the textbook trap.

**Q3.** Using the GARCH(1,1) model from Q2 (ω = 0.000004, α = 0.08, β = 0.90), the current daily volatility is 2.50% and today's return is +0.50%. The updated daily volatility estimate is closest to:

- A. 2.38%
- B. 2.50%
- C. 1.93%
- D. 2.55%

**Answer: A**

The ask: apply the GARCH update, then convert to volatility, and confirm the direction of mean reversion.

1. Recursion: $$\sigma_n^2 = \omega + \alpha\,r_{n-1}^2 + \beta\,\sigma_{n-1}^2$$.
2. ω term: $$0.000004$$.
3. Return term: $$r^2 = (0.005)^2 = 0.000025$$; $$\alpha r^2 = 0.08 \times 0.000025 = 0.000002$$.
4. Prior variance term: $$\sigma_{n-1}^2 = (0.025)^2 = 0.000625$$; $$\beta\sigma^2 = 0.90 \times 0.000625 = 0.0005625$$.
5. Sum: $$\sigma_n^2 = 0.000004 + 0.000002 + 0.0005625 = 0.0005685$$.
6. Convert: $$\sigma_n = \sqrt{0.0005685} = 0.02384 = 2.38\%$$.

The small return (0.50%) is far below the prior level, so volatility falls from 2.50% toward the 1.41% long-run level — mean reversion.

- B. 2.50% assumes no change.
- C. 1.93% swaps α and β (multiplies the small return by 0.90 and the prior variance by 0.08).
- D. 2.55% uses σ where σ² belongs (plugs 0.025 and 0.005 without squaring) — volatility rises incorrectly.
- A is correct.

📌 Exam tip: α multiplies the squared *return*; β multiplies the prior *variance*. Swapping them is a favorite distractor. A small return pulls GARCH volatility *down* toward $$V_L$$.

**Q4.** A GARCH(1,1) has α = 0.06 and β = 0.92, with current daily variance 0.000400 and long-run variance $$V_L$$ = 0.000250. Using the multi-day forecast formula, the expected daily variance 10 days ahead, $$E[\sigma_{n+10}^2]$$, is closest to:

- A. 0.000400
- B. 0.000250
- C. 0.000373
- D. 0.000350

**Answer: C**

The ask: forecast GARCH variance t days ahead using mean reversion at rate (α+β).

1. Multi-day formula: $$E[\sigma_{n+t}^2] = V_L + (\alpha+\beta)^t\,(\sigma_n^2 - V_L)$$.
2. Persistence: $$\alpha + \beta = 0.06 + 0.92 = 0.98$$.
3. Decay factor for t = 10: $$0.98^{10} = e^{10\ln 0.98} = e^{10(-0.020203)} = e^{-0.20203} = 0.8171$$.
4. Gap from long run: $$\sigma_n^2 - V_L = 0.000400 - 0.000250 = 0.000150$$.
5. Decayed gap: $$0.8171 \times 0.000150 = 0.00012256$$.
6. Forecast: $$0.000250 + 0.00012256 = 0.00037256 \approx 0.000373$$.

- A. 0.000400 assumes no mean reversion (EWMA behavior).
- B. 0.000250 assumes *full* reversion to $$V_L$$ (only true as $$t\to\infty$$).
- D. 0.000350 over-decays (e.g., uses too small a persistence factor).
- C is correct (partial reversion at 10 days).

📌 Exam tip: GARCH forecasts decay from today's variance toward $$V_L$$ at rate $$(\alpha+\beta)^t$$. The current level (no reversion) and the full long-run level (infinite horizon) are both distractors — finite-horizon forecasts land *between* them.

**Q5.** Empirical daily equity returns are conditionally close to normal yet unconditionally exhibit fat tails. Which explanation is most consistent with this and with the volatility-clustering evidence?

- A. Returns are unconditionally normal but conditionally fat-tailed.
- B. Time-varying volatility mixes normal distributions of differing variance, producing leptokurtosis; regime switching formalizes this.
- C. Positive skewness alone generates the excess kurtosis.
- D. Stale prices fully explain the fat tails independent of volatility dynamics.

**Answer: B**

The ask: identify why conditionally normal returns are unconditionally fat-tailed.

1. If σ changes over time, each day's return is normal *given* that day's σ, but the blend of normals with different variances is a mixture distribution.
2. A mixture of normals with different variances has excess kurtosis (fat tails) even though each component is normal.
3. Regime switching formalizes this: volatility flips between high/low states; within a regime returns look normal, across regimes the blended distribution is leptokurtic. Volatility clustering is the same time-varying-σ phenomenon.

- A reverses the conditioning (the stem says conditionally normal, not conditionally fat-tailed).
- C confuses skewness with kurtosis; skew alone does not produce symmetric fat tails.
- D overstates microstructure effects and ignores the volatility-clustering evidence.
- B is correct.

📌 Exam tip: "Conditionally normal but unconditionally fat-tailed" is the signature of *time-varying volatility* (mixture of normals / regime switching). This is the rationale for EWMA/GARCH: track conditional σ and standardized returns look nearly normal.

**Q6.** Compared with the GARCH(1,1) model, the EWMA model is best described as:

- A. A GARCH(1,1) with ω > 0 that mean-reverts faster.
- B. A GARCH(1,1) special case with ω = 0, α = 1−λ, β = λ, so it has no long-run variance to revert to.
- C. A model that weights all past observations equally, like the historical estimator.
- D. A three-parameter model requiring estimation of ω, α, and β.

**Answer: B**

The ask: relate EWMA to GARCH(1,1) precisely.

1. GARCH(1,1): $$\sigma_n^2 = \omega + \alpha r_{n-1}^2 + \beta\sigma_{n-1}^2$$.
2. EWMA: $$\sigma_n^2 = (1-\lambda) r_{n-1}^2 + \lambda\sigma_{n-1}^2$$.
3. Matching terms: $$\omega = 0$$, $$\alpha = 1-\lambda$$, $$\beta = \lambda$$. Since $$\alpha + \beta = 1$$, the long-run variance $$V_L = \omega/(1-\alpha-\beta)$$ is undefined (0/0) — there is no anchor, so EWMA does not mean-revert.

- A says ω > 0 — false; EWMA has ω = 0, and it does *not* mean-revert at all.
- C describes the equal-weight historical estimator, not EWMA (which uses geometrically declining weights).
- D: EWMA has a *single* parameter (λ), not three.
- B is correct.

📌 Exam tip: EWMA = GARCH with ω = 0 and α + β = 1. The defining contrast: GARCH mean-reverts to $$V_L$$; EWMA does not (flat multi-day forecasts equal to today's estimate).

**Q7.** A risk team updates the covariance between two assets with EWMA (λ = 0.97). Yesterday's covariance estimate was 0.00020, yesterday's return on X was +2.0%, and on Y was −1.5%. The updated covariance is closest to:

- A. 0.000185
- B. 0.000203
- C. 0.000585
- D. 0.000194

**Answer: A**

The ask: apply the EWMA covariance recursion (note the cross-product can be negative).

1. Recursion: $$\text{cov}_n = \lambda\,\text{cov}_{n-1} + (1-\lambda)\,x_{n-1}y_{n-1}$$.
2. Prior term: $$0.97 \times 0.00020 = 0.000194$$.
3. Cross product: $$x\,y = (0.02)(-0.015) = -0.0003$$; $$(1-\lambda)\,xy = 0.03 \times (-0.0003) = -0.000009$$.
4. Sum: $$\text{cov}_n = 0.000194 + (-0.000009) = 0.000185$$.

- B. 0.000203 *adds* the cross product as if positive (sign error: ignores that X up, Y down gives a negative product).
- C. 0.000585 omits the λ weighting or mis-scales.
- D. 0.000194 forgets the new cross-product term entirely.
- A is correct.

📌 Exam tip: The covariance cross product $$x\cdot y$$ keeps its sign — opposite-direction moves *reduce* covariance. Use the *same* λ for variances and covariances to keep the covariance matrix positive semi-definite.

**Q8.** Which statement about implied volatility is correct?

- A. Implied volatility is backward-looking and computed from historical returns.
- B. Implied volatility is forward-looking, backed out of option prices, and tends to exceed subsequently realized volatility because it embeds risk premia.
- C. The volatility smile confirms BSM's assumption of constant volatility across strikes.
- D. The VIX measures the realized 30-day volatility of the S&P 500.

**Answer: B**

The ask: identify the correct characterization of implied volatility.

1. Implied volatility is obtained by *inverting* an option-pricing model (BSM) on observed market prices — it is forward-looking (the market's view over the option's life).
2. Because option prices embed risk premia (and supply/demand for protection), implied volatility tends to sit *above* subsequently realized volatility on average.
3. The smile/skew (implied vol varying by strike) *violates* BSM's constant-σ assumption rather than confirming it.
4. The VIX is *model-free implied* (not realized) 30-day volatility of S&P 500 options.

- A describes statistical/historical volatility, not implied.
- C is backwards: the smile contradicts constant-σ BSM.
- D mislabels VIX as realized; it is implied.
- B is correct.

📌 Exam tip: Implied vol = forward-looking, from prices, usually > realized (risk premium). The smile/skew is evidence *against* BSM's flat-vol assumption. VIX = implied, not realized.
