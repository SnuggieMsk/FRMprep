**Q1.** A stock has an expected (simple) return of 14% per annum and a volatility of 28%. Under the BSM lognormal framework, the mean of the continuously compounded annual return and the standard deviation of $$\ln S_T$$ over a 4-year horizon (T = 4) are closest to:

- A. Mean 10.08%; std dev of ln S_T = 0.560
- B. Mean 14.00%; std dev of ln S_T = 0.280
- C. Mean 10.08%; std dev of ln S_T = 0.280
- D. Mean 13.61%; std dev of ln S_T = 0.560

**Answer: A**

The ask: compute the mean continuously compounded return (with the variance drag) and the standard deviation of log-price over T = 4.

1. Mean of the continuously compounded return:
   $$\mu - \frac{\sigma^2}{2} = 0.14 - \frac{0.28^2}{2} = 0.14 - \frac{0.0784}{2} = 0.14 - 0.0392 = 0.1008 = 10.08\%$$
2. The variance of $$\ln S_T$$ is $$\sigma^2 T$$, so the standard deviation is:
   $$\sigma\sqrt{T} = 0.28 \times \sqrt{4} = 0.28 \times 2 = 0.560$$

- B uses μ itself (14%) as the cc mean — it ignores the −σ²/2 variance drag — and uses σ (not σ√T) for the dispersion.
- C has the right mean but uses σ rather than σ√T for the 4-year dispersion.
- D mis-computes the drag (e.g., subtracts σ²/4) while getting the dispersion right.

📌 Exam tip: The cc return mean is $$\mu - \sigma^2/2$$ (volatility erodes compound growth). The dispersion of $$\ln S_T$$ scales with $$\sqrt{T}$$: std dev = σ√T.

**Q2.** A European call has $$S_0 = 100$$, K = 95, r = 5%, σ = 20%, T = 0.5 years. Given N(0.61) = 0.7291 and N(0.47) = 0.6808, the BSM call value is closest to:

- A. $9.83
- B. $5.00
- C. $11.65
- D. $8.06

**Answer: A**

The ask: compute a full BSM European call price.

1. Compute d₁:
   $$d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}}$$
   $$\ln(100/95) = \ln(1.052632) = 0.051293; \quad (0.05 + 0.02)(0.5) = 0.035$$
   $$d_1 = \frac{0.051293 + 0.035}{0.20 \times 0.707107} = \frac{0.086293}{0.141421} = 0.6102 \approx 0.61$$
2. Compute d₂:
   $$d_2 = d_1 - \sigma\sqrt{T} = 0.6102 - 0.1414 = 0.4688 \approx 0.47$$
3. Look up: N(d₁) = N(0.61) = 0.7291; N(d₂) = N(0.47) = 0.6808.
4. Discount the strike: $$Ke^{-rT} = 95 \times e^{-0.025} = 95 \times 0.975310 = 92.654$$.
5. Call price:
   $$c = S_0 N(d_1) - Ke^{-rT}N(d_2) = 100(0.7291) - 92.654(0.6808)$$
   $$= 72.91 - 63.08 = \$9.83$$

- B ($5.00) is the intrinsic value ($$S_0 - K = 5$$) — it ignores time value entirely.
- C ($11.65) forgets to discount K (uses $$95 \times 0.6808 = 64.68$$... actually larger if the σ²/2 sign is flipped to +; a representative "no-discount/wrong-d₁" error).
- D ($8.06) uses $$r - \sigma^2/2$$ in d₁ instead of $$r + \sigma^2/2$$ — the wrong sign on the variance term.

📌 Exam tip: Two highest-frequency BSM slips: (1) use $$r + \sigma^2/2$$ (not minus) in d₁; (2) discount the strike to $$Ke^{-rT}$$. Both wrong answers appear among the choices. Sanity-check: c > intrinsic ($5) and c < S₀.

**Q3.** Using the same option as Q2 ($$c = \$9.83$$, K = 95, r = 5%, T = 0.5, $$S_0 = 100$$), the BSM European PUT value, found via put-call parity, is closest to:

- A. $2.48
- B. $4.83
- C. $7.35
- D. $0.00

**Answer: A**

The ask: obtain the put price from put-call parity rather than re-running the formula.

1. Put-call parity: $$c + Ke^{-rT} = p + S_0 \;\Rightarrow\; p = c + Ke^{-rT} - S_0$$
2. Discount the strike: $$Ke^{-rT} = 95 \times e^{-0.025} = 95 \times 0.975310 = 92.654$$
3. Solve:
   $$p = 9.83 + 92.654 - 100 = 2.484 \approx \$2.48$$

- B ($4.83) forgets to discount K, using $$9.83 + 95 - 100 = 4.83$$ — the most common parity error.
- C ($7.35) is the call's lower bound $$S_0 - Ke^{-rT} = 7.346$$, not the put.
- D ($0.00) assumes the put is worthless because the call is in the money — ignores parity.

📌 Exam tip: Put-call parity $$p = c + Ke^{-rT} - S_0$$ is the fastest route to the second price AND a free check on the first. Always discount the strike — forgetting to do so is the planted distractor.

**Q4.** A European call is written on a stock index with a continuous dividend yield q = 3%. Which adjustment to the standard (non-dividend) BSM call formula correctly incorporates the dividend yield?

- A. Replace $$S_0$$ with $$S_0 e^{-qT}$$ (and use r − q in d₁).
- B. Replace r with r + q throughout.
- C. Replace K with $$Ke^{-qT}$$.
- D. Add the present value of dividends to $$S_0$$.

**Answer: A**

The ask: identify the correct continuous-dividend-yield adjustment to BSM.

1. For a continuous dividend yield, substitute $$S_0 e^{-qT}$$ for $$S_0$$ in the price formula and use r − q in the drift term of d₁:
   $$c = S_0 e^{-qT}N(d_1) - Ke^{-rT}N(d_2), \quad d_1 = \frac{\ln(S_0/K) + (r - q + \sigma^2/2)T}{\sigma\sqrt{T}}$$
2. Economically, the option holder does not receive dividends, and the stock drops on ex-dates, so the effective forward growth is reduced by q. This LOWERS the call value (and raises the put).

- B (r + q) moves in the wrong direction — it would raise the call value; dividends should lower it.
- C discounts the STRIKE by q, which is meaningless — q affects the underlying's growth, not the strike.
- D describes the DISCRETE-dividend adjustment, and even then dividends are SUBTRACTED from $$S_0$$ (as $$S_0 - PV(\text{divs})$$), not added.

📌 Exam tip: Continuous yield ⟹ replace $$S_0$$ with $$S_0 e^{-qT}$$ and use r − q in d₁. Discrete dividends ⟹ replace $$S_0$$ with $$S_0 - PV(\text{divs})$$. Dividends lower calls and raise puts.

**Q5.** An analyst computes the BSM value of a 3-month European call using the stock's historical volatility and gets $3.10. The same option is quoted in the market at $3.55. Which statement is correct?

- A. The option's implied volatility is higher than the historical volatility.
- B. The option's implied volatility is lower than the historical volatility.
- C. The implied volatility equals the historical volatility.
- D. The market price violates the BSM no-arbitrage bounds.

**Answer: A**

The ask: infer the relationship between implied and historical volatility from the price gap, using vega > 0.

1. Vega is positive: option price rises monotonically with σ. So price and implied vol move together.
2. The market price ($3.55) EXCEEDS the BSM value computed with historical σ ($3.10). To raise the model price to the market price, σ must be increased.
3. Therefore the implied volatility (the σ that reproduces the $3.55 market price) is HIGHER than the historical volatility used to get $3.10.

- B reverses the logic — a higher market price requires a higher, not lower, implied σ.
- C is impossible given the price gap (equal vols would give equal prices).
- D is unsupported — a higher market price is perfectly consistent with a higher implied vol, no bound violation.

📌 Exam tip: Vega > 0 means price and implied vol move together. Market price ABOVE your historical-vol BSM value ⟹ implied vol ABOVE historical. No computation needed — just the sign of vega.

**Q6.** A non-dividend-paying stock's American CALL and the otherwise-identical European call have which relationship, and why?

- A. They have equal value, because an American call on a non-dividend stock is never optimally exercised early.
- B. The American call is strictly more valuable, because early exercise adds value.
- C. The European call is more valuable, because it cannot be exercised prematurely.
- D. They are equal only if the option is at the money.

**Answer: A**

The ask: state the American-vs-European call relationship for a non-dividend stock and the reason.

1. Early exercise of a call on a non-dividend stock is never optimal: exercising forfeits the remaining time value and the interest that could be earned on the strike not yet paid.
2. Because the early-exercise right is never used, it adds no value — the American call's price equals the European call's price.
3. Consequently BSM (a European model) prices the American call exactly, with no adjustment needed.

- B is the trap: the early-exercise FEATURE exists, but it is never optimally exercised on a non-dividend stock, so it adds nothing.
- C is backward — an American option has every right a European has, so it can never be worth less.
- D introduces a false moneyness condition; the equality holds for all strikes.

📌 Exam tip: American call = European call for a NON-dividend stock (never exercise early). With dividends, early exercise of a call can pay just before an ex-date — then use Black's approximation. American PUTS can exceed European puts even with no dividends.

**Q7.** A company has 8 million shares outstanding and issues 2 million warrants (each on one share). The BSM value of an otherwise-equivalent exchange-traded call on the post-announcement stock is $6.00. The approximate value of each warrant, accounting for dilution, is closest to:

- A. $4.80
- B. $6.00
- C. $1.20
- D. $7.50

**Answer: A**

The ask: apply the dilution adjustment to a warrant value.

1. Warrant value with dilution:
   $$\text{Warrant} \approx \frac{N}{N + M} \times c$$
   where N = existing shares = 8 million, M = warrants = 2 million, c = BSM call value = $6.00.
2. Dilution factor:
   $$\frac{N}{N+M} = \frac{8}{8 + 2} = \frac{8}{10} = 0.80$$
3. Warrant value:
   $$0.80 \times 6.00 = \$4.80$$

- B ($6.00) ignores dilution entirely (treats the warrant like an ordinary call).
- C ($1.20) applies the wrong factor $$\frac{M}{N+M} = 0.20$$ (the diluted-away fraction, not the retained fraction).
- D ($7.50) inverts the factor, multiplying by $$\frac{N+M}{N} = 1.25$$.

📌 Exam tip: A warrant is worth $$\frac{N}{N+M} \times c$$ — the call value scaled DOWN by the share-dilution factor (existing shares over total post-exercise shares). The complement $$M/(N+M)$$ is a distractor.
