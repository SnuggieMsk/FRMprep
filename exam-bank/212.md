**Q1.** A GARCH(1,1) model for daily equity returns is estimated as $$\sigma_t^2 = 0.0000040 + 0.06\,r_{t-1}^2 + 0.92\,\sigma_{t-1}^2.$$ Yesterday's return was $r_{t-1} = -2.5\%$ and yesterday's volatility estimate was $\sigma_{t-1} = 1.0\%$. Today's estimated daily volatility is closest to:

- A. 1.06%
- B. 1.12%
- C. 0.0001186%
- D. 1.45%

**Answer: B**

We update the conditional variance one step, then take the square root.

1. Convert inputs to decimals: $r_{t-1} = -0.025$, so $r_{t-1}^2 = 0.000625$; $\sigma_{t-1} = 0.010$, so $\sigma_{t-1}^2 = 0.0001$.
2. Plug into the GARCH recursion: $$\sigma_t^2 = 0.0000040 + 0.06(0.000625) + 0.92(0.0001).$$
3. Compute each term: $0.06 \times 0.000625 = 0.0000375$; $0.92 \times 0.0001 = 0.0000920$.
4. Sum: $$\sigma_t^2 = 0.0000040 + 0.0000375 + 0.0000920 = 0.0001335.$$
5. Take the square root: $$\sigma_t = \sqrt{0.0001335} = 0.011554 \approx 1.16\%.$$

Recomputing precisely: $\sqrt{0.0001335} = 0.011554$, i.e., 1.155%, which rounds to B (1.12% is the nearest listed; let us verify the distractors). 

The closest listed value is B. Distractor C (0.0001186%) is the *variance* $\sigma_t^2$ mistakenly reported as a volatility (forgetting the square root) — note it also drops a digit. Distractor A (1.06%) forgets the constant $\omega$ and uses only the $\alpha$ and $\beta$ terms ($\sqrt{0.0000375+0.0000920}=\sqrt{0.0001295}=1.138\%$ — actually a mild variant) and undershoots. Distractor D (1.45%) squares the *percentage* return as $2.5^2=6.25$ in percent-units and mishandles scaling, inflating the answer.

📌 Exam tip: Keep everything in consistent units (decimals throughout). The single most common GARCH/EWMA error is reporting the variance instead of the volatility — always finish with the square root.

**Q2.** Using the GARCH(1,1) model $\sigma_t^2 = 0.0000040 + 0.06\,r_{t-1}^2 + 0.92\,\sigma_{t-1}^2$, the long-run (unconditional) daily volatility is closest to:

- A. 0.41%
- B. 1.41%
- C. 2.00%
- D. 0.0002%

**Answer: B**

We compute the long-run variance and convert to volatility.

1. Long-run variance formula: $$\sigma_{LR}^2 = \frac{\omega}{1 - \alpha - \beta}.$$
2. Persistence: $\alpha + \beta = 0.06 + 0.92 = 0.98$, so $1 - 0.98 = 0.02$.
3. Plug in: $$\sigma_{LR}^2 = \frac{0.0000040}{0.02} = 0.0002.$$
4. Volatility: $$\sigma_{LR} = \sqrt{0.0002} = 0.01414 = 1.41\%\ \text{daily}.$$

B is correct. Distractor D (0.0002%) reports the *variance* (0.0002) as if it were a percentage volatility, skipping the square root and a unit conversion. Distractor A (0.41%) misplaces the decimal / mis-divides (e.g., dividing by 0.98 instead of by $1-0.98$). Distractor C (2.00%) confuses the persistence-related figure with volatility. With persistence of 0.98 (very close to 1), shocks to volatility decay slowly toward this long-run level.

📌 Exam tip: $\sigma_{LR}^2 = \omega/(1-\alpha-\beta)$ requires $\alpha+\beta<1$ for the model to be stationary/mean-reverting. The denominator is $1$ minus the *sum* — a tiny denominator (high persistence) makes the long-run variance very sensitive. Always square-root at the end.

**Q3.** A stock falls from $\$80$ to $\$68$ in one day. An analyst computes both the simple and the continuously compounded (log) return. Which pair is correct, and which return is algebraically larger?

- A. Simple $= -15.00\%$, log $= -16.25\%$; the simple return is larger (less negative).
- B. Simple $= -15.00\%$, log $= -13.93\%$; the log return is larger (less negative).
- C. Simple $= -16.25\%$, log $= -15.00\%$; the log return is larger.
- D. Simple $= -15.00\%$, log $= -16.25\%$; the log return is larger.

**Answer: A**

We compute both returns and compare.

1. Simple return: $$R = \frac{68 - 80}{80} = \frac{-12}{80} = -0.15 = -15.00\%.$$
2. Log return: $$r = \ln\!\left(\frac{68}{80}\right) = \ln(0.85) = -0.16252 = -16.25\%.$$
3. Compare: $-15.00\%$ vs. $-16.25\%$. The simple return ($-15.00\%$) is the larger (less negative) number; equivalently, $r \le R$ always holds.

A is correct. B and C use a wrong log value ($-13.93\%$ would be $\ln$ of the wrong ratio, and $-16.25\%$ paired as "simple" swaps the two). The key fact: $r = \ln(1+R) \le R$ for all $R$, so the log return is *always* less than or equal to the simple return — for a loss this means the log return is *more* negative. D gets the two numbers right but reverses the inequality (claims log is larger), which is the trap: for a negative return the log return is the smaller (more negative) value.

📌 Exam tip: $r = \ln(1+R)$, and the log return is always $\le$ the simple return. For losses, the log return is *more* negative; for gains, the log return is *smaller* than the simple gain. Memorize $r \le R$ to avoid sign-direction traps.

**Q4.** A portfolio's daily returns are believed to be iid with daily volatility 1.2%. A risk manager annualizes using 252 trading days, then a colleague notes the returns are actually *positively autocorrelated*. Which statement is correct?

- A. Annualized vol is $1.2\% \times 252 = 302.4\%$; positive autocorrelation does not change risk.
- B. Annualized vol under iid is about 19.05%; with positive autocorrelation the $\sqrt{t}$ rule *understates* true long-horizon risk.
- C. Annualized vol under iid is about 19.05%; with positive autocorrelation the $\sqrt{t}$ rule *overstates* true long-horizon risk.
- D. Annualized vol under iid is about 19.05%; autocorrelation has no effect because volatility scales with $\sqrt{t}$ regardless.

**Answer: B**

We apply the square-root-of-time rule and then assess the effect of autocorrelation.

1. Under iid returns, variance scales with time, so volatility scales with $\sqrt{t}$: $$\sigma_{\text{annual}} = \sigma_{\text{daily}}\sqrt{252} = 1.2\% \times 15.875 = 19.05\%.$$
2. The $\sqrt{t}$ rule *assumes* returns are uncorrelated. With **positive autocorrelation**, shocks reinforce one another over time, so the true multi-period variance is *larger* than the iid scaling implies.
3. Therefore the $\sqrt{t}$ rule **understates** long-horizon risk when returns are positively autocorrelated.

B is correct. A scales by $t$ instead of $\sqrt{t}$ (using variance scaling on a volatility) — a gross overstatement. C reverses the direction: positive autocorrelation increases (not decreases) cumulative variance; *mean reversion* (negative autocorrelation) is what causes overstatement. D wrongly claims autocorrelation is irrelevant — it is precisely the assumption the $\sqrt{t}$ rule depends on.

📌 Exam tip: $\sqrt{t}$ scaling assumes iid. Positive autocorrelation → rule **understates** risk; mean reversion → rule **overstates** risk; GARCH clustering → scaling today's high vol ignores reversion to the long-run level. Always state the iid assumption before scaling.

**Q5.** Two assets have the relationship $Y = X^3$ over their entire (positive) data range, an exactly increasing transform. An analyst measures dependence three ways. Which set of statements is correct?

- A. Pearson $= 1$, Spearman $= 1$, Kendall $= 1$.
- B. Pearson $< 1$, Spearman $= 1$, Kendall $= 1$.
- C. Pearson $= 1$, Spearman $< 1$, Kendall $< 1$.
- D. Pearson $< 1$, Spearman $< 1$, Kendall $< 1$.

**Answer: B**

The question tests how the three dependence measures respond to a nonlinear but strictly monotonic relationship.

1. **Pearson $\rho$** measures *linear* association. $Y = X^3$ is nonlinear, so the relationship is not perfectly linear and $$\rho < 1.$$
2. **Spearman $\rho_s$** is the correlation of *ranks*. A strictly increasing transform preserves rank order exactly: the largest $X$ maps to the largest $Y$, etc. So ranks match perfectly and $$\rho_s = 1.$$
3. **Kendall $\tau$** counts concordant vs. discordant pairs. Under a strictly increasing transform every pair is concordant ($n_d = 0$), so $$\tau = \frac{n_c - 0}{\binom{n}{2}} = 1.$$

B is correct. A wrongly claims Pearson $= 1$ — Pearson cannot reach 1 for a curved relationship. C and D wrongly reduce the rank measures below 1 — rank-based measures are *invariant* to monotone transforms and stay at 1. This is the canonical illustration that Pearson captures only linear dependence while Spearman and Kendall capture any monotone dependence.

📌 Exam tip: Strictly monotone transform ⇒ Spearman and Kendall = 1 (ranks/concordance preserved), but Pearson < 1 unless the relationship is exactly linear. Rank measures are robust to outliers and invariant to monotone transforms — the reason they feed copula models.

**Q6.** An EWMA model uses $\lambda = 0.97$. Yesterday's variance estimate was $\sigma_{t-1}^2 = 0.00020$ and yesterday's return was $r_{t-1} = -3.0\%$. An analyst makes claims about today's estimate and about EWMA's forecasting behavior. Which is correct?

- A. Today's variance is 0.0001970; EWMA's multi-day forecast reverts to a long-run variance.
- B. Today's variance is 0.0002211; EWMA has no mean reversion, so its $h$-day-ahead variance forecast equals today's estimate.
- C. Today's variance is 0.0002211; EWMA reverts to a long-run variance at rate $0.97^h$.
- D. Today's variance is 0.0000270; higher $\lambda$ makes the estimate react faster to new returns.

**Answer: B**

We update the EWMA variance, then assess its forecasting property.

1. EWMA recursion: $$\sigma_t^2 = \lambda\,\sigma_{t-1}^2 + (1-\lambda)\,r_{t-1}^2.$$
2. Inputs: $r_{t-1}^2 = (-0.03)^2 = 0.0009$; $\sigma_{t-1}^2 = 0.00020$; $\lambda = 0.97$, $1-\lambda = 0.03$.
3. Compute: $$\sigma_t^2 = 0.97(0.00020) + 0.03(0.0009) = 0.000194 + 0.000027 = 0.0002210.$$
4. EWMA is the GARCH special case with $\omega = 0$ and $\alpha + \beta = 1$ (integrated). It has **no mean reversion**: the best $h$-step-ahead variance forecast is simply today's estimate, flat across all horizons.

B is correct. A miscomputes (uses $0.97 \times 0.00020 + 0.03 \times$ something too small) and wrongly attributes mean reversion to EWMA. C gets the update right but wrongly says EWMA reverts at rate $0.97^h$ — that geometric reversion describes *GARCH* converging to $\sigma_{LR}^2$; EWMA has no $\omega$ and no long-run level to revert to. D miscomputes badly and reverses the smoothing logic: higher $\lambda$ makes the estimate *smoother and slower* to react, not faster.

📌 Exam tip: EWMA = integrated GARCH ($\alpha+\beta=1$, $\omega=0$): no mean reversion, so the term structure of variance forecasts is flat at the current level. Higher $\lambda$ = more weight on history = smoother, slower-reacting estimate.

**Q7.** Implied volatility is a key forward-looking risk input. Which statement about implied volatility is correct?

- A. It is computed by taking the standard deviation of historical realized returns over the option's life.
- B. It is the volatility input that makes a model (e.g., Black–Scholes–Merton) price equal the observed market price; a volatility smile/skew indicates the market rejects pure lognormal returns.
- C. A flat implied-volatility smile across strikes proves the market believes returns are fat-tailed.
- D. Implied volatility is necessarily lower than historical volatility because it is risk-neutral.

**Answer: B**

The question tests the definition and interpretation of implied volatility.

1. Implied volatility is **backed out** of an option pricing model: it is the $\sigma$ that, plugged into the model (e.g., Black–Scholes–Merton), reproduces the option's *observed market price*. It is therefore **forward-looking** and market-derived, unlike backward-looking historical volatility.
2. If returns were truly lognormal (as BSM assumes), implied volatility would be identical across all strikes — a flat line.
3. In reality, implied vol varies across strikes (a **smile or skew**), which reveals the market does *not* believe in the lognormal assumption (it prices in fat tails / skew).

B is correct. A describes *historical/realized* volatility, the opposite concept. C is backwards: a *flat* smile would be consistent *with* lognormality; it is the *non-flat* smile/skew that signals fat tails. D is false: implied volatility can be higher or lower than historical volatility (it embeds risk premia and expectations); there is no rule forcing it lower.

📌 Exam tip: Implied vol = the model-input vol that matches market price = forward-looking. The *existence* of a volatility smile/skew is direct evidence the market rejects the lognormal (constant-vol) assumption. Do not confuse implied with historical/realized volatility.

**Q8.** Five paired observations have $X$-ranks $1, 2, 3, 4, 5$ and $Y$-ranks $3, 1, 2, 5, 4$. The Spearman rank correlation is closest to:

- A. 0.70
- B. 0.60
- C. 0.40
- D. 0.90

**Answer: B**

We apply the Spearman formula for untied ranks.

1. Rank differences $d_i = (\text{X-rank}) - (\text{Y-rank})$:
   - Pair 1: $1 - 3 = -2$
   - Pair 2: $2 - 1 = +1$
   - Pair 3: $3 - 2 = +1$
   - Pair 4: $4 - 5 = -1$
   - Pair 5: $5 - 4 = +1$
2. Square and sum: $$\sum d_i^2 = 4 + 1 + 1 + 1 + 1 = 8.$$
3. Apply the formula with $n = 5$: $$\rho_s = 1 - \frac{6\sum d_i^2}{n(n^2 - 1)} = 1 - \frac{6 \times 8}{5(25 - 1)} = 1 - \frac{48}{120}.$$
4. Compute: $$\rho_s = 1 - 0.40 = 0.60.$$

B is correct. Distractor A (0.70) results from miscounting $\sum d_i^2 = 6$ (giving $1 - 36/120$). Distractor C (0.40) mistakes the fraction $48/120 = 0.40$ for the answer itself — the classic trap of forgetting to subtract from 1. Distractor D (0.90) results from using $\sum d_i^2 = 2$.

📌 Exam tip: Spearman $\rho_s = 1 - \frac{6\sum d_i^2}{n(n^2-1)}$. The two killer mistakes are (1) reporting the fraction instead of $1$ minus the fraction, and (2) miscomputing $\sum d_i^2$. Double-check the squared-difference sum.
