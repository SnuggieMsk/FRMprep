**Q1.** A gap call option has a payoff strike $K_1 = \$55$ and a trigger strike $K_2 = \$50$. At expiration the stock is at $S_T = \$53$. The holder's payoff is *closest* to:

- A. $0
- B. $3
- C. −$2
- D. −$5

**Answer: C**

A gap call pays $S_T - K_1$ whenever $S_T > K_2$ (the trigger), and zero otherwise. The payoff strike and trigger strike differ, so the payoff can be **negative** and is **not** floored at zero.

1. Check the trigger: is $S_T > K_2$? $53 > 50$ → **yes, the option pays out** (exercise is automatic).
2. Compute the payoff using the payoff strike $K_1$: $$S_T - K_1 = 53 - 55 = -\$2$$
3. Because the trigger is met but $S_T < K_1$, the holder receives a **negative** payoff of $-\$2$.

- A ($0) wrongly floors the payoff at zero like a vanilla call — gap payoffs are not floored.
- B ($3) computes $S_T - K_2 = 53 - 50$, using the trigger as the payoff strike (mixing up $K_1$ and $K_2$).
- D (−$5) uses $K_2 - K_1 = 50 - 55$, the strike gap rather than the actual payoff.

📌 Exam tip: For a gap call, the **trigger** $K_2$ decides *whether* it pays; the **payoff strike** $K_1$ decides *how much* ($S_T - K_1$). When $K_1 > K_2$ and $K_2 < S_T < K_1$, the payoff is negative — never floor it at zero.

**Q2.** A down-and-out call is worth $4.20 and the otherwise identical vanilla call (same strike and maturity) is worth $6.50. The down-and-in call with the same barrier is worth:

- A. $2.30
- B. $4.20
- C. $6.50
- D. $10.70

**Answer: A**

We use the barrier parity identity: a knock-in plus the matching knock-out equals the vanilla option.

1. Barrier parity (same $K$, $T$, $H$): $$c_{\text{in}} + c_{\text{out}} = c_{\text{vanilla}}$$
2. Solve for the down-and-in: $$c_{\text{in}} = c_{\text{vanilla}} - c_{\text{out}} = 6.50 - 4.20 = \$2.30$$

- B ($4.20) just restates the knock-out price.
- C ($6.50) restates the vanilla price.
- D ($10.70) **adds** the two ($6.50 + 4.20$) instead of subtracting — the wrong direction of the identity.

📌 Exam tip: **Knock-in + knock-out = vanilla** (same strike, maturity, barrier). If a question gives any two of the three, the third is free marks via subtraction. Each barrier option alone is **cheaper** than the vanilla.

**Q3.** A stock is observed monthly over an option's life at prices 50, 45, 62, 58, and finishes at $S_T = 55$. Consider four options written on this path with $K = 50$ where relevant. Which payoff is computed *correctly*?

- A. Floating lookback call pays $S_T - S_{\max} = 55 - 62 = -\$7$
- B. Fixed lookback call pays $\max(S_{\max} - K, 0) = 62 - 50 = \$12$
- C. Asian average price call pays $S_T - S_{ave} = 55 - 54 = \$1$
- D. Floating lookback put pays $S_{\min} - S_T = 45 - 55 = -\$10$

**Answer: B**

We identify $S_{\min} = 45$, $S_{\max} = 62$, $S_T = 55$, $S_{ave} = (50+45+62+58+55)/5 = 270/5 = 54$, then test each payoff formula.

1. **Fixed lookback call**: $\max(S_{\max} - K, 0) = \max(62 - 50, 0) = \$12$. Choice B is correct.

- A uses the wrong extreme: a floating lookback **call** pays $S_T - S_{\min} = 55 - 45 = \$10$ (buy at the low), not $S_T - S_{\max}$.
- C states the **average strike** call formula ($S_T - S_{ave}$); the **average price** call pays $\max(S_{ave} - K, 0) = \max(54 - 50, 0) = \$4$.
- D mis-signs the floating lookback **put**, which pays $S_{\max} - S_T = 62 - 55 = \$7$ (sell at the high), not $S_{\min} - S_T$.

📌 Exam tip: Floating lookback **call** = $S_T - S_{\min}$ (buy low); floating **put** = $S_{\max} - S_T$ (sell high). Fixed lookback uses $K$ with the extreme. Average **price** uses $K$; average **strike** uses $S_T$.

**Q4.** Compared with an otherwise identical vanilla call, which exotic is correctly paired with its cost relationship and reasoning?

- A. Average price (Asian) call — **dearer**, because it is path-dependent
- B. Barrier knock-out call — **dearer**, because it has an extra trigger feature
- C. Floating lookback call — **cheaper**, because the minimum reduces volatility
- D. Average price (Asian) call — **cheaper**, because averaging reduces effective volatility

**Answer: D**

We match each exotic to its cost relative to vanilla and the correct driver.

1. An **average price (Asian) call** is based on the average underlying price, which is **less volatile** than the single terminal price. Lower effective volatility lowers the option value, so the Asian call is **cheaper** than vanilla. Choice D is correct.

- A reverses the direction: Asian options are cheaper, not dearer; path-dependence alone does not raise value (manipulation resistance is a feature, not a price driver upward).
- B is wrong: a knock-out call can be lost (it dies at the barrier), so it is **cheaper** than vanilla.
- C is wrong: a floating lookback call is **dearer** (it locks in the best entry, $S_T - S_{\min}$), not cheaper.

📌 Exam tip: Cheaper than vanilla → **Asian** (averaging cuts volatility), **barriers** (can be knocked out/never knocked in), **baskets** (correlation < 1). Dearer than vanilla → **lookbacks** (capture the extreme).

**Q5.** A chooser option lets the holder decide at time $T_1$ whether the option is a call or a put (both with the same strike $K$ and final maturity $T_2$). Its value at $T_1$ and its cost relative to a straddle are *best* described as:

- A. Value $\min(c, p)$ at $T_1$; more expensive than a straddle
- B. Value $\max(c, p)$ at $T_1$; cheaper than a straddle
- C. Value $c + p$ at $T_1$; equal to a straddle
- D. Value $\max(c - p, 0)$ at $T_1$; cheaper than a call alone

**Answer: B**

We characterize the chooser's value at the decision date and compare it to a straddle.

1. At $T_1$ the holder keeps whichever option is worth more, so the value is $$\max(c, p)$$
2. A straddle owns **both** a call and a put outright (value $\approx c + p$); a chooser owns only the **better** of the two, so it costs **less** than a straddle while giving similar big-move exposure. Via put-call parity it decomposes into a package of a call and a (smaller) put position.

- A uses $\min(c,p)$ (the holder would never choose the worse one) and the wrong cost ranking.
- C equates it to a straddle ($c + p$) — but the chooser holds only one option after $T_1$, so it is cheaper.
- D gives an exchange-option-style payoff that does not describe a chooser.

📌 Exam tip: Chooser value at the choice date = $\max(c, p)$. It mimics a straddle (profits from big moves) but is **cheaper** because you keep only one leg — a favorite "compare to straddle" distractor.

**Q6.** Which statement contrasting volatility swaps and variance swaps is *most* accurate?

- A. A variance swap pays $L(\sigma_{realized} - \sigma_K)$ and is harder to hedge than a volatility swap.
- B. A volatility swap pays $L(\sigma^2_{realized} - \sigma^2_K)$ and can be statically replicated from vanilla options.
- C. A variance swap pays $L(\sigma^2_{realized} - \sigma^2_K)$ and is easier to value and hedge because variance can be replicated from a static strip of vanilla calls and puts.
- D. Both swaps give exposure to the price direction of the underlying as well as its volatility.

**Answer: C**

We compare the payoffs and hedgeability of volatility versus variance swaps.

1. A **variance swap** pays on realized **variance**: $$L(\sigma^2_{realized} - \sigma^2_K)$$ and is **easier to value and hedge** because variance can be replicated from a **static strip of vanilla calls and puts** across strikes — which is why dealers prefer them.
2. A **volatility swap** pays $L(\sigma_{realized} - \sigma_K)$ (on volatility, not variance) and is harder to replicate.

- A swaps the payoff formulas (variance pays on $\sigma^2$, not $\sigma$).
- B assigns the variance payoff to the volatility swap and the easy replication to the wrong instrument.
- D is wrong: both swaps are **pure volatility** instruments with **no price-direction** exposure.

📌 Exam tip: **Variance swap = $\sigma^2$**, statically replicable from a strip of vanillas → dealers prefer it. **Volatility swap = $\sigma$**, harder to hedge. Neither has directional (delta) exposure.

**Q7.** A dealer wants to hedge a barrier option whose Greeks behave erratically near the barrier, making dynamic delta hedging unreliable. The *most* appropriate technique, and the reason it works, is:

- A. Dynamic delta hedging with more frequent rebalancing, because barriers are smooth
- B. Static option replication: build a portfolio of vanilla options that matches the exotic's value on a chosen boundary, held until the boundary is reached
- C. Buying the underlying outright, because barrier options are equivalent to forwards
- D. A variance swap, because it neutralizes the barrier's price risk

**Answer: B**

The question asks for the preferred hedge for an exotic with unstable Greeks near a barrier.

1. **Static option replication** finds a portfolio of vanilla options that matches the exotic's value along a chosen **boundary** (e.g., along the barrier and at maturity). If two portfolios agree on the whole boundary, they agree inside it.
2. The vanilla portfolio is **bought once and unwound only if the boundary is reached** — avoiding the costly, error-prone continuous rebalancing that breaks down near a barrier (where delta/gamma can swing violently).

- A is wrong: more frequent rebalancing worsens cost and still fails where Greeks blow up near the barrier.
- C is wrong: a barrier option is not equivalent to a forward; the underlying alone does not replicate its conditional payoff.
- D is wrong: a variance swap hedges volatility exposure, not a barrier's conditional payoff.

📌 Exam tip: Near a barrier, **dynamic delta hedging breaks down** (Greeks are unstable). The fix is **static replication** — match the exotic on the boundary with vanilla options, set once, unwind only if the boundary is hit.

**Q8.** Match the exotic to its correct path-dependence and payoff description:

- A. A forward start option is path-dependent and pays a fixed cash amount if in the money.
- B. A compound option is an option on an option, with two strikes and two maturities, and is path-independent.
- C. A cliquet (ratchet) is a single forward start option that pays the maximum price over its life.
- D. An exchange option is path-dependent and pays $\max(S_T^{(1)} + S_T^{(2)}, 0)$.

**Answer: B**

We test the definitions and path-dependence of several exotics.

1. A **compound option** is an option on an option (call-on-call, call-on-put, etc.) with **two strikes and two maturities**: at $T_1$ pay $K_1$ to acquire or sell the underlying option (strike $K_2$, maturity $T_2$). Its payoff depends only on the underlying option's value at $T_1$, so it is **path-independent**. Choice B is correct.

- A is wrong: a forward start option is **path-independent** (a vanilla option that starts at $T_1$, usually ATM then), and it does **not** pay a fixed cash amount (that describes a binary).
- C is wrong: a cliquet is a **series** of forward start options that reset ATM period by period — not a single option, and it does not pay the lifetime maximum.
- D mis-signs the exchange payoff: it is $\max(S_T^{(1)} - S_T^{(2)}, 0)$ (difference, not sum) and is path-independent.

📌 Exam tip: **Path-independent**: gap, forward start, compound, chooser, binary, exchange, basket, rainbow (depend only on terminal values). **Path-dependent**: barrier, lookback, Asian, shout (depend on the price path).
