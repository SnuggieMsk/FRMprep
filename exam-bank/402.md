**Q1.** A portfolio holds $80M in Asset 1 (daily σ = 1.5%) and $50M in Asset 2 (daily σ = 2.5%), with a return correlation of −0.20. Using the delta-normal method, the 99% one-day VaR is closest to:

- A. $3.61M
- B. $5.70M
- C. $4.42M
- D. $3.04M

**Answer: A**

The ask: compute two-asset delta-normal 99% VaR with a negative correlation.

1. Dollar volatilities: $$\sigma_1 = 80 \times 0.015 = \$1.20\text{M}$$; $$\sigma_2 = 50 \times 0.025 = \$1.25\text{M}$$.
2. Portfolio variance: $$\sigma_P^2 = \sigma_1^2 + \sigma_2^2 + 2\rho\sigma_1\sigma_2$$.
3. Plug in: $$= 1.20^2 + 1.25^2 + 2(-0.20)(1.20)(1.25) = 1.44 + 1.5625 - 0.60 = 2.4025$$.
4. Portfolio σ: $$\sigma_P = \sqrt{2.4025} = \$1.550\text{M}$$.
5. VaR: $$2.326 \times 1.550 = \$3.61\text{M}$$.

- B. $5.70M is undiversified VaR — $$2.326 \times (1.20 + 1.25) = 2.326 \times 2.45 = 5.70$$, treating correlation as +1 and ignoring diversification.
- C. $4.42M wrongly uses ρ = +0.20: $$\sqrt{3.0025 + 0.60} = \sqrt{3.6025} = 1.898$$, $$\times 2.326 = 4.42$$ — sign error on the cross term.
- D. $3.04M uses z = 1.96 instead of 2.326.

📌 Exam tip: A negative correlation *subtracts* the cross term, shrinking portfolio VaR. Always confirm the sign of $$2\rho\sigma_1\sigma_2$$ before taking the square root.

**Q2.** From 300 daily historical-simulation P&L observations, the four worst losses (in $000s) are 920, 760, 610, and 540. Using the GARP convention that 99% VaR is the $$n(1-\alpha)$$-th worst loss and 99% ES is the average of the worst $$n(1-\alpha)$$ losses, the 99% VaR and 99% ES are closest to:

- A. VaR = $540K; ES = $610K
- B. VaR = $610K; ES = $763K
- C. VaR = $540K; ES = $708K
- D. VaR = $610K; ES = $708K

**Answer: B**

The ask: find the rank for 99% VaR with n = 300, then the matching tail average for ES.

1. Rank for VaR: $$n(1-\alpha) = 300 \times 0.01 = 3$$ (an integer — no rounding needed). VaR = 3rd worst loss = **$610K**.
2. ES: average of the worst 3 losses = $$\frac{920 + 760 + 610}{3} = \frac{2{,}290}{3} = \$763.3\text{K} \approx \$763\text{K}$$.

- A uses the 4th worst as VaR (wrong rank) and averages the worst 2 for ES.
- C uses the 4th worst as VaR and averages all four worst (708) for ES — both off by one.
- D pairs the correct VaR with a 4-loss ES average ($708) instead of 3.
- B is correct.

📌 Exam tip: For HS, first compute $$n(1-\alpha)$$. When it is an integer, read VaR at exactly that rank; ES is the average of *that many* worst losses — not one more, not one fewer.

**Q3.** A one-day 95% VaR of $1.5M is to be scaled to a 16-day horizon assuming i.i.d. zero-mean returns. A second analyst instead scales it to 16 days by multiplying by 16. The difference between the incorrect and correct 16-day VaR is:

- A. $18.0M
- B. $6.0M
- C. $24.0M
- D. $4.5M

**Answer: A**

The ask: compute the correct √T-scaled VaR, the incorrect ×T VaR, and their difference.

1. Correct (square-root rule): $$\text{VaR}_{16} = 1.5 \times \sqrt{16} = 1.5 \times 4 = \$6.0\text{M}$$.
2. Incorrect (×T): $$1.5 \times 16 = \$24.0\text{M}$$.
3. Difference: $$24.0 - 6.0 = \$18.0\text{M}$$.

- B is the *correct* VaR, not the difference.
- C is the *incorrect* VaR, not the difference.
- D scales σ instead (or divides wrongly).
- A is correct.

📌 Exam tip: Scale VaR (and σ) by $$\sqrt{T}$$, never by T. Variance scales by T. The "×T" answer is always offered as a distractor — and so is the raw correct or incorrect figure when the question asks for a *difference*.

**Q4.** A bank backtests its 99% one-day VaR over 250 trading days and observes 8 exceptions. Under the Basel traffic-light approach and basic backtesting logic, which conclusion is most appropriate?

- A. 8 exceptions is below the 2.5 expected, so the model is too conservative.
- B. The expected number of exceptions is 2.5; 8 falls in the yellow zone, suggesting the model understates risk and the capital multiplier should rise.
- C. 8 exceptions exactly matches expectations for a 95% model, so no action is needed.
- D. 8 exceptions falls in the red zone, requiring the model to be disallowed.

**Answer: B**

The ask: interpret 8 exceptions for a 99%/250-day backtest using the traffic-light zones.

1. Expected exceptions: $$n(1-\alpha) = 250 \times 0.01 = 2.5$$.
2. Observed 8 > 2.5, so the model produces *too many* exceptions — it understates risk.
3. Basel traffic-light zones (250 days, 99%): green ≤ 4, yellow 5–9, red ≥ 10. Eight falls in the **yellow** zone → capital multiplier increases (penalty short of outright rejection).

- A misreads 8 as below expectation; 8 > 2.5.
- C invokes a 95% model — the question fixes 99%; irrelevant.
- D claims red zone, but red requires ≥ 10; 8 is yellow.
- B is correct.

📌 Exam tip: Memorize the 250-day/99% traffic-light cut-offs: green 0–4, yellow 5–9, red ≥ 10. Expected exceptions = $$n(1-\alpha)$$. Too many exceptions → understated risk; far too few → wasted capital.

**Q5.** A risk team must measure one-day VaR for a book of long out-of-the-money call options. Which statement about the appropriate method is correct?

- A. Delta-normal is exact here because the underlying returns are normal.
- B. Delta-normal will understate the curvature (gamma) effect; full-revaluation historical simulation or Monte Carlo is preferred.
- C. Historical simulation cannot capture option non-linearity even with full revaluation.
- D. Monte Carlo is unsuitable because it assumes normally distributed P&L.

**Answer: B**

The ask: choose the correct method rationale for a non-linear (option) portfolio.

1. Options have convex (non-linear) payoffs; the delta-normal method linearizes the payoff using delta only, ignoring gamma.
2. For large moves the delta approximation breaks down, and option P&L is skewed even when the underlying return is normal — so delta-normal mis-measures tail risk.
3. Full-revaluation methods (historical simulation or Monte Carlo) reprice the options under each scenario, capturing convexity. These are preferred.

- A is false: normal underlying returns do not make delta-normal exact for options; the payoff non-linearity remains.
- C is false: HS with full revaluation *does* capture non-linearity — that is its strength.
- D is false: Monte Carlo can use *any* specified distribution and full revaluation; it does not require normal P&L.
- B is correct.

📌 Exam tip: "Options" or "convexity/gamma" in a VaR question signals delta-normal is the *wrong* choice. Full revaluation (HS or MC) is the answer. Remember HS makes no distributional assumption and MC uses whatever distribution you specify.

**Q6.** An annual 95% VaR computed from an annual volatility of 30% on a $40M position is to be converted to a one-day VaR assuming 252 trading days and i.i.d. zero-mean returns. The one-day 95% VaR is closest to:

- A. $1.24M
- B. $0.078M
- C. $19.74M
- D. $0.0784M

**Answer: A**

The ask: compute annual VaR, then scale down to one day by dividing by $$\sqrt{252}$$.

1. Annual VaR: $$1.645 \times 0.30 \times 40 = 1.645 \times 12 = \$19.74\text{M}$$.
2. Scale to one day: divide by $$\sqrt{252} = 15.875$$.
3. One-day VaR: $$\frac{19.74}{15.875} = \$1.243\text{M} \approx \$1.24\text{M}$$.

- B/D divide by 252 (not $$\sqrt{252}$$): $$19.74/252 = 0.0783$$ — the classic scaling trap (using T instead of √T).
- C is the *annual* VaR, not the daily figure.
- A is correct.

📌 Exam tip: To go from a long horizon to a short one, divide by $$\sqrt{T}$$. Dividing by T (252) instead of $$\sqrt{252}$$ understates daily VaR by a factor of ~16 — exactly the distractor offered.

**Q7.** Which limitation is correctly paired with its VaR estimation method?

- A. Historical simulation — assumes returns are normally distributed.
- B. Monte Carlo simulation — limited by the length of the historical data window.
- C. Delta-normal — thin tails and poor handling of non-linear payoffs.
- D. Historical simulation — fastest method but most exposed to model misspecification.

**Answer: C**

The ask: match each method to its true principal weakness.

1. Delta-normal assumes normality (thin tails relative to empirical fat tails) and linearizes options — its two core weaknesses. Correct pairing.
2. Historical simulation makes *no* distributional assumption (so A is wrong) and its main weakness is dependence on the data window (unrepresentative samples, ghost effects).
3. Monte Carlo is *not* limited by a historical window (it generates paths), so B is wrong; its weakness is model misspecification and compute cost.
4. HS is *moderate* speed, not fastest (delta-normal is fastest), and "model misspecification" is the MC weakness — so D is wrong.

- A misattributes the normality assumption to HS.
- B misattributes the data-window limit to MC.
- D mislabels HS as fastest and pins MC's weakness on it.
- C is correct.

📌 Exam tip: Lock down the method–weakness map: delta-normal → thin tails + linearizes options; HS → unrepresentative window/ghosting; MC → model risk + slow. Mismatched pairings are a favorite multiple-choice trap.

**Q8.** A delta-normal VaR for a single long stock position equals $2.4M at 99%. The desk adds a second uncorrelated position whose standalone 99% VaR is $1.8M. What is the combined 99% delta-normal VaR, and does the result respect subadditivity?

- A. $4.20M; equal to the sum, so not diversifying.
- B. $3.00M; below the $4.20M sum, consistent with subadditivity.
- C. $3.00M; above the sum, violating subadditivity.
- D. $1.80M; below the sum, consistent with subadditivity.

**Answer: B**

The ask: combine two independent (ρ = 0) delta-normal VaRs and check subadditivity.

1. For normal P&L, VaR scales with σ, so VaRs combine like volatilities: $$\text{VaR}_P = \sqrt{\text{VaR}_1^2 + \text{VaR}_2^2 + 2\rho\,\text{VaR}_1\text{VaR}_2}$$.
2. With ρ = 0: $$\text{VaR}_P = \sqrt{2.4^2 + 1.8^2} = \sqrt{5.76 + 3.24} = \sqrt{9.00} = \$3.00\text{M}$$.
3. Sum of standalone VaRs = $$2.4 + 1.8 = \$4.20\text{M}$$.
4. Since $$3.00 < 4.20$$, the combined VaR is below the sum — delta-normal VaR is subadditive (it is for elliptical/normal distributions).

- A treats ρ = +1 (just adds the VaRs) — wrong for uncorrelated positions.
- C gets the right $3.00M but mislabels the relationship as a violation.
- D ignores Position 1's contribution.
- B is correct.

📌 Exam tip: For normal positions, VaRs aggregate exactly like volatilities (square, add with the correlation cross term, square-root). Delta-normal VaR is always subadditive — the subadditivity failures occur with non-elliptical (e.g., default) distributions, not here.
