**Q1.** A non-dividend stock trades at $80. Over one 6-month step it moves to either $92 or $70. The 6-month continuously compounded risk-free rate is 4% per annum. A European call with strike $84 is valued by replication / risk-neutral pricing. The call's value today is closest to:

- A. $4.14
- B. $5.00
- C. $4.22
- D. $4.62

**Answer: A**

The ask: value a one-step European call using the risk-neutral probability.

1. Identify u, d from the prices: $$u = 92/80 = 1.15$$, $$d = 70/80 = 0.875$$. Step Δt = 0.5, r = 0.04.
2. Risk-neutral probability:
   $$p = \frac{e^{r\Delta t} - d}{u - d} = \frac{e^{0.04 \times 0.5} - 0.875}{1.15 - 0.875} = \frac{e^{0.02} - 0.875}{0.275}$$
   $$e^{0.02} = 1.020201 \;\Rightarrow\; p = \frac{1.020201 - 0.875}{0.275} = \frac{0.145201}{0.275} = 0.52800$$
3. Terminal call payoffs (strike $84): up state $$\max(92 - 84, 0) = 8$$; down state $$\max(70 - 84, 0) = 0$$.
4. Discounted expected payoff:
   $$c = e^{-r\Delta t}[p \cdot 8 + (1-p) \cdot 0] = e^{-0.02} \times 0.52800 \times 8$$
   $$= 0.980199 \times 4.2240 = \$4.14$$

- B ($5.00) uses a wrong p (≈ 0.625) — e.g., from setting the growth factor too high.
- C ($4.22) forgets to discount the expected payoff ($$0.528 \times 8 = 4.224$$, undiscounted).
- D ($4.62) discounts at the wrong rate or mis-scales Δt in p.

📌 Exam tip: For a one-step tree, derive u and d from the given prices, compute $$p = (e^{r\Delta t} - d)/(u - d)$$, then discount the p-weighted payoff at the risk-free rate. Real-world probabilities never enter.

**Q2.** A stock index has volatility σ = 25% per annum. A binomial tree uses 3-month (quarterly) steps. Using the Cox-Ross-Rubinstein calibration, the up factor u is closest to:

- A. 1.133
- B. 1.077
- C. 1.284
- D. 1.025

**Answer: A**

The ask: calibrate u to volatility for a quarterly step.

1. CRR up factor:
   $$u = e^{\sigma\sqrt{\Delta t}}$$
2. Δt = 3/12 = 0.25, so $$\sqrt{\Delta t} = 0.5$$.
3. Exponent:
   $$\sigma\sqrt{\Delta t} = 0.25 \times 0.5 = 0.125$$
4. Compute:
   $$u = e^{0.125} = 1.13315 \approx 1.133$$

- B (1.077) forgets the square root and uses $$\sigma \cdot \Delta t = 0.25 \times 0.25 = 0.0625$$, giving $$e^{0.0625} = 1.0645$$ — or a related half-step error.
- C (1.284) uses $$e^{\sigma} = e^{0.25} = 1.284$$, ignoring Δt entirely (annual step assumed).
- D (1.025) uses $$\sigma^2 \Delta t$$ or another mis-scaling.

📌 Exam tip: $$u = e^{\sigma\sqrt{\Delta t}}$$ — the time enters as a SQUARE ROOT. For a quarterly step √Δt = 0.5; for monthly √(1/12) ≈ 0.2887. Forgetting the √Δt is the most common slip.

**Q3.** A non-dividend stock is at $100. Over each 6-month step it moves up by u = 1.1 or down by d = 0.9. The continuously compounded risk-free rate is 6% per annum, and the risk-neutral up probability is p = 0.6523. A two-step European call with strike $100 (1-year maturity) is worth closest to:

- A. $8.41
- B. $9.61
- C. $7.55
- D. $13.29

**Answer: A**

The ask: value a two-step European call by backward induction (or the one-shot terminal-payoff shortcut).

1. Terminal stock prices and call payoffs (K = $100):
   - $$S_{uu} = 100 \times 1.1^2 = 121 \Rightarrow \max(121-100,0) = 21$$
   - $$S_{ud} = 100 \times 1.1 \times 0.9 = 99 \Rightarrow \max(99-100,0) = 0$$
   - $$S_{dd} = 100 \times 0.9^2 = 81 \Rightarrow 0$$
2. Probabilities of terminal nodes: $$P(uu) = p^2 = 0.6523^2 = 0.42550$$.
3. European shortcut — discount the probability-weighted terminal payoff over the full year at r:
   $$c = e^{-0.06 \times 1}\left[p^2(21) + 2p(1-p)(0) + (1-p)^2(0)\right]$$
   $$= e^{-0.06} \times 0.42550 \times 21 = 0.941765 \times 8.9355 = 8.415 \approx \$8.41$$

- B ($9.61) forgets to discount over the full year (uses one half-year discount or none).
- C ($7.55) over-discounts or uses a too-low p.
- D ($13.29) is the value at the UP node ($f_u$) — i.e., it stops one step early instead of rolling back to the root.

📌 Exam tip: For European options you can discount the p-weighted TERMINAL payoffs in one shot at $$e^{-rT}$$. Only the $$S_{uu}$$ path is in the money here, so $$c = e^{-rT} p^2 \times 21$$. Don't stop at the up node — that's the value one step too early.

**Q4.** Using the same tree ($$S_0 = 100$$, u = 1.1, d = 0.9, r = 6% continuous, Δt = 0.5, p = 0.6523), an AMERICAN put with strike $100 is valued. The put is worth closest to:

- A. $3.59
- B. $2.59
- C. $7.05
- D. $1.97

**Answer: A**

The ask: value a two-step American put, checking early exercise (max of intrinsic and continuation) at every node.

1. Terminal put payoffs (K = $100): $$S_{uu}=121 \to 0$$; $$S_{ud}=99 \to 1$$; $$S_{dd}=81 \to 19$$.
2. Up node (S = 110): continuation $$= e^{-0.06 \times 0.5}[p \cdot 0 + (1-p) \cdot 1] = e^{-0.03} \times 0.3477 = 0.970446 \times 0.3477 = 0.3374$$. Intrinsic $$= \max(100-110,0) = 0$$. Value = max(0, 0.337) = **0.337**.
3. Down node (S = 90): continuation $$= e^{-0.03}[p \cdot 1 + (1-p) \cdot 19] = 0.970446 \times (0.6523 + 0.3477 \times 19) = 0.970446 \times (0.6523 + 6.6063) = 0.970446 \times 7.2586 = 7.044$$. Intrinsic $$= \max(100-90,0) = 10$$. EXERCISE: max(10, 7.044) = **10**.
4. Root (S = 100): continuation $$= e^{-0.03}[p \cdot 0.337 + (1-p) \cdot 10] = 0.970446 \times (0.6523 \times 0.337 + 0.3477 \times 10) = 0.970446 \times (0.2198 + 3.4770) = 0.970446 \times 3.6968 = 3.588 \approx \$3.59$$. Intrinsic at root = 0, so the continuation value stands.

- B ($2.59) is the EUROPEAN put value — it skips the early-exercise test at the down node and understates the American price.
- C ($7.05) is the down-node continuation value (forgets to exercise and never rolls to the root).
- D ($1.97) results from omitting the deep-ITM down-node payoff weighting.

📌 Exam tip: For American options, take $$\max(\text{intrinsic}, \text{continuation})$$ at EVERY non-terminal node — including the root. Here early exercise at the down node ($10 > $7.04) creates the entire $1.00 premium over the European put.

**Q5.** A binomial tree is built for a European option on a stock INDEX paying a continuous dividend yield of q = 2%. The domestic risk-free rate is r = 5%, u = 1.12, d = 0.89, and the step is 6 months (Δt = 0.5). The risk-neutral up probability is closest to:

- A. 0.543
- B. 0.587
- C. 0.499
- D. 0.522

**Answer: A**

The ask: compute the risk-neutral probability using the dividend-adjusted growth rate in the numerator.

1. For a dividend-paying index, the growth factor uses r − q:
   $$p = \frac{e^{(r-q)\Delta t} - d}{u - d}$$
2. Plug in: r − q = 0.05 − 0.02 = 0.03; Δt = 0.5; so exponent = 0.015.
   $$e^{0.015} = 1.015113$$
3. Compute:
   $$p = \frac{1.015113 - 0.89}{1.12 - 0.89} = \frac{0.125113}{0.23} = 0.5440 \approx 0.543$$

- B (0.587) uses plain r (no dividend adjustment): $$e^{0.025} = 1.025315$$, $$p = 0.135313/0.23 = 0.588$$ — the classic "forgot to subtract q" trap.
- C (0.499) subtracts too much or uses r − 2q.
- D (0.522) mis-scales Δt (e.g., uses Δt = 1 with r − q).

📌 Exam tip: The numerator growth factor is r for a non-dividend stock, r − q for an index/dividend stock, r − r_f for a currency, and 0 for futures. Discounting is ALWAYS at the domestic r. The "use plain r" answer is always offered as a distractor.

**Q6.** In a binomial tree for an option on a FUTURES contract, the correct risk-neutral up probability is:

- A. $$\dfrac{e^{r\Delta t} - d}{u - d}$$
- B. $$\dfrac{1 - d}{u - d}$$
- C. $$\dfrac{e^{(r-q)\Delta t} - d}{u - d}$$
- D. $$\dfrac{e^{-r\Delta t} - d}{u - d}$$

**Answer: B**

The ask: identify the risk-neutral probability for an option on futures.

1. Entering a futures position costs nothing, so in the risk-neutral world a futures price has ZERO drift — its expected growth factor is 1, not $$e^{r\Delta t}$$.
2. Setting the growth factor to 1 in the template $$p = \frac{e^{(\text{growth})\Delta t} - d}{u - d}$$ gives:
   $$p = \frac{1 - d}{u - d}$$
3. Discounting of the expected payoff still occurs at the domestic risk-free rate $$e^{-r\Delta t}$$ — only the numerator drift is zero.

- A is the formula for a non-dividend STOCK (growth = r), not futures.
- C is the dividend-stock/index formula (growth = r − q).
- D nonsensically uses $$e^{-r\Delta t}$$ in the numerator (a sign error).

📌 Exam tip: Futures have zero cost-of-carry drift in the risk-neutral world, so the growth factor is 1 ⟹ $$p = (1-d)/(u-d)$$. Discounting still uses $$e^{-r\Delta t}$$.

**Q7.** At a particular node of an American CALL on a non-dividend-paying stock, the intrinsic value is $6.50 and the continuation (discounted risk-neutral) value is $7.10. The value placed at that node, and the broader principle, is best stated as:

- A. $7.10; an American call on a non-dividend stock is never exercised early, so continuation is taken.
- B. $6.50; early exercise is always optimal for American calls.
- C. $6.80; the average of intrinsic and continuation is used.
- D. $7.10; but the same call should be exercised early if it were deep in the money.

**Answer: A**

The ask: apply the early-exercise rule at a node and recall the no-early-exercise property of American calls on non-dividend stocks.

1. Backward induction uses $$f_{node} = \max(\text{intrinsic}, \text{continuation}) = \max(6.50, 7.10) = 7.10$$.
2. Consistent with theory: an American call on a non-dividend stock is NEVER exercised early — continuation always dominates intrinsic (here 7.10 > 6.50), because exercising forfeits the time value and the interest on the strike not yet paid.

- B is doubly wrong: it picks the smaller value and asserts a false "always exercise" rule.
- C averages the two values — backward induction takes the MAX, never an average.
- D contradicts itself: an American call on a non-dividend stock is never optimally exercised early regardless of moneyness.

📌 Exam tip: $$\max(\text{intrinsic}, \text{continuation})$$ at every node — never an average. An American call on a NON-dividend stock is never exercised early, so its value equals the European call's. Early exercise of calls can pay only with dividends, just before an ex-date.
