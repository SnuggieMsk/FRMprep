**Q1.** A portfolio has daily P&L that is normally distributed with a mean of $40,000 and a daily standard deviation of $250,000. Using a one-day horizon and accounting for the non-zero mean, the 99% VaR is closest to:

- A. $581,500
- B. $541,500
- C. $621,500
- D. $501,500

**Answer: B**

The ask: compute parametric one-day 99% VaR for normal P&L with a positive expected profit, using the full formula (do not drop the mean).

1. Formula: $$\text{VaR}_\alpha = -\mu + z_\alpha\,\sigma$$ with $$z_{0.99} = 2.326$$.
2. Volatility term: $$z_\alpha\,\sigma = 2.326 \times 250{,}000 = 581{,}500$$.
3. Mean term: $$-\mu = -40{,}000$$ (a positive expected gain *reduces* VaR).
4. Combine: $$\text{VaR} = -40{,}000 + 581{,}500 = \$541{,}500$$.

- A. $581,500 ignores the mean entirely (treats μ = 0) — a trap when the question gives a non-zero drift.
- B. $541,500 correctly applies $$-\mu + z\sigma$$.
- C. $621,500 *adds* the mean ($581,500 + 40,000) — wrong sign; a positive expected return must lower VaR, not raise it.
- D. $501,500 over-subtracts (e.g., subtracts $80,000) or mis-scales.

📌 Exam tip: When a positive mean P&L is given, it lowers VaR ($$-\mu$$ term). Only set μ = 0 when the question says to or when the horizon is very short and drift is assumed negligible.

**Q2.** Two independent zero-coupon bonds each default over one year with probability 4%, producing a loss of $20 million if they default and $0 otherwise. A risk manager computes the 95% VaR of each bond standalone and of the equally combined two-bond book. Which statement is correct?

- A. Standalone 95% VaR is $20M each; combined VaR is $40M, so VaR is subadditive here.
- B. Standalone 95% VaR is $0 each; combined 95% VaR is $20M, demonstrating that VaR violates subadditivity.
- C. Standalone 95% VaR is $0 each; combined 95% VaR is $0, so VaR is subadditive.
- D. Standalone 95% VaR is $20M each; combined VaR is $20M, demonstrating subadditivity.

**Answer: B**

The ask: identify the standalone and combined 95% VaR for the classic two-bond counterexample and state the coherence implication.

1. Standalone: P(loss) = 4% < 5%. The 95% quantile of the loss distribution is the loss not exceeded with 95% probability. Since the probability of *any* loss is only 4% (below 5%), the 95th percentile loss is **$0**. So VaR = $0 each; sum = $0.
2. Combined book: P(at least one default) = $$1 - (1-0.04)^2 = 1 - 0.96^2 = 1 - 0.9216 = 0.0784 = 7.84\%$$.
3. Since 7.84% > 5%, the lower 95% tail includes default states, so the 95% quantile loss is at least $20M (one bond defaulting). Combined 95% VaR = **$20M**.
4. Result: $$\text{VaR}(A+B) = \$20\text{M} > \text{VaR}(A) + \text{VaR}(B) = \$0$$ — subadditivity is violated.

- A and D assume each bond's VaR is $20M — wrong, because 4% default probability sits *below* the 5% tail cutoff, so the quantile loss is $0.
- C correctly gets $0 standalone but wrongly claims the combined VaR is $0; with 7.84% > 5% combined default probability, the tail now captures a $20M loss.
- B is correct.

📌 Exam tip: VaR fails subadditivity precisely when individual default probabilities lie *between* one another and the tail level. Diversifying makes measured VaR jump — the textbook reason ES (coherent) is preferred.

**Q3.** A trading book's daily P&L is normal with mean 0 and σ = $4 million. Which of the following is closest to the difference between the 97.5% expected shortfall and the 97.5% VaR? Use $$z_{0.975} = 1.960$$ and $$\phi(1.960) = 0.0584$$.

- A. $1.49M
- B. $1.71M
- C. $0.94M
- D. $2.13M

**Answer: A**

The ask: compute ES − VaR at 97.5% for normal P&L.

1. VaR: $$\text{VaR}_{0.975} = z\,\sigma = 1.960 \times 4 = \$7.840\text{M}$$.
2. ES: $$\text{ES}_{0.975} = \sigma\,\frac{\phi(z)}{1-\alpha} = 4 \times \frac{0.0584}{0.025}$$.
3. Compute the multiplier: $$\frac{0.0584}{0.025} = 2.336$$.
4. ES: $$4 \times 2.336 = \$9.344\text{M}$$.
5. Difference: $$9.344 - 7.840 = \$1.504\text{M} \approx \$1.49\text{M}$$ (rounding of inputs).

- B uses a slightly different φ or divides by 0.0584/0.0250 incorrectly.
- C halves the result (uses $1-\alpha = 0.05$ by mistake).
- D adds rather than computing the spread, or uses the 99% multiplier.
- A is correct.

📌 Exam tip: The ES multiplier $$\phi(z)/(1-\alpha)$$ always exceeds $$z$$, so ES > VaR. At 97.5% the ES multiplier (2.336) is almost exactly the 99% VaR multiplier (2.326) — that near-equality is why FRTB swapped 99% VaR for 97.5% ES.

**Q4.** A risk measure ρ assigns higher numbers to riskier positions. A junior analyst claims VaR is coherent. Which single property does VaR violate in general, and what is the financial consequence?

- A. Translation invariance — adding cash would fail to reduce required capital.
- B. Positive homogeneity — doubling a position would not double VaR.
- C. Subadditivity — combining portfolios can increase measured risk, penalizing diversification.
- D. Monotonicity — a position that always pays less could show lower VaR.

**Answer: C**

The ask: name the coherence property VaR fails and its consequence.

1. The four coherence properties are monotonicity, subadditivity, positive homogeneity, and translation invariance.
2. VaR satisfies monotonicity, positive homogeneity, and translation invariance for any distribution.
3. VaR fails **subadditivity** for non-elliptical distributions: $$\rho(X_1 + X_2)$$ can exceed $$\rho(X_1) + \rho(X_2)$$.
4. Consequence: diversification can appear to *raise* risk, which penalizes pooling positions and invites regulatory arbitrage (splitting a book into desks to lower reported VaR).

- A is false; VaR satisfies translation invariance ($$\rho(X+c) = \rho(X) - c$$).
- B is false; VaR is positively homogeneous.
- D is false; VaR satisfies monotonicity.
- C is correct.

📌 Exam tip: Memorize that VaR fails *only* subadditivity (and only for non-elliptical/non-normal cases). ES satisfies all four — that single failure is the entire case for ES.

**Q5.** A portfolio's loss is normal with μ = 0 and σ = $10M. A manager wants to report a single tail number that (i) is coherent and (ii) reflects the *average* severity of losses in the worst 1% of days. Which measure and value (using $$\phi(2.326) = 0.0267$$) is correct?

- A. 99% VaR = $23.26M
- B. 99% ES = $26.70M
- C. 99% ES = $23.26M
- D. 99% VaR = $26.70M

**Answer: B**

The ask: choose the coherent, average-tail-severity measure (ES, not VaR) and compute 99% ES.

1. VaR is a quantile (frequency of breach), not an average of tail losses, and is not coherent — so it fails both stated requirements. The answer must be ES.
2. Formula: $$\text{ES}_{0.99} = \sigma\,\frac{\phi(z_{0.99})}{1-\alpha} = 10 \times \frac{0.0267}{0.01}$$.
3. Multiplier: $$\frac{0.0267}{0.01} = 2.670$$.
4. ES: $$10 \times 2.670 = \$26.70\text{M}$$.

- A and D report VaR, which is neither coherent nor an average of tail losses — disqualified by the question's criteria.
- C labels ES but plugs in the VaR value ($$2.326 \times 10 = 23.26$$) — it forgot to use the ES multiplier.
- B is correct.

📌 Exam tip: Read the *requirements* in the stem. "Coherent" + "average of the worst losses" both point to ES. Then never reuse the VaR multiplier (z) for ES — use $$\phi(z)/(1-\alpha)$$.

**Q6.** An analyst states: "Two portfolios with identical mean and identical standard deviation are equally risky, so the mean-variance framework ranks them correctly." For which case is this conclusion guaranteed to be valid?

- A. When at least one portfolio contains short option positions.
- B. When both return distributions are elliptical (e.g., both normal).
- C. Whenever the standard deviations are estimated with no sampling error.
- D. When both portfolios have negative skew of equal magnitude.

**Answer: B**

The ask: identify when mean-variance ranking is guaranteed correct.

1. Mean-variance ranking is consistent with expected utility only when the distribution is fully described by μ and σ — true for **elliptical** distributions (normal, t with finite variance).
2. If both are elliptical with the same μ and σ, they have the same distribution, so they are genuinely equally risky.
3. Skew or fat tails add information σ cannot capture; two distributions with equal μ and σ but different higher moments can have very different tail risk.

- A: short options create skew/non-linearity — mean-variance breaks down.
- C: accurate σ does not help if the distribution is non-elliptical; the framework is wrong regardless of estimation precision.
- D: equal negative skew of equal magnitude is not guaranteed by equal σ, and skew itself voids the framework's sufficiency; this is not the guaranteed-valid case.
- B is correct.

📌 Exam tip: The mean-variance framework's validity hinges on the *distribution class* (elliptical), not on estimation quality. "Accurate σ" distractors are designed to mislead — accuracy of inputs is irrelevant if the model assumes the wrong shape.

**Q7.** A normal portfolio P&L has μ = 0. An analyst computes 95% VaR using $$z = 1.645$$ but mistakenly looks up $$z = 1.282$$ (the 90% value). If true σ = $8M, by how much does the analyst *understate* the 95% VaR?

- A. $2.90M
- B. $10.26M
- C. $13.16M
- D. $1.45M

**Answer: A**

The ask: compute the dollar understatement caused by using the 90% z-value instead of the 95% z-value.

1. Correct 95% VaR: $$1.645 \times 8 = \$13.16\text{M}$$.
2. Erroneous VaR (90% z): $$1.282 \times 8 = \$10.256\text{M} \approx \$10.26\text{M}$$.
3. Understatement: $$13.16 - 10.256 = \$2.904\text{M} \approx \$2.90\text{M}$$.

- B is the *erroneous* VaR itself, not the difference.
- C is the *correct* VaR, not the difference.
- D uses $$(1.645 - 1.282) \times 4$$ or otherwise halves σ.
- A is correct: $$(1.645 - 1.282) \times 8 = 0.363 \times 8 = 2.904$$.

📌 Exam tip: When a question describes a z-value mix-up, compute both VaRs and take the difference. The shortcut is $$(\Delta z) \times \sigma$$. Common confidence z-values to memorize: 90% = 1.282, 95% = 1.645, 97.5% = 1.960, 99% = 2.326.
