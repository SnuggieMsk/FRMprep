# Formula Sheets

One sheet per book — every formula that is fair game on the exam, with the
variable definitions and the classic traps noted inline. No formula sheet is
provided at the exam: in the final two weeks, write each of these out from
memory daily until you can.

{: .tip }
Don't memorize formulas as symbol strings — memorize them as *sentences*
(e.g., "forward price is spot grown at the carry rate net of income").
Sentences survive exam stress; symbol strings don't.
