# 12. Measuring Returns, Volatility, and Correlation

Simple vs. log returns, annualization, the stylized facts of volatility, EWMA and GARCH(1,1) updating, implied volatility, and the three correlation measures. EWMA/GARCH update arithmetic is a near-certain exam computation.

## Learning objectives

- Calculate, distinguish, and convert between simple and continuously compounded (log) returns.
- Define and calculate annualized volatility; apply the square-root-of-time rule and its limitations.
- Describe how the jump-diffusion view and fat-tailed/skewed distributions relate to observed returns.
- Explain how the implied volatility of an option is determined and what it represents.
- Describe alternative measures of dependence: Pearson, Spearman rank, and Kendall's tau.
- Estimate and update volatility using EWMA and GARCH(1,1); explain mean reversion of volatility and the long-run variance.

## Simple vs. log returns

**Simple (holding-period) return:**

$$R_t = \frac{P_t - P_{t-1}}{P_{t-1}}$$

**Log (continuously compounded) return:**

$$r_t = \ln\!\left(\frac{P_t}{P_{t-1}}\right) = \ln(1 + R_t)$$

- Log returns **add across time**: $$r_{0,T} = \sum_t r_t$$ — ideal for time aggregation.
- Simple returns **aggregate across assets**: portfolio return = weighted average of component simple returns (not true for log returns).
- $$r_t \le R_t$$ always, with near-equality for small returns; log returns can go to $$-\infty$$, simple returns are bounded below by $$-100\%$$.

## Volatility and annualization

Volatility $$\sigma$$ = standard deviation of returns. Under iid returns, variance scales with time, so with 252 trading days:

$$\sigma_{\text{annual}} = \sigma_{\text{daily}}\sqrt{252}, \qquad \sigma_{\text{monthly}} = \sigma_{\text{annual}}/\sqrt{12}$$

{: .warning }
The $$\sqrt{t}$$ rule assumes iid (uncorrelated, constant-variance) returns. With positively autocorrelated returns it *understates* long-horizon risk; with mean reversion it *overstates* it; with GARCH-style clustering, scaling today's high volatility by $$\sqrt{t}$$ ignores reversion to the long-run level. State the assumption before you scale.

**Stylized facts:** return distributions are fat-tailed (excess kurtosis), often negatively skewed, and volatility clusters in time. A jump-diffusion view — smooth diffusion punctuated by occasional jumps — and conditional-volatility models both generate these features even with conditionally normal shocks.

**Implied volatility:** the $$\sigma$$ that equates a model (Black–Scholes–Merton) price to the observed market option price — a forward-looking, risk-neutral market forecast, unlike backward-looking historical estimates. The variation of implied vol across strikes (smile/skew) shows the market does not believe in lognormal returns.

## EWMA

The exponentially weighted moving average updates variance with one parameter $$\lambda$$ (RiskMetrics: $$\lambda = 0.94$$ daily):

$$\sigma_t^2 = \lambda\,\sigma_{t-1}^2 + (1 - \lambda)\,r_{t-1}^2$$

Weights on past squared returns decay geometrically: $$(1-\lambda)\lambda^k$$. Higher $$\lambda$$ ⇒ smoother, slower-reacting estimate. EWMA has **no mean reversion** — its long-horizon forecast is just the current variance.

## GARCH(1,1)

$$\sigma_t^2 = \omega + \alpha\,r_{t-1}^2 + \beta\,\sigma_{t-1}^2$$

with $$\alpha + \beta < 1$$ for covariance stationarity. The **long-run (unconditional) variance**:

$$\sigma_{LR}^2 = \frac{\omega}{1 - \alpha - \beta}$$

GARCH = EWMA plus a pull toward $$\sigma^2_{LR}$$; EWMA is the special case $$\omega = 0$$, $$\alpha = 1-\lambda$$, $$\beta = \lambda$$ (then $$\alpha + \beta = 1$$: integrated, no mean reversion). Persistence $$\alpha + \beta$$ governs how slowly shocks to volatility decay; multi-step forecasts converge to $$\sigma_{LR}^2$$ geometrically at rate $$(\alpha+\beta)^h$$.

## Measures of dependence

| Measure | What it captures | Range | Robust to outliers? | Invariant to monotone transforms? |
|---|---|---|---|---|
| Pearson $$\rho$$ | Linear association | $$[-1,1]$$ | No | No (only linear) |
| Spearman $$\rho_s$$ | Monotonic association (correlation of **ranks**) | $$[-1,1]$$ | Yes | Yes |
| Kendall $$\tau$$ | Concordance of pairs | $$[-1,1]$$ | Yes | Yes |

**Spearman:** with no ties, $$\rho_s = 1 - \frac{6\sum d_i^2}{n(n^2-1)}$$ where $$d_i$$ = rank differences.

**Kendall:** $$\tau = \frac{n_c - n_d}{\binom{n}{2}}$$, concordant minus discordant pairs over total pairs.

{: .note }
Pearson correlation captures only *linear* dependence and fully characterizes dependence only for elliptical (e.g., jointly normal) distributions. Rank measures survive nonlinear but monotone relationships ($$Y = X^3$$ has Spearman/Kendall = 1, Pearson < 1) and are the natural inputs for copula-based models.

### Worked example: returns and annualization

A stock goes from \$100 to \$94 in one day.

$$R = \frac{94 - 100}{100} = -6.00\%, \qquad r = \ln(0.94) = -6.19\%$$

Over a year its daily log returns have standard deviation 1.4%:

$$\sigma_{\text{annual}} = 1.4\% \times \sqrt{252} = 1.4\% \times 15.87 = 22.2\%$$

Two-day cumulative log return after days of $$+2\%$$ and $$-1\%$$ (log): simply $$+1\%$$. The simple-return equivalent: $$e^{0.01} - 1 = 1.005\%$$.

### Worked example: EWMA update

$$\lambda = 0.94$$, yesterday's volatility estimate $$\sigma_{t-1} = 1.0\%$$/day, yesterday's return $$r_{t-1} = 2.0\%$$.

$$\sigma_t^2 = 0.94 \times (0.01)^2 + 0.06 \times (0.02)^2 = 0.000094 + 0.000024 = 0.000118$$

$$\sigma_t = \sqrt{0.000118} = 1.086\%$$

A 2-sigma move lifts the vol estimate by about 9% in one day.

### Worked example: GARCH(1,1) update and long-run variance

$$\sigma_t^2 = 0.000002 + 0.10\,r_{t-1}^2 + 0.85\,\sigma_{t-1}^2$$, with $$r_{t-1} = 1.5\%$$ and $$\sigma_{t-1} = 1.2\%$$.

**Update:**

$$\sigma_t^2 = 0.000002 + 0.10(0.015)^2 + 0.85(0.012)^2$$

$$= 0.000002 + 0.0000225 + 0.0001224 = 0.0001469$$

$$\sigma_t = 1.212\%$$

**Long-run variance and volatility:**

$$\sigma_{LR}^2 = \frac{0.000002}{1 - 0.10 - 0.85} = \frac{0.000002}{0.05} = 0.00004 \;\Rightarrow\; \sigma_{LR} = 0.632\%\ \text{daily}$$

Annualized: $$0.632\% \times \sqrt{252} \approx 10.0\%$$. Current vol (1.21%) is far above the long-run level, so multi-day GARCH forecasts decline toward 0.632% at rate $$0.95^h$$.

### Worked example: Spearman rank correlation

Five paired observations, ranks of $$X$$: 1, 2, 3, 4, 5; ranks of $$Y$$: 2, 1, 4, 3, 5. Differences $$d$$: −1, 1, −1, 1, 0; $$\sum d^2 = 4$$.

$$\rho_s = 1 - \frac{6 \times 4}{5(25 - 1)} = 1 - \frac{24}{120} = 0.80$$

## Quick quiz

**1.** A price falls from \$50 to \$45. The log return is closest to:

- A. $$-10.00\%$$
- B. $$-10.54\%$$
- C. $$-9.53\%$$
- D. $$-11.11\%$$

**2.** GARCH(1,1): $$\omega = 0.000003$$, $$\alpha = 0.08$$, $$\beta = 0.90$$. The long-run daily volatility is closest to:

- A. 1.22%
- B. 0.015%
- C. 0.55%
- D. 1.73%

**3.** Relative to GARCH(1,1), the EWMA model:

- A. Has more parameters
- B. Mean-reverts faster
- C. Has no mean reversion (it is the $$\alpha + \beta = 1$$, $$\omega = 0$$ case)
- D. Weights all past returns equally

**4.** $$Y = e^X$$ (a strictly increasing transform). Compared with the Pearson correlation of $$(X, Y)$$, the Spearman correlation is:

- A. Exactly 1
- B. Exactly 0
- C. Lower
- D. Undefined

<details markdown="1">
<summary>Show answers</summary>

**1. B** — $$\ln(45/50) = \ln(0.9) = -10.54\%$$. (A is the simple return.)

**2. A** — $$\sigma^2_{LR} = 0.000003/0.02 = 0.00015$$; $$\sigma = 1.22\%$$.

**3. C** — EWMA is integrated: shocks to variance never decay toward a long-run level.

**4. A** — Ranks are preserved under any strictly increasing transform, so $$\rho_s = 1$$; Pearson is below 1 because the relation is nonlinear.

</details>
