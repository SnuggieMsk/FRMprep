# 6. Hypothesis Testing

For 2026, GARP reworded this chapter's LOs toward *applied* testing: construct the test, compute the statistic, state the decision, and read p-values and confidence intervals correctly. Expect numbers, not definitions.

## Learning objectives

- Construct an appropriate null hypothesis and alternative hypothesis and distinguish between them.
- Differentiate between one-sided and two-sided tests and identify when each applies.
- Explain the difference between Type I and Type II errors and how they relate to the size and power of a test.
- Calculate and interpret the test statistic for a hypothesis about a population mean.
- Explain what the p-value of a hypothesis test measures; interpret test results at a given confidence level.
- Construct and apply confidence intervals for one-sided and two-sided tests; explain how a hypothesis test and confidence interval are related.
- Identify the steps to test a hypothesis about the difference between two population means.
- Explain the problem of multiple testing and how it can bias results.

## Setting up the test

- **Null hypothesis $$H_0$$:** the maintained claim, always contains the equality (e.g., $$\mu = \mu_0$$, $$\mu \le \mu_0$$). The test can *reject* or *fail to reject* $$H_0$$ — it never "accepts" it.
- **Alternative $$H_1$$:** what you conclude if the data are sufficiently inconsistent with $$H_0$$.
- **Two-sided:** $$H_1: \mu \ne \mu_0$$ — reject for large $$\lvert z \rvert$$; split $$\alpha$$ across both tails (5% test: critical value 1.96).
- **One-sided:** $$H_1: \mu > \mu_0$$ (or $$<$$) — all of $$\alpha$$ in one tail (5% test: 1.645).

{: .warning }
One- vs. two-tailed is the most common point thrown away in this chapter. At $$\alpha = 5\%$$: two-tailed critical value 1.96, one-tailed 1.645. A statistic of 1.80 rejects a one-sided null but fails to reject a two-sided one. Let the wording ("differs from" vs. "exceeds") choose the test for you.

## Test statistics

For a mean with known variance (or large $$n$$):

$$z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$$

With unknown variance and small samples, use the t-statistic with $$n - 1$$ degrees of freedom:

$$t = \frac{\bar{X} - \mu_0}{s/\sqrt{n}}$$

Decision rule: reject $$H_0$$ when the statistic falls beyond the critical value(s) for the chosen size $$\alpha$$.

## Errors, size, and power

| | $$H_0$$ true | $$H_0$$ false |
|---|---|---|
| Reject $$H_0$$ | **Type I error** (prob. = $$\alpha$$, the *size*) | Correct (prob. = **power** $$= 1 - \beta$$) |
| Fail to reject | Correct | **Type II error** (prob. = $$\beta$$) |

- Size $$\alpha$$ is chosen by the tester (5% standard, 1% strict).
- Power rises with sample size, with a larger true deviation from $$H_0$$, and with a larger $$\alpha$$.
- For fixed $$n$$, decreasing $$\alpha$$ increases $$\beta$$: the only free lunch is more data.

## p-values

The **p-value** is the probability, computed assuming $$H_0$$ is true, of a test statistic at least as extreme as the one observed. Equivalently, the smallest $$\alpha$$ at which you would reject. Reject when p-value $$< \alpha$$.

{: .warning }
The p-value is **not** the probability that $$H_0$$ is true, and $$1 - p$$ is not the probability $$H_1$$ is true. It is a statement about the data given the null, not about the null given the data. GARP tests this wording directly.

## Confidence intervals and their duality with tests

A $$(1-\alpha)$$ two-sided confidence interval for $$\mu$$:

$$\bar{X} \pm z_{\alpha/2}\,\frac{\sigma}{\sqrt{n}} \qquad \text{(or } t_{\alpha/2,\,n-1}\, s/\sqrt{n}\text{)}$$

A one-sided 95% interval uses 1.645 and is unbounded on one side, e.g. $$(\bar X - 1.645\,\sigma/\sqrt{n},\; \infty)$$.

**Duality:** a two-sided test of size $$\alpha$$ rejects $$H_0: \mu = \mu_0$$ exactly when $$\mu_0$$ lies **outside** the $$(1-\alpha)$$ confidence interval. The CI is the set of all nulls that would not be rejected.

## Difference between two means

For independent samples with large $$n$$:

$$z = \frac{(\bar{X}_1 - \bar{X}_2) - (\mu_1 - \mu_2)_0}{\sqrt{\dfrac{s_1^2}{n_1} + \dfrac{s_2^2}{n_2}}}$$

Steps: (1) state $$H_0: \mu_1 - \mu_2 = 0$$; (2) compute the difference of sample means; (3) compute the standard error by summing the variance contributions; (4) form the statistic; (5) compare to the critical value. For paired data, test the mean of the differences instead.

## Multiple testing

Running many tests at $$\alpha = 5\%$$ inflates the family-wide false-positive rate: with $$k$$ independent true nulls,

$$P(\text{at least one rejection}) = 1 - (1 - \alpha)^k$$

For $$k = 10$$: $$1 - 0.95^{10} = 40.1\%$$. Consequences in finance: backtest overfitting, data snooping, "discovering" fund-manager skill by scanning thousands of funds. Remedies: the **Bonferroni** correction (use $$\alpha / k$$ per test), out-of-sample validation, and skepticism toward selected (best-of-many) results.

### Worked example: two-sided t-test on a mean

A strategy's 25 monthly returns average 0.80% with sample standard deviation 2.0%. Test $$H_0: \mu = 0$$ vs. $$H_1: \mu \ne 0$$ at 5%.

$$t = \frac{0.80 - 0}{2.0/\sqrt{25}} = \frac{0.80}{0.40} = 2.00$$

Critical value $$t_{0.025, 24} = 2.064$$. Since $$2.00 < 2.064$$, **fail to reject** — no significant evidence of nonzero mean return. (Had the test been one-sided, $$t_{0.05,24} = 1.711$$ and we would reject — the one-/two-tail choice flips the answer.)

### Worked example: z-test, p-value, and CI together

A VaR model should produce exceptions on 1% of days. Over $$n = 500$$ days you observe 9 exceptions, i.e. $$\hat{p} = 0.018$$. Test $$H_0: p = 0.01$$ (two-sided, 5%).

Standard error under $$H_0$$: $$\sqrt{0.01 \times 0.99 / 500} = \sqrt{0.0000198} = 0.00445$$.

$$z = \frac{0.018 - 0.010}{0.00445} = 1.798$$

p-value $$= 2 \times P(Z > 1.798) = 2 \times 0.0361 = 0.0722$$. Since $$0.0722 > 0.05$$, fail to reject: the exception rate is not statistically distinguishable from 1%. Consistently, the 95% CI for $$p$$, $$0.018 \pm 1.96 \times \sqrt{0.018 \times 0.982/500} = 0.018 \pm 0.0116 = (0.64\%,\, 2.96\%)$$, contains 1%.

### Worked example: difference of means

Desk A: $$n_1 = 60$$ days, mean P&L 1.5, $$s_1 = 4$$. Desk B: $$n_2 = 40$$ days, mean P&L 0.2, $$s_2 = 5$$. Test equal means at 5% (two-sided).

$$SE = \sqrt{\frac{16}{60} + \frac{25}{40}} = \sqrt{0.2667 + 0.6250} = \sqrt{0.8917} = 0.9443$$

$$z = \frac{1.5 - 0.2}{0.9443} = \frac{1.3}{0.9443} = 1.377$$

$$1.377 < 1.96$$: fail to reject — the desks' mean P&Ls are not significantly different.

### Worked example: power and Type II error

Returns are $$N(\mu, 2^2)$$, $$n = 16$$, so $$SE = 2/4 = 0.5$$. One-sided test of $$H_0: \mu = 0$$ vs. $$H_1: \mu > 0$$ at 5% rejects when $$\bar X > 1.645 \times 0.5 = 0.8225$$. If the true mean is $$\mu = 1$$:

$$\text{Power} = P(\bar X > 0.8225 \mid \mu = 1) = P\!\left(Z > \frac{0.8225 - 1}{0.5}\right) = P(Z > -0.355) = 0.639$$

So power ≈ 63.9% and the Type II error rate is $$\beta \approx 36.1\%$$. Doubling $$n$$ to 64 halves the SE to 0.25, threshold 0.411, and power jumps to $$P(Z > -2.355) \approx 99.1\%$$.

### Worked example: multiple testing

An analyst screens 20 independent trading signals, each tested at 5%, all actually useless. Probability at least one looks "significant":

$$1 - 0.95^{20} = 1 - 0.3585 = 64.2\%$$

Bonferroni fix: test each at $$0.05/20 = 0.25\%$$, keeping the family-wise error rate at about 5%.

## Quick quiz

**1.** A sample of 36 returns has mean 1.2% and standard deviation 3.6%. The t-statistic for $$H_0: \mu = 0$$ is:

- A. 0.33
- B. 1.20
- C. 2.00
- D. 12.0

**2.** A test statistic has a p-value of 0.03. Which is TRUE?

- A. There is a 3% probability that $$H_0$$ is true
- B. Reject $$H_0$$ at 5% but not at 1%
- C. Reject $$H_0$$ at 1% but not at 5%
- D. The power of the test is 97%

**3.** Reducing the significance level from 5% to 1% with a fixed sample:

- A. Decreases both Type I and Type II error probabilities
- B. Decreases Type I but increases Type II error probability
- C. Increases power
- D. Increases the size of the test

**4.** A 95% confidence interval for a regression coefficient is $$(0.4, 2.6)$$. A two-sided 5% test of $$H_0: \beta = 0$$ would:

- A. Fail to reject, since the interval contains positive values
- B. Reject, since 0 lies outside the interval
- C. Be inconclusive without the t-statistic
- D. Reject only at the 1% level

<details markdown="1">
<summary>Show answers</summary>

**1. C** — $$t = 1.2 / (3.6/\sqrt{36}) = 1.2 / 0.6 = 2.0$$.

**2. B** — Reject whenever p-value $$< \alpha$$: $$0.03 < 0.05$$ but $$0.03 > 0.01$$. (A) is the classic misreading of a p-value.

**3. B** — Smaller $$\alpha$$ means fewer rejections: fewer false positives (Type I) but more missed detections (Type II); power falls.

**4. B** — By test–CI duality, any value outside the 95% CI is rejected at 5%; 0 is outside $$(0.4, 2.6)$$.

</details>
