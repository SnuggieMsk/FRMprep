# 4. Multivariate Random Variables

This chapter covers joint behavior: marginal and conditional distributions, covariance and correlation, portfolio variance algebra, and iid sums. The portfolio-variance formula and covariance algebra are among the most tested computations in Book 2.

## Learning objectives

- Explain how a probability matrix can be used to express a probability mass function for a bivariate distribution.
- Compute the marginal and conditional distributions of a discrete bivariate random variable.
- Explain how the expectation of a function is computed for a bivariate discrete random variable.
- Define covariance and explain what it measures.
- Explain the relationship between the covariance and correlation of two random variables, and how these are related to the independence of the two variables.
- Explain the effects of applying linear transformations on the covariance and correlation between two random variables.
- Compute the variance of a weighted sum of two random variables.
- Compute the conditional expectation of a component of a bivariate random variable.
- Describe the features of an iid sequence of random variables.
- Explain how the iid property is helpful in computing the mean and variance of a sum of iid random variables.

## Probability matrices, marginals, and conditionals

A discrete bivariate PMF can be laid out as a **probability matrix** $$f(x, y) = P(X = x, Y = y)$$. From it:

- **Marginal**: sum across the other variable, $$f_X(x) = \sum_y f(x, y)$$.
- **Conditional**: divide the joint by the marginal,

$$f_{Y \mid X}(y \mid x) = \frac{f(x, y)}{f_X(x)}$$

- **Independence**: $$f(x, y) = f_X(x) f_Y(y)$$ for **every** cell. One failing cell kills independence.
- **Expectation of a function**: $$E[g(X, Y)] = \sum_x \sum_y g(x, y) f(x, y)$$.
- **Conditional expectation**: $$E[Y \mid X = x] = \sum_y y\, f_{Y\mid X}(y \mid x)$$.

## Covariance and correlation

$$\mathrm{Cov}(X, Y) = E[(X - \mu_X)(Y - \mu_Y)] = E[XY] - E[X]E[Y]$$

$$\rho_{XY} = \frac{\mathrm{Cov}(X, Y)}{\sigma_X \sigma_Y}, \qquad -1 \le \rho \le 1$$

Covariance measures the direction of **linear** co-movement; its units are the product of the variables' units. Correlation is the unit-free version. Key facts:

- $$\mathrm{Cov}(X, X) = \mathrm{Var}(X)$$
- Independence $$\Rightarrow$$ $$\mathrm{Cov} = 0$$, but zero covariance does **not** imply independence in general.
- For **jointly normal** variables (only), zero correlation does imply independence.

{: .warning }
"Uncorrelated" means "no *linear* relationship." $$Y = X^2$$ with symmetric $$X$$ has $$\rho = 0$$ yet perfect dependence. The exception — zero correlation implies independence — holds only under joint normality. This exact distinction is a perennial exam question.

## Linear transformations

For $$a, b, c, d$$ constants:

$$\mathrm{Cov}(aX + b,\; cY + d) = ac\,\mathrm{Cov}(X, Y)$$

$$\rho(aX+b,\, cY+d) = \mathrm{sign}(ac)\,\rho(X, Y)$$

Correlation is unchanged in magnitude by linear transformations — only its sign can flip.

## Variance of a weighted sum (portfolio variance)

$$\mathrm{Var}(aX + bY) = a^2 \sigma_X^2 + b^2 \sigma_Y^2 + 2ab\,\mathrm{Cov}(X, Y)$$

With correlation: $$\mathrm{Cov}(X,Y) = \rho \sigma_X \sigma_Y$$. For a difference, set $$b = -1$$:

$$\mathrm{Var}(X - Y) = \sigma_X^2 + \sigma_Y^2 - 2\,\mathrm{Cov}(X, Y)$$

{: .tip }
Diversification in one line: with $$\rho < 1$$ the cross term is less than $$2ab\,\sigma_X\sigma_Y$$, so portfolio standard deviation is below the weighted average of component standard deviations.

## IID sequences

Variables are **iid** when they are mutually independent and share one distribution. For $$X_1, \dots, X_n$$ iid with mean $$\mu$$ and variance $$\sigma^2$$:

$$E\left[\sum X_i\right] = n\mu, \qquad \mathrm{Var}\left(\sum X_i\right) = n\sigma^2, \qquad \sigma_{\text{sum}} = \sigma\sqrt{n}$$

Variance of the sum grows linearly in $$n$$; standard deviation grows with $$\sqrt{n}$$. This is the source of the **square-root-of-time** volatility scaling rule.

{: .warning }
$$\sqrt{t}$$ scaling requires iid returns — zero autocorrelation and constant variance. With positive autocorrelation, true multi-period risk *exceeds* $$\sigma\sqrt{t}$$; with mean reversion it is lower. GARP likes asking when the rule breaks.

### Worked example: probability matrix

Joint PMF of market state $$X$$ (0 = down, 1 = up) and a fund's result $$Y$$ (0 = loss, 1 = gain):

| | $$Y=0$$ | $$Y=1$$ | $$f_X$$ |
|---|---|---|---|
| $$X=0$$ | 0.20 | 0.10 | 0.30 |
| $$X=1$$ | 0.15 | 0.55 | 0.70 |
| $$f_Y$$ | 0.35 | 0.65 | 1.00 |

**Conditional:** $$P(Y=1 \mid X=1) = 0.55 / 0.70 = 0.7857$$.

**Conditional expectation:** $$E[Y \mid X = 1] = 0(0.2143) + 1(0.7857) = 0.7857$$.

**Covariance:** $$E[XY] = 1 \cdot 1 \cdot 0.55 = 0.55$$; $$E[X] = 0.7$$, $$E[Y] = 0.65$$.

$$\mathrm{Cov}(X,Y) = 0.55 - 0.7 \times 0.65 = 0.095$$

**Correlation:** $$\sigma_X^2 = 0.7(0.3) = 0.21$$, $$\sigma_Y^2 = 0.65(0.35) = 0.2275$$.

$$\rho = \frac{0.095}{\sqrt{0.21 \times 0.2275}} = \frac{0.095}{0.2186} = 0.4346$$

Independence fails (e.g., $$0.20 \ne 0.30 \times 0.35 = 0.105$$), consistent with $$\rho \ne 0$$.

### Worked example: two-asset portfolio variance

Asset A: $$\sigma_A = 20\%$$; Asset B: $$\sigma_B = 12\%$$; $$\rho = 0.3$$. Portfolio: 60% A, 40% B.

$$\mathrm{Cov}(A,B) = 0.3 \times 0.20 \times 0.12 = 0.0072$$

$$\sigma_P^2 = 0.6^2(0.04) + 0.4^2(0.0144) + 2(0.6)(0.4)(0.0072)$$

$$= 0.0144 + 0.002304 + 0.003456 = 0.02016$$

$$\sigma_P = \sqrt{0.02016} = 14.20\%$$

Compare with the weighted average $$0.6(20) + 0.4(12) = 16.8\%$$ — diversification saved 2.6 points.

### Worked example: iid scaling

Daily returns are iid with $$\sigma_d = 1.2\%$$. The 10-day volatility is

$$\sigma_{10} = 1.2\% \times \sqrt{10} = 3.79\%$$

and 10-day variance is $$10 \times 1.2^2 = 14.4$$ (%²) — variance scales with $$t$$, volatility with $$\sqrt{t}$$.

## Quick quiz

**1.** $$\sigma_X = 5$$, $$\sigma_Y = 8$$, $$\rho = -0.25$$. $$\mathrm{Var}(X + Y)$$ is:

- A. 89
- B. 69
- C. 109
- D. 49

**2.** If $$U = 3X + 2$$ and $$V = -4Y + 1$$, and $$\rho(X, Y) = 0.5$$, then $$\rho(U, V) =$$

- A. 0.5
- B. $$-0.5$$
- C. $$-6.0$$
- D. 0.0

**3.** Zero correlation between $$X$$ and $$Y$$ guarantees independence:

- A. Always
- B. Never
- C. Only if $$X$$ and $$Y$$ are jointly normally distributed
- D. Only if both have zero mean

**4.** Daily returns are iid with daily variance 0.0004. The 25-day return standard deviation is:

- A. 0.01
- B. 0.10
- C. 0.02
- D. 0.05

<details markdown="1">
<summary>Show answers</summary>

**1. B** — $$\mathrm{Cov} = -0.25(5)(8) = -10$$; $$\mathrm{Var} = 25 + 64 + 2(-10) = 69$$.

**2. B** — Scales 3 and $$-4$$: sign of $$ac$$ is negative, so correlation flips to $$-0.5$$; magnitude unchanged.

**3. C** — Joint normality is the special case where uncorrelated implies independent.

**4. B** — $$\sigma_d = 0.02$$; $$\sigma_{25} = 0.02\sqrt{25} = 0.10$$.
