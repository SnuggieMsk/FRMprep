# 15. Machine Learning and Prediction

The supervised-learning toolbox: logistic regression, decision trees and ensembles, KNN, SVM, neural networks, and how to score classifiers (confusion matrix, precision/recall, ROC/AUC). Confusion-matrix arithmetic is the most likely calculation here.

## Learning objectives

- Explain the role of linear and logistic regression as elementary prediction tools and compute predicted probabilities from a logistic model.
- Describe decision trees, how they are grown, and ensemble methods (bagging, random forests, boosting).
- Describe K-nearest neighbors (KNN) and support vector machines (SVM) for classification.
- Describe the structure of neural networks and how they are trained.
- Apply and interpret performance metrics: confusion matrix, accuracy, precision, recall, F1, ROC curve, and AUC.
- Understand the use of reinforcement learning in sequential decision problems.

## Logistic regression

For a binary outcome, model the **probability** through the sigmoid so predictions stay in $$(0,1)$$:

$$P(Y = 1 \mid X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X_1 + \cdots + \beta_k X_k)}}$$

Equivalently the **log-odds** are linear: $$\ln\frac{p}{1-p} = \beta_0 + \beta_1 X_1 + \cdots$$. Each $$\beta_j$$ is the change in log-odds per unit of $$X_j$$. Estimated by maximum likelihood, not OLS. Classify as 1 when $$\hat p$$ exceeds a chosen threshold (0.5 by default — but lower it when missing a default is costlier than a false alarm).

{: .warning }
Plain linear regression on a 0/1 outcome can predict probabilities below 0 or above 1 and forces constant marginal effects — that is exactly why logistic regression exists. GARP tests this contrast.

## Decision trees and ensembles

A **decision tree** recursively splits the feature space with binary questions ($$\text{leverage} > 3.2$$?), choosing at each node the split that best purifies the child nodes — minimizing **Gini impurity** $$\sum_k p_k(1-p_k)$$ or **entropy** $$-\sum_k p_k \ln p_k$$ (classification), or MSE (regression). Leaves carry predictions. Trees are interpretable and capture nonlinearities/interactions automatically, but deep trees overfit badly (high variance). Control by limiting depth/minimum leaf size or pruning.

**Ensembles** fix the variance problem by combining many models:

- **Bagging:** train trees on bootstrap resamples; average (or majority-vote) predictions.
- **Random forest:** bagging plus a random subset of features at each split — decorrelates the trees, cutting ensemble variance further.
- **Boosting (e.g., gradient boosting):** build shallow trees **sequentially**, each fitted to the previous ensemble's errors; reduces bias as well as variance but can overfit if run too long.

## K-nearest neighbors

To classify a point: find the $$K$$ closest training points (standardized features, usually Euclidean distance) and take a majority vote (or average, for regression). No training phase ("lazy" learner). Small $$K$$ ⇒ flexible, high variance; large $$K$$ ⇒ smooth, high bias. Costly at prediction time; struggles in high dimensions.

## Support vector machines

SVM finds the separating boundary that **maximizes the margin** — the distance to the nearest training points (the *support vectors*, which alone determine the boundary). Soft-margin SVM tolerates some misclassification via a cost parameter; the **kernel trick** (polynomial, radial) builds nonlinear boundaries by implicitly mapping features to higher dimensions. Effective in high-dimensional problems; output scores are not natural probabilities.

## Neural networks

Layers of neurons: input layer (features) → hidden layer(s) → output. Each neuron computes a weighted sum of its inputs plus a bias, passed through a nonlinear **activation function** (sigmoid, tanh, ReLU $$= \max(0, z)$$):

$$a = g(w^\top x + b)$$

With enough hidden units, networks approximate almost any function. Training: minimize a loss (MSE, cross-entropy) by **gradient descent**, with gradients computed by **backpropagation**; the learning rate sets the step size. Many weights ⇒ strong overfitting risk: hold-out validation, early stopping, regularization, dropout. Powerful but opaque — a model-governance issue in regulated finance.

## Performance measurement for classifiers

**Confusion matrix** (positive = the event of interest, e.g., default):

| | Predicted + | Predicted − |
|---|---|---|
| Actual + | TP | FN |
| Actual − | FP | TN |

$$\text{Accuracy} = \frac{TP + TN}{TP+TN+FP+FN} \qquad \text{Precision} = \frac{TP}{TP + FP}$$

$$\text{Recall (sensitivity, TPR)} = \frac{TP}{TP + FN} \qquad F_1 = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}$$

**ROC curve:** true-positive rate vs. false-positive rate as the classification threshold sweeps from 1 to 0. **AUC** (area under ROC): probability a random positive is scored above a random negative — 1.0 perfect, 0.5 coin flip.

{: .warning }
Accuracy is nearly useless with imbalanced classes: if 2% of loans default, "predict no default always" scores 98% accuracy with zero recall. For rare-event risk models, judge precision/recall, F1, and AUC — and remember lowering the threshold raises recall at the cost of precision.

## Reinforcement learning

An **agent** observes a state, takes an action, receives a reward, and learns a **policy** maximizing cumulative (discounted) reward through trial and error — balancing **exploration** (trying new actions) against **exploitation** (using what works). Q-learning estimates the value of state–action pairs. Finance applications: optimal trade execution (minimizing market impact), dynamic hedging, market making.

### Worked example: logistic default probability

A fitted PD model: $$\ln\frac{p}{1-p} = -4 + 0.8 \times \text{leverage}$$. For leverage = 5:

$$z = -4 + 0.8 \times 5 = 0, \qquad p = \frac{1}{1 + e^{0}} = 0.50$$

For leverage = 3: $$z = -1.6$$, $$p = \frac{1}{1+e^{1.6}} = \frac{1}{1+4.953} = 0.168$$. With a 0.25 threshold, the first borrower is classified as a default risk, the second is not.

### Worked example: confusion-matrix metrics

A default model on 1,000 loans (50 actual defaults): TP = 30, FN = 20, FP = 70, TN = 880.

$$\text{Accuracy} = \frac{30 + 880}{1000} = 91.0\%$$

$$\text{Precision} = \frac{30}{30 + 70} = 30.0\% \qquad \text{Recall} = \frac{30}{30 + 20} = 60.0\%$$

$$F_1 = \frac{2 \times 0.30 \times 0.60}{0.30 + 0.60} = \frac{0.36}{0.90} = 0.40$$

Accuracy looks excellent, yet the model misses 40% of defaults and only 3 in 10 alarms are real — the imbalanced-data lesson in numbers.

**1.** A logistic model gives log-odds $$z = 1.0$$ for a borrower. The predicted default probability is closest to:

- A. 50.0%
- B. 73.1%
- C. 26.9%
- D. 100%

**2.** A random forest reduces overfitting relative to a single deep tree primarily by:

- A. Increasing each tree's depth
- B. Averaging many decorrelated trees grown on bootstrap samples
- C. Fitting each tree to the previous tree's residuals
- D. Removing the need for validation data

**3.** A classifier has TP = 40, FP = 10, FN = 60, TN = 890. Its recall is:

- A. 80%
- B. 40%
- C. 93%
- D. 4%

**4.** An AUC of 0.5 indicates:

- A. A perfect classifier
- B. A classifier no better than random ranking
- C. 50% accuracy
- D. Half the positives are detected
