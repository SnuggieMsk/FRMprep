# 7. Linear Regression

Single-variable OLS: the slope/intercept formulas, the OLS assumptions, interpreting coefficients, and $$R^2$$. You should be able to compute $$\hat\beta$$ from covariances and test a slope coefficient cold.

## Learning objectives

- Describe the models that can be estimated using linear regression and differentiate them from those that cannot.
- Interpret the results of an ordinary least squares (OLS) regression with a single explanatory variable.
- Describe the key assumptions of OLS parameter estimation.
- Characterize the properties of OLS estimators and their sampling distributions.
- Construct, apply, and interpret hypothesis tests and confidence intervals for a single regression coefficient.

## The model

$$Y_i = \alpha + \beta X_i + \epsilon_i$$

- $$Y$$: dependent (explained) variable; $$X$$: independent (explanatory) variable; $$\epsilon$$: error/shock capturing everything else.
- "Linear" means **linear in the parameters**. $$Y = \alpha + \beta X^2 + \epsilon$$ and $$\ln Y = \alpha + \beta \ln X + \epsilon$$ are fine (transform the data); $$Y = \alpha + X^\beta + \epsilon$$ is not estimable by OLS.

## OLS estimators

OLS minimizes the sum of squared residuals $$\sum \hat\epsilon_i^2$$. The solutions:

$$\hat\beta = \frac{\sum (X_i - \bar X)(Y_i - \bar Y)}{\sum (X_i - \bar X)^2} = \frac{\widehat{\mathrm{Cov}}(X, Y)}{\widehat{\mathrm{Var}}(X)} = \rho_{XY}\frac{s_Y}{s_X}$$

$$\hat\alpha = \bar Y - \hat\beta \bar X$$

The fitted line always passes through $$(\bar X, \bar Y)$$; residuals sum to zero and are uncorrelated with $$X$$ in-sample. The CAPM beta is exactly this estimator with market excess returns as $$X$$.

**Interpretation:** $$\hat\beta$$ = expected change in $$Y$$ per one-unit change in $$X$$; $$\hat\alpha$$ = expected $$Y$$ when $$X = 0$$.

## Key OLS assumptions

1. The mean of the error is zero given $$X$$: $$E[\epsilon \mid X] = 0$$ (exogeneity — $$X$$ uncorrelated with the error).
2. $$(X_i, Y_i)$$ pairs are iid draws (random sampling).
3. The variance of $$X$$ is positive and large outliers are unlikely (finite fourth moments).
4. Constant error variance, $$\mathrm{Var}(\epsilon \mid X) = \sigma^2$$ (homoskedasticity), and no correlation across errors — needed for the textbook standard errors and efficiency (Gauss–Markov: OLS is BLUE).

Under 1–3, OLS is unbiased and consistent, and by the CLT $$\hat\beta$$ is approximately normal in large samples.

{: .warning }
Violating homoskedasticity (assumption 4) does **not** bias $$\hat\beta$$ — it invalidates the *standard errors* and thus the t-tests. Violating exogeneity (assumption 1) is the deadly one: it biases the coefficient itself. Know which assumption breaks what.

## Goodness of fit

Total variation splits into explained and residual parts:

$$\underbrace{\sum (Y_i - \bar Y)^2}_{TSS} = \underbrace{\sum (\hat Y_i - \bar Y)^2}_{ESS} + \underbrace{\sum \hat\epsilon_i^2}_{RSS}$$

$$R^2 = \frac{ESS}{TSS} = 1 - \frac{RSS}{TSS}$$

In single-variable regression, $$R^2 = \rho_{XY}^2$$. The **standard error of the regression** is $$s_\epsilon = \sqrt{RSS/(n-2)}$$ (two parameters estimated).

## Inference on coefficients

$$t = \frac{\hat\beta - \beta_0}{SE(\hat\beta)} \sim t_{n-2}$$

Most often $$\beta_0 = 0$$ (is $$X$$ relevant at all?). Confidence interval:

$$\hat\beta \pm t_{\alpha/2,\,n-2}\,SE(\hat\beta)$$

Reject $$H_0: \beta = \beta_0$$ at level $$\alpha$$ exactly when $$\beta_0$$ falls outside the interval.

### Worked example: estimating beta from moments

Stock and market excess returns give: $$\widehat{\mathrm{Cov}}(R_s, R_m) = 0.0024$$, $$\widehat{\mathrm{Var}}(R_m) = 0.0016$$, $$\bar R_s = 1.0\%$$, $$\bar R_m = 0.5\%$$.

$$\hat\beta = \frac{0.0024}{0.0016} = 1.50$$

$$\hat\alpha = 1.0 - 1.50 \times 0.5 = 0.25\%$$

Fitted model: $$\hat R_s = 0.25 + 1.50\,R_m$$. If $$\rho = 0.6$$ between stock and market, $$R^2 = 0.36$$: the market explains 36% of the stock's variance.

### Worked example: testing a slope

A regression on $$n = 62$$ observations yields $$\hat\beta = 0.85$$ with $$SE(\hat\beta) = 0.30$$.

**Test $$H_0: \beta = 0$$ (5%, two-sided):**

$$t = \frac{0.85}{0.30} = 2.833$$

With 60 d.o.f. the critical value is 2.000; $$2.833 > 2.000$$, so reject — $$X$$ is significant.

**Test $$H_0: \beta = 1$$ (e.g., is the hedge ratio one?):**

$$t = \frac{0.85 - 1}{0.30} = -0.50$$

$$\lvert -0.50 \rvert < 2.000$$: fail to reject — statistically indistinguishable from a one-for-one hedge.

**95% CI:** $$0.85 \pm 2.000 \times 0.30 = (0.25,\, 1.45)$$ — contains 1, excludes 0, matching both tests.

{: .tip }
"Significant" answers come straight off the t-table: with large $$n$$, $$\lvert t \rvert > 1.96$$ at 5% and $$> 2.58$$ at 1%. If GARP gives a coefficient and its SE, they almost certainly want $$t = \hat\beta / SE$$.

## Quick quiz

**1.** $$s_X = 4\%$$, $$s_Y = 6\%$$, $$\rho_{XY} = 0.5$$. The OLS slope of $$Y$$ on $$X$$ is:

- A. 0.33
- B. 0.50
- C. 0.75
- D. 1.33

**2.** In a single-variable OLS regression, $$R^2 = 0.49$$. The correlation between $$X$$ and $$Y$$ is:

- A. 0.49
- B. $$\pm 0.70$$
- C. 0.24
- D. Cannot be determined

**3.** Heteroskedastic errors in OLS cause:

- A. Biased slope estimates
- B. Invalid standard errors but unbiased slope estimates
- C. Inconsistent slope estimates
- D. A downward-biased $$R^2$$

**4.** $$\hat\beta = 1.2$$, $$SE = 0.4$$, $$n$$ large. At the 5% level, $$H_0: \beta = 0$$ is:

- A. Rejected ($$t = 3.0$$)
- B. Not rejected ($$t = 0.48$$)
- C. Rejected only one-sided
- D. Not testable without $$R^2$$

<details markdown="1">
<summary>Show answers</summary>

**1. C** — $$\hat\beta = \rho \frac{s_Y}{s_X} = 0.5 \times 6/4 = 0.75$$.

**2. B** — $$\rho = \pm\sqrt{R^2} = \pm 0.7$$; the sign matches the slope's sign, which is not given.

**3. B** — Heteroskedasticity leaves OLS unbiased/consistent but corrupts the usual standard errors (use robust SEs).

**4. A** — $$t = 1.2/0.4 = 3.0 > 1.96$$: reject.

</details>
