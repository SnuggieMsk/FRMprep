# 14. Machine-Learning Methods

The ML foundations chapter: types of learning, the train/validation/test discipline, over- vs. underfitting and the bias–variance trade-off, regularization (ridge/LASSO), PCA, and K-means. Mostly conceptual on the exam, with occasional small calculations (scaling, cluster assignment, penalty terms).

## Learning objectives

- Discuss the philosophical and practical differences between machine-learning techniques and classical econometrics.
- Explain the differences among supervised, unsupervised, and reinforcement learning.
- Understand the process of and issues with data preparation, including standardization and the handling of categorical variables.
- Describe the differences among training, validation, and test data subsamples; explain the role of each.
- Understand the problems of underfitting and overfitting in model design (the bias–variance trade-off).
- Use principal components analysis to reduce the dimensionality of a set of features.
- Describe and use the K-means clustering algorithm, including measures of cluster quality.
- Be aware of natural language processing and how it is used.

## ML vs. classical econometrics

Econometrics starts from a theory-driven, small, interpretable model and focuses on unbiased parameter estimates and hypothesis tests. ML prioritizes **out-of-sample predictive accuracy**, tolerates biased or opaque models, handles huge feature sets and nonlinearities automatically, and validates empirically (held-out data) rather than via distributional theory.

## Three types of learning

| Type | Data | Goal | Examples |
|---|---|---|---|
| **Supervised** | Labeled $$(X, Y)$$ | Predict $$Y$$ from $$X$$ | Regression, classification: credit scoring, default prediction |
| **Unsupervised** | Unlabeled $$X$$ only | Find structure | PCA, clustering, anomaly detection |
| **Reinforcement** | Reward signal from environment | Learn a policy of sequential actions by trial and error | Optimal trade execution, hedging |

Supervised learning splits further into **regression** (continuous target) and **classification** (categorical target).

## Data preparation

- **Standardization:** rescale features, $$z = (x - \mu)/\sigma$$, so distance- and penalty-based methods (KNN, K-means, ridge/LASSO, SVM) don't let large-unit features dominate. Min-max scaling to $$[0,1]$$ is the common alternative.
- **Categorical variables:** one-hot/dummy encoding (one column per category); ordinal encoding only when categories are genuinely ordered.
- Cleaning: missing values, outliers, deduplication — usually most of the work.

## Training, validation, and test sets

- **Training set:** fit the model parameters.
- **Validation set:** compare candidate models / tune hyperparameters (e.g., $$\lambda$$, $$K$$, tree depth).
- **Test set:** used **once**, at the end, for an unbiased estimate of real-world performance.

**Cross-validation** (k-fold) recycles training data into temporary validation folds when data are scarce.

{: .warning }
Two exam traps. (1) Tuning hyperparameters on the *test* set contaminates it — performance estimates become optimistic; that's the validation set's job. (2) With time-series data, random shuffling leaks the future into training; splits must respect chronology.

## Underfitting, overfitting, and bias–variance

Expected prediction error decomposes as

$$E[(y - \hat f)^2] = \underbrace{\text{Bias}^2}_{\text{too simple}} + \underbrace{\text{Variance}}_{\text{too sensitive}} + \underbrace{\sigma^2_{\text{noise}}}_{\text{irreducible}}$$

- **Underfitting** (high bias): model too simple — poor fit in-sample *and* out-of-sample.
- **Overfitting** (high variance): model memorizes training noise — excellent in-sample, poor out-of-sample. Signature: training error keeps falling while validation error turns upward.
- Complexity should be chosen where *validation* error is minimized.

## Regularization: ridge and LASSO

Penalize complexity directly in the objective:

**Ridge (L2):**

$$\min_\beta \sum_i (y_i - X_i\beta)^2 + \lambda \sum_j \beta_j^2$$

**LASSO (L1):**

$$\min_\beta \sum_i (y_i - X_i\beta)^2 + \lambda \sum_j \lvert\beta_j\rvert$$

| | Ridge | LASSO |
|---|---|---|
| Penalty | squared coefficients | absolute coefficients |
| Effect | shrinks all coefficients toward zero | shrinks **and sets some exactly to zero** |
| Feature selection | no | yes (sparse models) |
| Collinearity | handles well (shares weight) | picks one of a correlated group |

$$\lambda$$ is tuned on validation data: $$\lambda = 0$$ is OLS; $$\lambda \to \infty$$ shrinks everything to zero. Regularization deliberately accepts bias to cut variance — the bias–variance trade-off made explicit. **Elastic net** mixes both penalties.

## Principal components analysis

PCA replaces correlated features with a small set of uncorrelated **principal components** — orthogonal linear combinations ordered by variance explained. The first PC is the direction of maximum variance; each subsequent PC maximizes remaining variance subject to orthogonality. Choose enough PCs to explain, say, 90% of total variance (scree plot).

Finance staple: yield-curve moves compress to ~3 PCs — **level, slope, curvature** — typically explaining 95%+ of variance. Standardize features first; PCs lack direct economic interpretation (a price of dimension reduction).

## K-means clustering

Unsupervised grouping of observations into $$K$$ clusters:

1. Choose $$K$$; initialize $$K$$ centroids.
2. Assign each point to the nearest centroid (Euclidean distance).
3. Recompute each centroid as the mean of its members.
4. Repeat 2–3 until assignments stop changing.

Quality: **inertia** (within-cluster sum of squares) falls as $$K$$ rises — pick $$K$$ at the "elbow," or maximize the **silhouette** score (cohesion vs. separation, range $$-1$$ to $$1$$). Results depend on initialization (run multiple starts) and on feature scaling. Uses: segmenting counterparties, regime identification, fraud/anomaly screening.

### Worked example: K-means assignment

Two centroids in standardized feature space: $$c_1 = (0, 0)$$, $$c_2 = (4, 2)$$. Assign point $$x = (3, 0)$$.

$$d_1 = \sqrt{(3-0)^2 + 0^2} = 3.00, \qquad d_2 = \sqrt{(3-4)^2 + (0-2)^2} = \sqrt{5} = 2.24$$

$$d_2 < d_1$$: assign $$x$$ to cluster 2; centroid 2 then moves toward $$x$$ at the update step.

## Natural language processing

NLP converts text (news, filings, transcripts, complaints) into features: tokenization, stop-word removal, stemming/lemmatization, then representations from bag-of-words/TF-IDF counts to word embeddings and large language models. Risk uses: news **sentiment** scoring, surveillance of trader communications, classifying operational-loss descriptions, KYC/adverse-media screening.

## Quick quiz

**1.** Predicting loan default from labeled historical data is:

- A. Unsupervised learning
- B. Supervised classification
- C. Reinforcement learning
- D. Supervised regression

**2.** Which penalty can set coefficients exactly to zero, performing variable selection?

- A. Ridge (L2)
- B. LASSO (L1)
- C. Both equally
- D. Neither

**3.** Training error is near zero but validation error is large and rising with model complexity. The model is:

- A. Underfit (high bias)
- B. Overfit (high variance)
- C. Well-tuned
- D. Suffering from multicollinearity

**4.** In a PCA of daily yield-curve changes, the first principal component typically represents:

- A. Curvature twists
- B. A parallel level shift
- C. Idiosyncratic noise
- D. The slope
