# 13. Simulation and Bootstrapping

Monte Carlo mechanics, simulation error and how to shrink it (more trials, antithetic variates, control variates), bootstrapping, and pseudo-random seeds. Expect a Monte Carlo standard-error calculation and a conceptual MC-vs-bootstrap question.

## Learning objectives

- Describe the basic steps to conduct a Monte Carlo simulation.
- Describe ways to reduce Monte Carlo sampling error; explain the use of antithetic and control variates in variance reduction.
- Describe the bootstrapping method and its advantage over Monte Carlo simulation.
- Describe pseudo-random number generation and the role of seeds.
- Describe situations where the bootstrapping method is ineffective.
- Describe the disadvantages of the simulation approach to financial problem solving.

## Monte Carlo: the recipe

1. **Specify** the data-generating process (DGP) — distributions and parameters (e.g., GBM for prices, $$N(\mu, \sigma^2)$$ shocks).
2. **Generate** pseudo-random draws from the assumed distributions.
3. **Compute** the statistic or payoff of interest for that path/draw.
4. **Repeat** $$N$$ times (thousands+).
5. **Aggregate:** the estimate is the average across trials; the empirical distribution gives quantiles (VaR), etc.

By the LLN the estimate converges to the true value; by the CLT its error is approximately normal with **standard error**

$$SE = \frac{s}{\sqrt{N}}$$

where $$s$$ is the across-trial standard deviation. Precision improves at rate $$\sqrt{N}$$: **10× more accuracy needs 100× more trials**.

## Variance reduction

**Antithetic variates:** pair each draw $$u$$ with its mirror ($$1-u$$, or $$-z$$ for normals). The two estimates are negatively correlated, so the variance of their average,

$$\mathrm{Var}\!\left(\frac{\hat\theta_1 + \hat\theta_2}{2}\right) = \frac{\sigma^2}{2}(1 + \rho),$$

falls below independent sampling whenever $$\rho < 0$$ — and you reuse the random numbers, halving generation cost.

**Control variates:** simulate alongside the target a related quantity $$X$$ whose true value $$E[X]$$ is known analytically (e.g., price an arithmetic Asian option using the geometric Asian, which has a closed form, as control):

$$\hat\theta_{CV} = \hat\theta + \beta\,(E[X] - \hat{X})$$

The simulation error in $$\hat X$$ corrects the error in $$\hat\theta$$; works best when target and control are highly correlated.

## Pseudo-random numbers and seeds

Computers generate **pseudo-random** sequences: deterministic algorithms that pass statistical randomness tests. The **seed** sets the starting state — the same seed reproduces the identical sequence. Benefits: reproducibility (audit/debug), and fair comparison of two models on identical shocks. The sequence eventually cycles, but modern generators have astronomically long periods.

## Bootstrapping

The bootstrap resamples **with replacement from observed data** instead of drawing from an assumed distribution:

1. From a sample of $$n$$ observations, draw $$n$$ with replacement.
2. Compute the statistic on the resample.
3. Repeat $$B$$ times; the spread of the $$B$$ statistics estimates the sampling distribution (standard errors, confidence intervals, VaR).

Two flavors: **iid bootstrap** (draw single observations — fine for independent data) and **circular block bootstrap** (draw consecutive blocks, wrapping around the end — preserves time-series dependence such as volatility clustering).

**Advantage over Monte Carlo:** no distributional assumption — the data speak for themselves, automatically capturing fat tails and skew that a normal-based MC would miss (no model risk from a misspecified DGP).

**When the bootstrap fails:**

- **Structural breaks / non-stationarity:** history resampled from a different regime misleads.
- **Strong dependence handled naively:** iid resampling destroys autocorrelation and volatility clustering (use block bootstrap).
- **Tails beyond the data:** the bootstrap can never generate losses worse than the worst observation — a real problem for extreme-quantile risk.

{: .warning }
Monte Carlo draws from an *assumed model*; bootstrap draws from *observed data*. MC's weakness is model misspecification; bootstrap's weaknesses are short/unrepresentative samples and inability to extrapolate past observed extremes. The exam asks for this contrast almost verbatim.

## Disadvantages of simulation generally

- Results carry **sampling error**; precision is bought slowly ($$\sqrt{N}$$).
- MC answers are only as good as the assumed DGP (model risk).
- Computational cost for path-dependent or nested problems.
- A simulated answer is specific to the chosen parameters — it provides less general insight than an analytic solution, and analytic solutions should be preferred where they exist.

### Worked example: Monte Carlo standard error

A 10,000-trial simulation of a portfolio's 1-year P&L gives mean \$2.0M and across-trial standard deviation \$15M.

$$SE = \frac{15}{\sqrt{10{,}000}} = \frac{15}{100} = \$0.15\text{M}$$

95% CI for the true expected P&L: $$2.0 \pm 1.96 \times 0.15 = (\$1.71\text{M},\, \$2.29\text{M})$$.

To halve the SE to \$0.075M you need $$4 \times 10{,}000 = 40{,}000$$ trials; to cut it to \$0.015M (10×) you need 1,000,000 trials.

### Worked example: antithetic variates

An estimator has per-pair variance $$\sigma^2 = 400$$. With independent pairs, the average of two draws has variance $$400/2 = 200$$. Using antithetic pairs with $$\rho = -0.6$$:

$$\mathrm{Var} = \frac{400}{2}(1 - 0.6) = 200 \times 0.4 = 80$$

A 60% variance reduction — equivalent to running 2.5× as many independent trials at no extra simulation cost.

### Worked example: bootstrap VaR

Daily returns for 500 days are stored. To estimate the 99% 1-day VaR without assuming normality: draw 500 returns with replacement, compute the 1st percentile (the 5th worst), and repeat $$B = 1{,}000$$ times. Suppose the resampled percentiles average $$-3.1\%$$ with standard deviation 0.4%. Then VaR(99%) ≈ 3.1% of portfolio value, with bootstrap standard error 0.4% — and note that no resample can produce a loss beyond the worst day in the 500-day window.

## Quick quiz

**1.** A Monte Carlo estimate has standard error \$50,000 from 2,500 trials. To reduce the SE to \$10,000, the required number of trials is:

- A. 12,500
- B. 62,500
- C. 25,000
- D. 250,000

**2.** Antithetic variates reduce variance because the paired estimates are:

- A. Independent
- B. Positively correlated
- C. Negatively correlated
- D. Identically zero

**3.** The key advantage of bootstrapping over Monte Carlo is:

- A. It always converges faster
- B. It requires no assumption about the return distribution
- C. It can generate losses beyond historical extremes
- D. It eliminates sampling error

**4.** Fixing the seed of a pseudo-random number generator:

- A. Makes the draws truly random
- B. Reproduces the same sequence of draws each run
- C. Eliminates Monte Carlo error
- D. Is required for antithetic sampling

<details markdown="1">
<summary>Show answers</summary>

**1. B** — SE must fall 5×, so trials rise $$5^2 = 25$$×: $$2{,}500 \times 25 = 62{,}500$$.

**2. C** — Mirrored draws produce negatively correlated estimates; averaging cancels error.

**3. B** — The bootstrap samples the empirical distribution directly; C is exactly what it *cannot* do.

**4. B** — Seeds give reproducibility and let competing models face identical shocks.

</details>
